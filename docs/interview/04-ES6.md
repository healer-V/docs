## 2、let 与var 的区别？
>[!tip] let 与 var
> - **1. 全局污染**：
>   - `var`声明的变量会被挂载到全局对象window上，会污染全局命名空间，容易造成命名冲突。
>   - `let`声明的变量不会被挂载到全局对象window上，不会污染全局命名空间，不会造成命名冲突。
> - **2. 块级作用域**：
>   - `var`声明的变量可以跨越多个函数作用域，可以修改值，会进行变量提升，声明的变量会挂载到window对象上。
>   - `let`声明的变量只能在当前代码块有效，不能跨越多个函数作用域，不能修改值，不会进行变量提升，声明的变量不会挂载到window对象上。
> - **3. 暂时性死区**：
>   - `var`声明的变量可以在整个函数范围内有效，可以访问到。
>   - `let`声明的变量只能在当前代码块有效，不能重复声明。
> - **4. 重复声明**：
>   - `var`声明的变量可以重复声明，可以不用初始化赋值,可以重复赋值，可以修改值。
>   - `let`声明的变量可以不用初始化赋值，不能重复声明,可以修改值。


>[!tip]
> - `var`声明的变量可以重复声明，可以不用初始化赋值,可以重复赋值，可以修改值，会进行变量提升，声明的变量会挂载到window对象上。
> - `let`声明的变量可以不用初始化赋值，不能重复声明,可以修改值。
> - `const`声明的变量是常量，需要初始化赋值，只能赋值一次，不能修改，不能重复声明。
> - `let`和`const`声明的变量不会被提升，而`var`声明的变量会被提升到函数作用域的顶部。
> - `let`和`const` 声明的变量具有块级作用域，而`var`声明的变量则可以在整个函数范围内有效。

## 3、箭头函数有什么用？
>[!tip]
> - 箭头函数是ES6新增的一种函数，可以简化函数的定义，可以直接使用外层作用域的变量。
> - 没有`arguments`对象，所以不能使用`arguments`对象来获取函数的实参。
> - 没有`this`对象，所以不能使用`this`关键字来获取函数的执行上下文。
> - 没有`super`对象，所以不能使用`super`关键字来调用父类的构造函数。
> - 没有`new.target`对象，所以不能使用`new.target`关键字来判断函数是否被用作构造函数。
> - 没有`prototype`属性，所以不能使用`instanceof`关键字来判断函数是否是某个类的实例。
> - 没有`name`属性，所以不能使用`Function.prototype.name`来获取函数的名字。

## 4、call、apply、bind方法有什么区别？
> [!tip]
> 1. 执行方式不同‌：
>   - call和apply是同步代码，改变后页面加载之后就立即执行。
>   - bind是异步代码，改变后不会立即执行，而是返回一个新的函数，需要在之后手动调用这个新函数。
> 2. 传参方式不同‌：
>   - call方法接受多个参数，第一个参数是this的指向，后面依次传入调用的函数参数。
>   - apply方法接受两个参数，第一个参数也是this的指向，第二个参数是一个数组或类数组对象，数组中的元素作为参数传递给函数。
>   - bind方法接受多个参数，第一个参数是this的指向，后面的参数是预设的，调用返回的新函数时可以再传入新的参数，这些参数会跟在预设参数之后。
> 3. ‌返回值和使用场景‌：
>   - call和apply方法会直接调用函数，并返回函数的执行结果。
>   - bind方法不会立即执行函数，而是返回一个新的函数。这个新函数在被调用时，this会按照bind指定的值来绑定。
>   - call和apply常用于需要立即执行函数并改变this指向的场景。
>   - bind常用于需要预先设置this指向，但又不希望立即执行函数的场景，比如回调函数、事件处理函数等。

## 5、什么是异步编程
> [!tip] 异步编程
>1. 它允许代码在等待耗时操作完成时继续执行其他任务，而不会阻塞整个程序的运行。（如网络请求、文件读写等）
>2. JS 是单线程语言，一次只能执行一个任务。如果没有异步机制，所有耗时操作都会阻塞后续代码的执行，导致用户体验差（如浏览器界面卡死）。


## 6、什么是 Promise
> [!tip] 为了统一异步处理模型
>1. 社区提出的`Promise A+`规范：一个拥有`then()`方法的对象或函数，就是`Promise`。
>2. 官方标准: 内置了 `Promise` 类，实现并扩展了 `Promise A+` 规范，添加了`all`、`race`、`reject`、`resolve`、`finally`等方法。
> - 官方标准 Promise 是 ES6 新增的 **异步编程的解决方案**，它是一种对象，用来传递异步操作的消息。
>
> - Promise对象代表一个异步操作的最终结果，可以是成功或失败。
> - Promise对象有**三种状态**：
>    - Pending（等待中）：初始状态，既没有完成也没有失败。
>    - Fulfilled（已完成）：操作成功完成。
>    - Rejected（已失败）：操作失败。
> 
> Promise对象有**两个主要的方法**：
> - `then()`：注册成功和失败的回调函数。
> - `catch()`：注册失败的回调函数。
> - `finally()`：注册无论成功或失败都会执行的回调函数。
>
> Promise对象可以链式调用，这意味着你可以将多个Promise对象按照顺序执行，前一个Promise对象的成功或失败，会触发后一个Promise对象的执行。

## 7、async/await有什么用？
> [!tip]
> async/await是 `ES8 (ES2017)` 新增的语法，它是Promise的语法糖，让异步代码更 简洁易读。
>- 优点：
>  - 简化异步代码的编写
>  - 提高代码的可读性和可维护性‌
>  - 提高应用程序的并发性能和响应速度
>  - 错误处理‌使用try/catch语句来捕获和处理异步操作中可能出现的错误
>  - 支持多种异步操作，可以用于等待其他类型的表达式
>- 缺点：
>  - 兼容性：async/await目前只支持新版本的浏览器。
>  - 调试困难：async/await的代码调试比较困难。

## 8、原型与原型链有什么作用？
> [!tip]
> 1. **原型：**
>     - 用来实现面向对象，标注对象的类型。
>     - 所有对象都有原型，原型是对象所属的原型对象，所有对象都可以访问原型对象的属性和方法。
>     - 原型对象可以添加属性和方法，所有实例对象都可以访问这些属性和方法。
> 2. **原型链：**
>    - 原型链是由一个个原型对象组成的链条，它是实现继承的一种方式。
>    - 当访问一个对象的属性或方法时，JavaScript引擎会先在该对象**本身查找**，如果没有找到，则会沿着原型链继续查找，直到找到为止。
>    - 原型链的顶端是`Object.prototype`，它是所有对象的原型,默认值为`null`。

## 9、模块化的作用？
> [!tip]模块化的概念
>JS 中 组织和封装代码的方式，可以将代码分割成独立、可重用的模块，每个模块有明确的功能和接口。


>[!tip] 模块化的作用
> - **降低耦合度**：模块化可以降低模块间的耦合度，使得代码更容易维护、修改和扩展。
> - **提高代码复用性**：模块化可以提高代码的复用性，可以将模块化的代码片段导入到其他程序中使用。
> - **降低开发难度**：模块化可以降低开发难度，开发人员可以专注于模块的开发，而不需要考虑其他模块的实现。
> - **降低运行时内存占用**：模块化可以降低运行时内存占用，因为模块只在需要时加载，不需要全部加载到内存。
> - **增强可靠性**：模块化可以增强代码的可靠性，因为模块化的代码可以被多个程序共同使用，可以避免程序之间的相互影响。

**模块化的实现方式**
>[!tip] ES Modules
> - ES Modules是JavaScript的模块化方案，它是原生的模块化方案，在浏览器和Node.js中都可以使用。
> - ES Modules特点：
>   - ​**​标准来源​**​：官方标准，新增语法（`import`和`export`）。
>   - **静态模块**：**编译时**就能确定模块的依赖关系，因此可以实现高度的静态分析。
>   - **异步加载**：浏览器中可以异步加载模块，不阻塞页面渲染。
>   - **循环依赖**：支持循环依赖，可以解决模块间的依赖关系。
>   - **跨域加载**：可以跨域加载模块，可以实现模块的共享。
> - **使用：**
>   - 使用`import`导入模块，使用`export`导出模块。
>   - 使用`import.meta`来获取当前模块的信息。

>[!tip] CommonJS
> - CommonJS是服务器端的模块化方案，它是基于模块的思想，通过`require()`和`module.exports`来实现模块化。
> - CommonJS的特点：
>   - ​**​标准来源​**​：社区标准，新增API （`require()函数`、`module.exports`对象）。
>   - **动态模块**：在**运行时**才能确定模块的依赖关系，因此不能实现高度的静态分析。
>   - **同步加载**：CommonJS是同步加载的，模块的加载会阻塞后续代码的执行。
> - **使用：**
>   - 使用`require()`导入模块，使用`module.exports`导出模块。


## 10、ESM和CommonJS的区别
>[!tip] 区别
>  - **1、标准来源**：
>    - `ESM`是ES**官方标准**，新增API。
>    - `CommonJS`是**社区标准**，新增语法。
>  - **2、作用时态：**
>    - `ESM`是 运行时 和 编译时都支持。编译时要求静态语法（tree-shaking）。ES7开始支持运行时态 `import()`，运行过程中确定依赖关系。
>    - `CommonJS`是运行时态，模块放置到函数。
>  - **3、加载方式：**
>    - `ESM`是异步加载，可以跨域加载模块。
>    - `CommonJS`是同步加载，模块的加载会阻塞后续代码的执行。
>  - **4、导出方式：**
>    - `ESM`是通过`export`关键字导出模块，可以导出变量、函数、类、接口等。
>    - `CommonJS`是通过`module.exports`对象导出模块，只能导出变量。
>  - **5、导入方式：**
>    - `ESM`是通过`import`关键字导入模块，可以导入变量、函数、类、接口等。
>    - `CommonJS`是通过`require()`函数导入模块，只能导入变量。
>  - **6、命名空间：**
>    - `ESM`没有命名空间，所有导入的模块都是全局变量。
>    - `CommonJS`有命名空间，导入的模块都挂载到`require()`函数的返回值上。
>  - **7、循环依赖：**
>    - `ESM`支持循环依赖，可以解决模块间的依赖关系。
>    - `CommonJS`不支持循环依赖，因为模块的加载是同步的。


**使用示例**
::: details ESM 和 CommonJS 模块化的导入导出示例
```js
/************* ESM  ****************/
// 导入模块
import { add } from './math.js';

// 导出模块
export function add(a, b) {
  return a + b;
}

/************* CommonJS *************/
// 导入模块
const { add } = require('./math.js');

// 导出模块
module.exports = {
  add: function(a, b) {
    return a + b;
  }
}

```
:::


## 11、for in 和 for of 的区别
>[!tip] for in
**用途​**​：遍历对象的可枚举属性（包括原型链上的属性）
>1. 遍历对象的所有可枚举属性（包括继承的属性）。
>2. 遍历的是键名（对于数组是索引）。
>3. 不保证遍历顺序（虽然现代浏览器通常按定义顺序）。
>4. 适用于普通对象，不推荐用于数组。

>[!tip] for of
**用途​​**：遍历可迭代对象（Array, Map, Set, String, TypedArray, arguments 等）的元素值
>1. 遍历的是值而非键。
>2. 只遍历可迭代对象（实现了 [Symbol.iterator] 方法的对象）。
>3. 保证遍历顺序（按迭代器返回的顺序）。
>4. 不会遍历原型链上的属性。
>5. ES6 新增特性。

## 12、Set和Map有什么区别？
>[!tip] Set和Map的区别
> - **结构不同**： Set是一组key的集合，Map是一组key-value的集合。
> - **存储方式不同**： Set是通过哈希表实现的，Map是通过哈希表和链表实现的。
> - **API不同**： Set只提供add、delete、has、clear等方法，Map提供set、get、delete、has等方法。
> - **性能不同**： Set的查找、删除、添加操作的时间复杂度是O(1)，而Map的查找、删除、添加操作的时间复杂度是O(log n)。
> - **应用场景不同**： Set适合于集合的存储和查询，比如去重、交集、并集等。 Map适合于存储和查找键值对，比如对象。

>[!tip] Set 集合
> - Set类似于数组，但是成员的值都是唯一的，没有重复的值，称为集合。
> - Set的主要方法有：
>   - `add(value)`：添加某个值到Set中，返回Set本身。
>   - `delete(value)`：删除某个值，返回布尔值，表示删除是否成功。
>   - `has(value)`：返回布尔值，表示该值是否为Set的成员。
>   - `clear()`：清空Set。
> - 遍历：
>   - `keys()`：返回键名的遍历器。
>   - `values()`：返回键值的遍历器。
>   - `entries()`：返回键值对的遍历器。
>   - `forEach()`：遍历每个成员，回调函数只接受值，不接受键名。
> - Set的应用场景：
>   - 去重：利用Set可以快速地对数组进行去重操作。
>   - 交集、并集：利用Set可以快速地求两个集合的交集、并集。

>[!tip] Map 字典
> - Map是键值对的有序列表，而键和值都可以是任意类型。
> - Map的主要方法有：
>   - `size`：返回 Map 的成员总数。
>   - `set(key, value)`：设置某个键值对，返回 Map 本身。
>   - `get(key)`：读取某个键对应的值，如果不存在，返回 undefined。
>   - `delete(key)`：删除某个键值对，返回布尔值，表示删除是否成功。
>   - `has(key)`：返回布尔值，表示该键是否存在。
>   - `clear()`：清空 Map。
> - 遍历：
>   - `keys()`：返回键名的遍历器。
>   - `values()`：返回键值的遍历器。
>   - `entries()`：返回键值对的遍历器。
>   - `forEach()`：遍历每个成员，回调函数接受两个参数，第一个参数是键，第二个参数是值。
> - Map的应用场景：
>   - 对象：可以用Map来模拟对象，将键和值对应起来。
>   - 缓存：可以用Map缓存数据，提高读取效率。
>   - 存储：可以用Map存储键值对，方便查找。

## 13、WeakSet 和 WeakMap
#### WeakSet
>[!tip] WeakSet
>1. 只能成员只能是引用类型，而不能是其他类型的值。
>2. WeakSet里面的引用只要在外部消失，它在 WeakSet里面的引用就会自动消失。
>- 在 API 中 WeakSet与Set有两个区别:
>   - 没有遍历操作的API
>   - 没有size属性


#### WeakMap
>[!tip] WeakMap
>1. 只接受对象作为键名（null除外），不接受其他类型的值作为键名。
>2. WeakMap 的键名所指向的对象，一旦不再需要，里面的键名对象和所对应的键值对会自动消失，不用手动删除引用。
>3. 键名只能是对象类型，不能是其他类型的值。
>- 在 API 中 WeakMap与Map有两个区别:
>   - 没有遍历操作的API
>   - 没有clear清空方法
