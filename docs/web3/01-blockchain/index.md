# 区块链基础

## 核心优势

- **底层认知**：理解区块链的运作原理，为智能合约和 DApp 开发打下坚实基础
- **全景视角**：从共识机制到交易模型，建立对去中心化世界的系统认知
- **实操入门**：学会使用 MetaMask 钱包，理解 Gas 费用，准备好与链上交互

## 适用场景

区块链基础知识适用于以下学习路径：

- 零基础入门 Web3 开发
- 理解去中心化应用的架构设计
- 为 Solidity 智能合约开发做准备
- 理解 DeFi、NFT 等应用背后的原理

## 技术栈

- **区块链平台**：Ethereum
- **钱包工具**：MetaMask
- **测试网络**：Sepolia
- **区块链浏览器**：Etherscan

## 学习路线

1. **区块链核心概念**：区块结构、共识机制、去中心化原理
2. **以太坊基础**：EVM、智能合约、DApp 架构、Layer2
3. **钱包与账户**：公钥/私钥、MetaMask、账户类型
4. **Gas 与交易机制**：Gas 计费、EIP-1559、交易生命周期
