# Ethers.js 实战

## 核心优势

- **轻量高效**：包体积远小于 Web3.js，加载更快
- **TypeScript 优先**：原生 TypeScript 支持，开发体验优秀
- **API 清晰**：Provider（只读）和 Signer（签名）的分离设计简洁直观

## 适用场景

Ethers.js 适用于以下开发场景：

- 现代 DApp 前端开发（推荐首选）
- TypeScript 项目中的区块链交互
- 服务端脚本（自动化交易、数据采集）
- 与 Hardhat 配合进行合约测试和部署

## 技术栈

- **核心库**：Ethers.js (v6)
- **编程语言**：TypeScript / JavaScript
- **类型生成**：TypeChain
- **配合框架**：React + wagmi

## 学习路线

1. **Ethers.js 入门**：与 Web3.js 对比、核心模块、基本用法
2. **Provider 与 Signer**：只读查询、签名交易、钱包管理
3. **合约交互**：Contract 实例、TypeChain 类型安全、事件处理、批量调用
