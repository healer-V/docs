# Solidity 智能合约

## 核心优势

- **链上编程**：Solidity 是以太坊官方智能合约语言，掌握它就能编写链上程序
- **类 JavaScript 语法**：对前端开发者友好，上手门槛低
- **完善的工具链**：Remix IDE、Hardhat、OpenZeppelin 等工具和库支持

## 适用场景

Solidity 智能合约适用于以下开发场景：

- ERC-20 代币发行
- ERC-721 / ERC-1155 NFT 项目
- DeFi 协议（DEX、借贷、质押）
- DAO 治理合约
- 链上游戏逻辑

## 技术栈

- **合约语言**：Solidity (>=0.8.x)
- **开发环境**：Remix IDE、VS Code
- **合约库**：OpenZeppelin
- **测试框架**：Hardhat、Foundry

## 学习路线

1. **开发环境搭建**：Remix IDE 使用、VS Code 配置、编译部署流程
2. **基本语法与数据类型**：值类型、引用类型、存储位置、映射与结构体
3. **函数与修饰器**：可见性、状态可变性、自定义 modifier
4. **合约继承与接口**：多重继承、抽象合约、ERC 标准接口
5. **事件与日志**：事件定义与触发、indexed 参数、前端监听
6. **安全最佳实践**：重入攻击防护、权限控制、审计工具
