# 进阶主题

## 核心优势

- **深入理解**：从应用层深入到协议层，理解 DeFi 和合约升级的底层机制
- **生产级技术**：合约升级模式和数据索引是正式项目的必备技术
- **拓宽视野**：了解 DeFi 生态全貌，为参与或构建协议做准备

## 适用场景

进阶主题适用于以下学习目标：

- 理解 DeFi 协议（AMM、借贷）的工作原理
- 掌握可升级合约的设计模式
- 学习链上数据索引，优化 DApp 数据查询性能
- 为参与 DeFi 协议开发做技术储备

## 技术栈

- **DeFi 协议**：Uniswap、Aave、MakerDAO
- **升级模式**：Transparent Proxy、UUPS
- **数据索引**：The Graph、Subgraph
- **查询语言**：GraphQL

## 学习路线

1. **DeFi 核心概念**：AMM 机制、流动性池、借贷协议、闪电贷
2. **合约升级模式**：代理模式、Transparent Proxy、UUPS、存储布局规则
3. **The Graph 数据索引**：Subgraph 开发、GraphQL 查询、前端集成
