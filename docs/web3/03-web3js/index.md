# Web3.js 前端交互

## 核心优势

- **历史悠久**：最早的以太坊 JavaScript 交互库，社区资源丰富
- **功能全面**：支持账户管理、交易发送、合约交互、事件监听等完整功能
- **浏览器友好**：与 MetaMask 等钱包插件无缝集成

## 适用场景

Web3.js 适用于以下开发场景：

- DApp 前端与智能合约的交互
- 链上数据的查询和展示
- 钱包连接和交易签名
- 实时监听合约事件并更新 UI

## 技术栈

- **核心库**：Web3.js (v4)
- **编程语言**：JavaScript / TypeScript
- **钱包集成**：MetaMask（window.ethereum）
- **传输协议**：HTTP Provider、WebSocket Provider

## 学习路线

1. **Web3.js 入门**：安装配置、连接区块链、Provider 类型
2. **连接区块链与读取数据**：查询区块、余额、合约状态
3. **发送交易与合约调用**：ETH 转账、合约写入方法、Gas 估算
4. **事件监听与过滤**：实时订阅、历史事件查询、链重组处理
