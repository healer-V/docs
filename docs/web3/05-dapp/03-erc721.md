# ERC-721 NFT 开发

NFT（Non-Fungible Token，非同质化代币）是区块链上独一无二的数字资产。与 ERC-20 代币不同，每个 NFT 都拥有唯一的 Token ID，不可互换。ERC-721 标准定义了 NFT 的通用接口，使得数字艺术、游戏道具、域名、会员凭证等资产能够在不同平台之间自由流通。

## 一、NFT 基础概念

### 1. 同质化代币 vs 非同质化代币

| 特征 | 同质化代币（ERC-20） | 非同质化代币（ERC-721） |
|------|---------------------|------------------------|
| 互换性 | 每个代币完全相同，可互换 | 每个代币独一无二，不可互换 |
| 可分割性 | 可分割（如 0.5 ETH） | 不可分割（1 个 NFT 就是 1 个） |
| 标识方式 | 通过余额表示持有量 | 通过唯一的 Token ID 标识 |
| 典型应用 | 货币、积分、治理代币 | 数字艺术、游戏装备、证书 |
| 存储结构 | `mapping(address => uint256)` | `mapping(uint256 => address)` |
| 价值特点 | 同种代币价值相同 | 每个 NFT 价值可能不同 |

### 2. NFT 的组成部分

一个完整的 NFT 由两部分组成：

- **链上数据**：Token ID、拥有者地址、合约逻辑，永久存储在区块链上
- **链下元数据**：图片、名称、描述、属性等，通常存储在 IPFS 或中心化服务器上

::: warning
如果 NFT 的图片存储在中心化服务器上，服务器关闭后图片将不可访问。建议使用 IPFS 等去中心化存储方案，确保数据的持久性。
:::

## 二、ERC-721 标准接口

### 1. 核心函数

ERC-721 标准要求实现以下接口：

| 函数 | 说明 |
|------|------|
| `balanceOf(address owner)` | 查询指定地址持有的 NFT 数量 |
| `ownerOf(uint256 tokenId)` | 查询指定 Token ID 的拥有者 |
| `safeTransferFrom(address from, address to, uint256 tokenId)` | 安全转移 NFT（检查接收方是否能处理 NFT） |
| `transferFrom(address from, address to, uint256 tokenId)` | 转移 NFT（不检查接收方） |
| `approve(address to, uint256 tokenId)` | 授权某地址可转移指定 NFT |
| `setApprovalForAll(address operator, bool approved)` | 授权/取消授权某地址管理你的所有 NFT |
| `getApproved(uint256 tokenId)` | 查询指定 NFT 的被授权地址 |
| `isApprovedForAll(address owner, address operator)` | 查询是否全部授权 |

### 2. 元数据扩展（ERC721Metadata）

| 函数 | 说明 |
|------|------|
| `name()` | NFT 集合名称，如 "Bored Ape Yacht Club" |
| `symbol()` | NFT 集合符号，如 "BAYC" |
| `tokenURI(uint256 tokenId)` | 返回指定 Token ID 的元数据 URI |

### 3. 枚举扩展（ERC721Enumerable）

| 函数 | 说明 |
|------|------|
| `totalSupply()` | 已铸造的 NFT 总数 |
| `tokenByIndex(uint256 index)` | 按全局索引获取 Token ID |
| `tokenOfOwnerByIndex(address owner, uint256 index)` | 按持有者索引获取 Token ID |

::: tip
`safeTransferFrom` 和 `transferFrom` 的区别在于，前者会检查接收方是否实现了 `IERC721Receiver` 接口。如果向不支持 NFT 的合约地址转移，`safeTransferFrom` 会自动回滚，防止 NFT 被永久锁死。
:::

### 2. 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | NFT 名称，通常包含集合名和编号 |
| `description` | string | NFT 描述 |

| `animation_url` | string | 可选，动画/视频/3D 模型文件的 URI |

## 四、IPFS 存储

### 1. 什么是 IPFS

IPFS（InterPlanetary File System）是一个分布式文件存储协议。文件通过内容哈希（CID）寻址，而非 URL 路径。相同内容始终对应相同的 CID，确保数据的不可篡改性。

### 2. 使用 Pinata 上传

Pinata 是最常用的 IPFS 固定服务（Pinning Service），提供免费额度足够开发使用。

::: details 使用 Pinata 上传 NFT 资源
```ts{12-26,30-50}
// scripts/uploadToIPFS.ts
import axios from "axios";
import FormData from "form-data";
import * as fs from "fs";
import * as path from "path";

const PINATA_API_KEY = process.env.PINATA_API_KEY || "";
const PINATA_SECRET_KEY = process.env.PINATA_SECRET_KEY || "";

const PINATA_BASE_URL = "https://api.pinata.cloud";

// 第一步：上传图片文件夹到 IPFS
async function uploadImages(imageDir: string): Promise<string> {
  const formData = new FormData();
  const files = fs.readdirSync(imageDir);

  for (const file of files) {
    const filePath = path.join(imageDir, file);
    formData.append("file", fs.createReadStream(filePath), {
      filepath: `images/${file}`, // 保持目录结构
    });
  }

  const response = await axios.post(
    `${PINATA_BASE_URL}/pinning/pinFileToIPFS`,
    formData,
    {
      headers: {
        ...formData.getHeaders(),
        pinata_api_key: PINATA_API_KEY,
        pinata_secret_api_key: PINATA_SECRET_KEY,
      },
      maxContentLength: Infinity,
    }
  );

  const imageCID = response.data.IpfsHash;
  console.log("Images uploaded. CID:", imageCID);
  return imageCID;
}

// 第二步：生成元数据 JSON 并上传
async function uploadMetadata(imageCID: string, totalSupply: number): Promise<string> {
  const metadataDir = path.join(__dirname, "../metadata");
  if (!fs.existsSync(metadataDir)) {
    fs.mkdirSync(metadataDir, { recursive: true });
  }

  const backgrounds = ["Sunset", "Ocean", "Forest", "Mountain", "Space"];
  const scales = ["Golden", "Silver", "Diamond", "Obsidian", "Emerald"];
  const flames = ["Blue", "Red", "Purple", "White", "Green"];

  for (let i = 0; i < totalSupply; i++) {
    const metadata = {
      name: `Pixel Dragon #${i}`,
      description: "一条来自像素世界的火龙，拥有独特的鳞片纹理和火焰颜色。",
      image: `ipfs://${imageCID}/images/${i}.png`,
      attributes: [
        { trait_type: "Background", value: backgrounds[i % backgrounds.length] },
        { trait_type: "Scales", value: scales[i % scales.length] },
        { trait_type: "Flame Color", value: flames[i % flames.length] },
        { trait_type: "Power Level", display_type: "number", value: Math.floor(Math.random() * 100) },
      ],
    };

    fs.writeFileSync(
      path.join(metadataDir, `${i}.json`),
      JSON.stringify(metadata, null, 2)
    );
  }

  // 上传整个 metadata 文件夹
  const formData = new FormData();
  for (let i = 0; i < totalSupply; i++) {
    formData.append("file", fs.createReadStream(path.join(metadataDir, `${i}.json`)), {
      filepath: `metadata/${i}.json`,
    });
  }

  const response = await axios.post(
    `${PINATA_BASE_URL}/pinning/pinFileToIPFS`,
    formData,
    {
      headers: {
        ...formData.getHeaders(),
        pinata_api_key: PINATA_API_KEY,
        pinata_secret_api_key: PINATA_SECRET_KEY,
      },
      maxContentLength: Infinity,
    }
  );

  const metadataCID = response.data.IpfsHash;
  console.log("Metadata uploaded. CID:", metadataCID);
  return metadataCID;
}

async function main() {
  const imageCID = await uploadImages(path.join(__dirname, "../assets/images"));
  const metadataCID = await uploadMetadata(imageCID, 100);
  console.log("\n=== Upload Complete ===");
  console.log(`Base URI for contract: ipfs://${metadataCID}/metadata/`);
}

main().catch(console.error);
```
:::

::: warning
上传完成后，记录返回的 CID。这个 CID 将作为合约的 `baseURI`，NFT 市场会通过 `tokenURI(tokenId)` 拼接出完整的元数据地址。
:::

## 五、编写 NFT 合约

### 1. 使用 OpenZeppelin 实现

::: details 完整的 NFT 合约
```solidity{10-14,27-30,47-66}
// contracts/PixelDragon.sol
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

import "@openzeppelin/contracts/token/ERC721/ERC721.sol";
import "@openzeppelin/contracts/token/ERC721/extensions/ERC721URIStorage.sol";
import "@openzeppelin/contracts/token/ERC721/extensions/ERC721Enumerable.sol";
import "@openzeppelin/contracts/access/Ownable.sol";
import "@openzeppelin/contracts/utils/Strings.sol";

/**
 * @title PixelDragon
 * @dev 像素龙 NFT 合约，支持白名单铸造、公开铸造和总量限制
 */
contract PixelDragon is ERC721, ERC721Enumerable, ERC721URIStorage, Ownable {
    using Strings for uint256;

    // 铸造配置
    uint256 public constant MAX_SUPPLY = 10000;         // 最大供应量
    uint256 public constant MAX_PER_WALLET = 5;         // 每钱包最多铸造数
    uint256 public mintPrice = 0.01 ether;              // 铸造价格
    uint256 private _nextTokenId;                        // 下一个 Token ID

    // 铸造状态
    enum SaleState { CLOSED, WHITELIST, PUBLIC }
    SaleState public saleState = SaleState.CLOSED;

    // 白名单
    mapping(address => bool) public whitelist;
    // 每个地址已铸造数量
    mapping(address => uint256) public mintedCount;

    // 元数据基础 URI
    string private _baseTokenURI;

    // 事件
    event Minted(address indexed minter, uint256 indexed tokenId);
    event SaleStateChanged(SaleState newState);

    constructor(string memory baseURI)
        ERC721("Pixel Dragon", "PXDRGN")
        Ownable(msg.sender)
    {
        _baseTokenURI = baseURI;
    }

    /// @notice 铸造 NFT
    /// @param quantity 铸造数量
    function mint(uint256 quantity) external payable {
        // 检查铸造状态
        require(saleState != SaleState.CLOSED, "PixelDragon: sale not active");
        if (saleState == SaleState.WHITELIST) {
            require(whitelist[msg.sender], "PixelDragon: not in whitelist");
        }

        // 检查数量限制
        require(quantity > 0, "PixelDragon: quantity must be > 0");
        require(
            mintedCount[msg.sender] + quantity <= MAX_PER_WALLET,
            "PixelDragon: exceeds per-wallet limit"
        );
        require(
            _nextTokenId + quantity <= MAX_SUPPLY,
            "PixelDragon: exceeds max supply"
        );

        // 检查支付金额
        require(msg.value >= mintPrice * quantity, "PixelDragon: insufficient payment");

        // 执行铸造
        for (uint256 i = 0; i < quantity; i++) {
            uint256 tokenId = _nextTokenId;
            _nextTokenId++;
            _safeMint(msg.sender, tokenId);
            emit Minted(msg.sender, tokenId);
        }

        mintedCount[msg.sender] += quantity;
    }

    /// @notice 设置白名单地址（批量）
    function setWhitelist(address[] calldata addresses, bool status) external onlyOwner {
        for (uint256 i = 0; i < addresses.length; i++) {
            whitelist[addresses[i]] = status;
        }
    }

    /// @notice 设置铸造状态
    function setSaleState(SaleState state) external onlyOwner {
        saleState = state;
        emit SaleStateChanged(state);
    }

    /// @notice 设置铸造价格
    function setMintPrice(uint256 newPrice) external onlyOwner {
        mintPrice = newPrice;
    }

    /// @notice 设置基础 URI
    function setBaseURI(string memory baseURI) external onlyOwner {
        _baseTokenURI = baseURI;
    }

    /// @notice 提取合约中的 ETH
    function withdraw() external onlyOwner {
        uint256 balance = address(this).balance;
        require(balance > 0, "PixelDragon: no funds to withdraw");
        (bool success, ) = payable(owner()).call{value: balance}("");
        require(success, "PixelDragon: withdraw failed");
    }

    // ============ 内部函数 & 重写 ============

    function _baseURI() internal view override returns (string memory) {
        return _baseTokenURI;
    }

    function tokenURI(uint256 tokenId)
        public view override(ERC721, ERC721URIStorage)
        returns (string memory)
    {
        // 拼接 baseURI + tokenId + .json
        return string(abi.encodePacked(_baseTokenURI, tokenId.toString(), ".json"));
    }

    // 解决多重继承冲突
    function _update(address to, uint256 tokenId, address auth)
        internal override(ERC721, ERC721Enumerable)
        returns (address)
    {
        return super._update(to, tokenId, auth);
    }

    function _increaseBalance(address account, uint128 value)
        internal override(ERC721, ERC721Enumerable)
    {
        super._increaseBalance(account, value);
    }

    function supportsInterface(bytes4 interfaceId)
        public view override(ERC721, ERC721Enumerable, ERC721URIStorage)
        returns (bool)
    {
        return super.supportsInterface(interfaceId);
    }
}
```

## 六、编写测试

::: details PixelDragon 合约完整测试
```ts{18-23,45-57,72-87}
// test/PixelDragon.ts
import { expect } from "chai";
import { ethers } from "hardhat";
import { PixelDragon } from "../typechain-types";
import { SignerWithAddress } from "@nomicfoundation/hardhat-ethers/signers";

describe("PixelDragon", function () {
  let nft: PixelDragon;
  let owner: SignerWithAddress;
  let whitelistedUser: SignerWithAddress;
  let publicUser: SignerWithAddress;

  const BASE_URI = "ipfs://QmTestCID/metadata/";
  const MINT_PRICE = ethers.parseEther("0.01");

  beforeEach(async function () {
    [owner, whitelistedUser, publicUser] = await ethers.getSigners();
    const NFTFactory = await ethers.getContractFactory("PixelDragon");
    nft = await NFTFactory.deploy(BASE_URI);
    await nft.waitForDeployment();
  });

  describe("部署验证", function () {
    it("应正确设置名称和符号", async function () {
      expect(await nft.name()).to.equal("Pixel Dragon");
      expect(await nft.symbol()).to.equal("PXDRGN");
    });

    it("初始铸造状态应为 CLOSED", async function () {
      expect(await nft.saleState()).to.equal(0); // CLOSED = 0
    });

    it("初始供应量应为 0", async function () {
      expect(await nft.totalSupply()).to.equal(0);
    });
  });

  describe("白名单铸造", function () {
    beforeEach(async function () {
      // 设置白名单并开启白名单铸造
      await nft.setWhitelist([whitelistedUser.address], true);
      await nft.setSaleState(1); // WHITELIST = 1
    });

    it("白名单用户应能铸造", async function () {
      await nft.connect(whitelistedUser).mint(1, { value: MINT_PRICE });
      expect(await nft.balanceOf(whitelistedUser.address)).to.equal(1);
      expect(await nft.ownerOf(0)).to.equal(whitelistedUser.address);
    });

    it("非白名单用户不能铸造", async function () {
      await expect(
        nft.connect(publicUser).mint(1, { value: MINT_PRICE })
      ).to.be.revertedWith("PixelDragon: not in whitelist");
    });

    it("应正确触发 Minted 事件", async function () {
      await expect(
        nft.connect(whitelistedUser).mint(1, { value: MINT_PRICE })
      )
        .to.emit(nft, "Minted")
        .withArgs(whitelistedUser.address, 0);
    });
  });

  describe("公开铸造", function () {
    beforeEach(async function () {
      await nft.setSaleState(2); // PUBLIC = 2
    });

    it("任何人都能在公开阶段铸造", async function () {
      await nft.connect(publicUser).mint(2, { value: MINT_PRICE * 2n });
      expect(await nft.balanceOf(publicUser.address)).to.equal(2);
    });

    it("支付不足时应拒绝", async function () {
      await expect(
        nft.connect(publicUser).mint(1, { value: ethers.parseEther("0.005") })
      ).to.be.revertedWith("PixelDragon: insufficient payment");
    });

    it("超过每钱包限制时应拒绝", async function () {
      await nft.connect(publicUser).mint(5, { value: MINT_PRICE * 5n });
      await expect(
        nft.connect(publicUser).mint(1, { value: MINT_PRICE })
      ).to.be.revertedWith("PixelDragon: exceeds per-wallet limit");
    });

    it("铸造关闭时不能铸造", async function () {
      await nft.setSaleState(0); // CLOSED
      await expect(
        nft.connect(publicUser).mint(1, { value: MINT_PRICE })
      ).to.be.revertedWith("PixelDragon: sale not active");
    });
  });

  describe("元数据", function () {
    beforeEach(async function () {
      await nft.setSaleState(2);
      await nft.connect(publicUser).mint(1, { value: MINT_PRICE });
    });

    it("应返回正确的 tokenURI", async function () {
      expect(await nft.tokenURI(0)).to.equal(`${BASE_URI}0.json`);
    });

    it("owner 应能更新 baseURI", async function () {
      const newBaseURI = "ipfs://QmNewCID/metadata/";
      await nft.setBaseURI(newBaseURI);
      expect(await nft.tokenURI(0)).to.equal(`${newBaseURI}0.json`);
    });
  });

  describe("资金提取", function () {
    it("owner 应能提取合约中的 ETH", async function () {
      await nft.setSaleState(2);
      await nft.connect(publicUser).mint(3, { value: MINT_PRICE * 3n });

      const contractBalance = await ethers.provider.getBalance(await nft.getAddress());
      expect(contractBalance).to.equal(MINT_PRICE * 3n);

      const ownerBalanceBefore = await ethers.provider.getBalance(owner.address);
      const tx = await nft.withdraw();
      const receipt = await tx.wait();
      const gasCost = receipt!.gasUsed * receipt!.gasPrice;

      const ownerBalanceAfter = await ethers.provider.getBalance(owner.address);
      expect(ownerBalanceAfter).to.equal(
        ownerBalanceBefore + MINT_PRICE * 3n - gasCost
      );
    });

    it("非 owner 不能提取", async function () {
      await expect(nft.connect(publicUser).withdraw()).to.be.reverted;
    });
  });
});
```
