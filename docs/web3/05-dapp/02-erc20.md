# ERC-20 代币开发

ERC-20 是以太坊上最广泛使用的代币标准，定义了同质化代币（Fungible Token）的统一接口。从 USDT、USDC 等稳定币到 UNI、AAVE 等治理代币，几乎所有你在交易所看到的以太坊代币都遵循 ERC-20 标准。掌握 ERC-20 的实现原理，是你开发 DeFi 应用的必要基础。

## 一、ERC-20 标准概述

### 1. 什么是 ERC-20

ERC-20（Ethereum Request for Comments 20）是 2015 年由 Fabian Vogelsteller 提出的代币标准提案。它定义了一组函数和事件接口，任何实现了这些接口的合约都可以被钱包、交易所、DeFi 协议等无缝识别和集成。

"同质化"意味着每个代币单位是完全相同的、可互换的——就像人民币一样，你手中的 1 元和他人手中的 1 元没有区别。

### 2. 标准接口

ERC-20 标准要求实现以下函数和事件：

**必须实现的函数：**

| 函数 | 返回值 | 说明 |
|------|--------|------|
| `name()` | `string` | 代币名称，如 "Tether USD" |
| `symbol()` | `string` | 代币符号，如 "USDT" |
| `decimals()` | `uint8` | 小数位数，通常为 18 |
| `totalSupply()` | `uint256` | 代币总供应量 |
| `balanceOf(address)` | `uint256` | 查询指定地址的代币余额 |
| `transfer(address, uint256)` | `bool` | 向目标地址转账 |
| `approve(address, uint256)` | `bool` | 授权第三方使用你的代币 |
| `allowance(address, address)` | `uint256` | 查询授权额度 |
| `transferFrom(address, address, uint256)` | `bool` | 第三方代为转账（需先 approve） |

**必须实现的事件：**

| 事件 | 说明 |
|------|------|
| `Transfer(address indexed from, address indexed to, uint256 value)` | 转账时触发（包括铸造和销毁） |
| `Approval(address indexed owner, address indexed spender, uint256 value)` | 授权时触发 |

::: tip
`decimals` 决定了代币的最小单位。当 `decimals = 18` 时，代币的最小单位是 `10^-18`，这与 ETH 的 Wei 一致。实际存储的数字是整数，前端显示时需要做除法处理。
:::

### 3. 授权-转账机制

ERC-20 的 `approve` + `transferFrom` 模式是 DeFi 协议的核心交互方式：

1. 用户调用 `approve(spender, amount)` 授权某合约（如 Uniswap）可使用的代币额度
2. 合约调用 `transferFrom(user, recipient, amount)` 代替用户完成转账
3. 每次 `transferFrom` 会自动扣减授权额度

::: warning
无限授权（`approve` 设置为 `type(uint256).max`）可以减少交易次数，但存在安全风险。如果被授权的合约存在漏洞，攻击者可能转走你所有的代币。建议只授权实际需要的额度。
:::

## 二、从零实现 ERC-20

为了深入理解标准的工作原理，你可以先手动实现一个完整的 ERC-20 合约。

::: details 完整的 ERC-20 手动实现
```solidity{18-19,43-57,63-79}
// contracts/ManualToken.sol
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

/**
 * @title ManualToken
 * @dev 手动实现 ERC-20 标准，用于理解底层原理
 */
contract ManualToken {
    // 代币元信息
    string public name;
    string public symbol;
    uint8 public decimals;
    uint256 public totalSupply;

    // 核心存储：地址 => 余额
    mapping(address => uint256) private _balances;
    // 授权存储：持有者 => (被授权者 => 额度)
    mapping(address => mapping(address => uint256)) private _allowances;

    // 标准事件
    event Transfer(address indexed from, address indexed to, uint256 value);
    event Approval(address indexed owner, address indexed spender, uint256 value);

    constructor(
        string memory _name,
        string memory _symbol,
        uint8 _decimals,
        uint256 _initialSupply
    ) {
        name = _name;
        symbol = _symbol;
        decimals = _decimals;

        // 初始供应量铸造给部署者
        uint256 supply = _initialSupply * (10 ** uint256(_decimals));
        totalSupply = supply;
        _balances[msg.sender] = supply;
        emit Transfer(address(0), msg.sender, supply);
    }

    /// @notice 查询指定地址的代币余额
    function balanceOf(address account) public view returns (uint256) {
        return _balances[account];
    }

    /// @notice 向目标地址转账
    function transfer(address to, uint256 amount) public returns (bool) {
        require(to != address(0), "ERC20: transfer to zero address");
        require(_balances[msg.sender] >= amount, "ERC20: insufficient balance");

        _balances[msg.sender] -= amount;
        _balances[to] += amount;

        emit Transfer(msg.sender, to, amount);
        return true;
    }

    /// @notice 授权第三方可使用的代币额度
    function approve(address spender, uint256 amount) public returns (bool) {
        require(spender != address(0), "ERC20: approve to zero address");

        _allowances[msg.sender][spender] = amount;
        emit Approval(msg.sender, spender, amount);
        return true;
    }

    /// @notice 查询授权额度
    function allowance(address owner, address spender) public view returns (uint256) {
        return _allowances[owner][spender];
    }

    /// @notice 第三方代为转账（需先 approve）
    function transferFrom(address from, address to, uint256 amount) public returns (bool) {
        require(to != address(0), "ERC20: transfer to zero address");
        require(_balances[from] >= amount, "ERC20: insufficient balance");
        require(_allowances[from][msg.sender] >= amount, "ERC20: insufficient allowance");

        _balances[from] -= amount;
        _balances[to] += amount;
        _allowances[from][msg.sender] -= amount;

        emit Transfer(from, to, amount);
        return true;
    }
}
```
:::

::: danger
上面的手动实现仅用于学习理解。在生产环境中，你应该使用经过审计的 OpenZeppelin 库，它处理了溢出保护、边界条件等诸多细节。
:::

## 三、使用 OpenZeppelin 实现

OpenZeppelin 是经过大量安全审计的智能合约库，提供了 ERC-20 的标准实现和多种扩展模块。

### 1. 基础代币

最简单的方式是继承 `ERC20` 合约：

::: details 使用 OpenZeppelin 创建基础代币
```solidity
// contracts/SimpleToken.sol
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

import "@openzeppelin/contracts/token/ERC20/ERC20.sol";

/**
 * @title SimpleToken
 * @dev 使用 OpenZeppelin 实现的最简 ERC-20 代币
 * 固定供应量 1,000,000 枚，全部铸造给部署者
 */
contract SimpleToken is ERC20 {
    constructor() ERC20("Simple Token", "SMPL") {
        // _mint 内部会设置 totalSupply 并触发 Transfer 事件
        // 18 decimals 是 ERC20 的默认值，所以实际总量是 1000000 * 10^18
        _mint(msg.sender, 1_000_000 * 10 ** decimals());
    }
}
```
:::

### 2. 带扩展功能的代币

实际项目中，你通常需要铸造、销毁、暂停等功能。以下是一个功能完整的代币合约：

::: details 功能完整的 ERC-20 代币合约
```solidity{8-12,26-28,43-49}
// contracts/ProjectToken.sol
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

import "@openzeppelin/contracts/token/ERC20/ERC20.sol";
import "@openzeppelin/contracts/token/ERC20/extensions/ERC20Burnable.sol";
import "@openzeppelin/contracts/token/ERC20/extensions/ERC20Pausable.sol";
import "@openzeppelin/contracts/token/ERC20/extensions/ERC20Capped.sol";
import "@openzeppelin/contracts/access/Ownable.sol";

/**
 * @title ProjectToken
 * @dev 项目代币，具备铸造、销毁、暂停和总量上限功能
 */
contract ProjectToken is ERC20, ERC20Burnable, ERC20Pausable, ERC20Capped, Ownable {

    // 铸造事件，方便前端监听
    event TokensMinted(address indexed to, uint256 amount);

    constructor()
        ERC20("Project Token", "PTK")
        ERC20Capped(100_000_000 * 10 ** 18) // 总量上限 1 亿
        Ownable(msg.sender)
    {
        // 初始铸造 1000 万给部署者（预留团队份额）
        _mint(msg.sender, 10_000_000 * 10 ** decimals());
    }

    /// @notice 铸造新代币（仅 owner 可调用）
    /// @param to 接收地址
    /// @param amount 铸造数量（含 decimals）
    function mint(address to, uint256 amount) public onlyOwner {
        _mint(to, amount);
        emit TokensMinted(to, amount);
    }

    /// @notice 暂停所有转账（紧急情况使用）
    function pause() public onlyOwner {
        _pause();
    }

    /// @notice 恢复转账
    function unpause() public onlyOwner {
        _unpause();
    }

    // 解决多重继承冲突：ERC20Pausable 和 ERC20Capped 都重写了 _update
    function _update(
        address from,
        address to,
        uint256 value
    ) internal override(ERC20, ERC20Pausable, ERC20Capped) {
        super._update(from, to, value);
    }
}
```
:::

### 3. 各扩展模块说明

| 模块 | 功能 | 适用场景 |
|------|------|----------|
| `ERC20Burnable` | 持有者可销毁自己的代币 | 通缩代币、手续费销毁 |
| `ERC20Pausable` | owner 可暂停所有转账 | 安全事故紧急响应 |
| `ERC20Capped` | 设置代币总量硬上限 | 保证代币稀缺性 |
| `ERC20Permit` | 支持 EIP-2612 签名授权（免 gas approve） | 改善用户体验 |
| `ERC20Votes` | 代币持有者可参与链上投票 | DAO 治理 |
| `ERC20Snapshot` | 在特定时间点记录余额快照 | 空投、分红计算 |

## 四、编写测试

### 1. 完整测试用例

::: details ProjectToken 合约测试
```ts{14-18,35-42,56-68}
// test/ProjectToken.ts
import { expect } from "chai";
import { ethers } from "hardhat";
import { ProjectToken } from "../typechain-types";
import { SignerWithAddress } from "@nomicfoundation/hardhat-ethers/signers";

describe("ProjectToken", function () {
  let token: ProjectToken;
  let owner: SignerWithAddress;
  let recipient: SignerWithAddress;
  let spender: SignerWithAddress;

  const INITIAL_SUPPLY = ethers.parseEther("10000000"); // 1000 万
  const MAX_SUPPLY = ethers.parseEther("100000000");    // 1 亿

  beforeEach(async function () {
    [owner, recipient, spender] = await ethers.getSigners();
    const TokenFactory = await ethers.getContractFactory("ProjectToken");
    token = await TokenFactory.deploy();
    await token.waitForDeployment();
  });

  describe("部署验证", function () {
    it("应正确设置代币名称和符号", async function () {
      expect(await token.name()).to.equal("Project Token");
      expect(await token.symbol()).to.equal("PTK");
    });

    it("应正确设置初始供应量", async function () {
      expect(await token.totalSupply()).to.equal(INITIAL_SUPPLY);
    });

    it("初始供应量应全部分配给部署者", async function () {
      expect(await token.balanceOf(owner.address)).to.equal(INITIAL_SUPPLY);
    });

    it("小数位数应为 18", async function () {
      expect(await token.decimals()).to.equal(18);
    });
  });

  describe("转账功能", function () {
    const transferAmount = ethers.parseEther("1000");

    it("应能成功转账", async function () {
      await token.transfer(recipient.address, transferAmount);
      expect(await token.balanceOf(recipient.address)).to.equal(transferAmount);
    });

    it("余额不足时应拒绝转账", async function () {
      const tooMuch = ethers.parseEther("999999999");
      await expect(
        token.transfer(recipient.address, tooMuch)
      ).to.be.reverted;
    });

    it("应触发 Transfer 事件", async function () {
      await expect(token.transfer(recipient.address, transferAmount))
        .to.emit(token, "Transfer")
        .withArgs(owner.address, recipient.address, transferAmount);
    });
  });

  describe("授权与代扣", function () {
    const approveAmount = ethers.parseEther("5000");
    const transferAmount = ethers.parseEther("3000");

    it("应能正确授权", async function () {
      await token.approve(spender.address, approveAmount);
      expect(await token.allowance(owner.address, spender.address))
        .to.equal(approveAmount);
    });

    it("被授权者应能代为转账", async function () {
      await token.approve(spender.address, approveAmount);
      await token.connect(spender).transferFrom(
        owner.address,
        recipient.address,
        transferAmount
      );
      expect(await token.balanceOf(recipient.address)).to.equal(transferAmount);
    });

    it("代扣后授权额度应减少", async function () {
      await token.approve(spender.address, approveAmount);
      await token.connect(spender).transferFrom(
        owner.address,
        recipient.address,
        transferAmount
      );
      const remaining = approveAmount - transferAmount;
      expect(await token.allowance(owner.address, spender.address))
        .to.equal(remaining);
    });
  });

  describe("铸造功能", function () {
    it("owner 应能铸造新代币", async function () {
      const mintAmount = ethers.parseEther("1000");
      await token.mint(recipient.address, mintAmount);
      expect(await token.balanceOf(recipient.address)).to.equal(mintAmount);
    });

    it("非 owner 不能铸造", async function () {
      await expect(
        token.connect(recipient).mint(recipient.address, ethers.parseEther("1"))
      ).to.be.reverted;
    });

    it("铸造超过上限应失败", async function () {
      const overCap = MAX_SUPPLY + 1n;
      await expect(token.mint(recipient.address, overCap)).to.be.reverted;
    });
  });

  describe("销毁功能", function () {
    it("持有者应能销毁自己的代币", async function () {
      const burnAmount = ethers.parseEther("100");
      await token.burn(burnAmount);
      expect(await token.totalSupply()).to.equal(INITIAL_SUPPLY - burnAmount);
    });
  });

  describe("暂停功能", function () {
    it("暂停后转账应失败", async function () {
      await token.pause();
      await expect(
        token.transfer(recipient.address, ethers.parseEther("1"))
      ).to.be.reverted;
    });

    it("恢复后转账应成功", async function () {
      await token.pause();
      await token.unpause();
      const amount = ethers.parseEther("1");
      await token.transfer(recipient.address, amount);
      expect(await token.balanceOf(recipient.address)).to.equal(amount);
    });
  });
});
```

### 1. 部署脚本

::: details 部署 ProjectToken
```ts
// scripts/deployToken.ts
import { ethers } from "hardhat";

async function main() {
  const [deployer] = await ethers.getSigners();
  console.log("Deployer address:", deployer.address);
  console.log("Deployer balance:", ethers.formatEther(
    await ethers.provider.getBalance(deployer.address)
  ), "ETH");

  // 部署 ProjectToken
  const TokenFactory = await ethers.getContractFactory("ProjectToken");
  const token = await TokenFactory.deploy();
  await token.waitForDeployment();

  const tokenAddress = await token.getAddress();
  console.log("ProjectToken deployed to:", tokenAddress);
  console.log("Total supply:", ethers.formatEther(await token.totalSupply()), "PTK");
}

main()
  .then(() => process.exit(0))
  .catch((error) => {
    console.error(error);
    process.exit(1);
  });
```

## 六、前端交互

部署完成后，你可以在前端使用 Ethers.js 与代币合约交互。

### 1. 读取代币信息

::: details 前端读取代币信息
```ts
// src/utils/tokenReader.ts
import { ethers } from "ethers";

// ProjectToken 合约 ABI（只需要用到的函数）
const TOKEN_ABI = [
  "function name() view returns (string)",
  "function symbol() view returns (string)",
  "function decimals() view returns (uint8)",
  "function totalSupply() view returns (uint256)",
  "function balanceOf(address) view returns (uint256)",
];

const TOKEN_ADDRESS = "0x1234...your-deployed-address";

async function getTokenInfo() {
  const provider = new ethers.BrowserProvider(window.ethereum);
  const tokenContract = new ethers.Contract(TOKEN_ADDRESS, TOKEN_ABI, provider);

  const [name, symbol, decimals, totalSupply] = await Promise.all([
    tokenContract.name(),
    tokenContract.symbol(),
    tokenContract.decimals(),
    tokenContract.totalSupply(),
  ]);

  console.log(`${name} (${symbol})`);
  console.log(`Decimals: ${decimals}`);
  console.log(`Total Supply: ${ethers.formatUnits(totalSupply, decimals)}`);
}

async function getBalance(userAddress: string) {
  const provider = new ethers.BrowserProvider(window.ethereum);
  const tokenContract = new ethers.Contract(TOKEN_ADDRESS, TOKEN_ABI, provider);
  const balance = await tokenContract.balanceOf(userAddress);
  const decimals = await tokenContract.decimals();
  return ethers.formatUnits(balance, decimals);
}
```
:::

### 2. 发送转账交易

::: details 前端发起代币转账
```ts{10-17}
// src/utils/tokenTransfer.ts
import { ethers } from "ethers";

const TOKEN_ABI = [
  "function transfer(address to, uint256 amount) returns (bool)",
  "function approve(address spender, uint256 amount) returns (bool)",
];

async function transferToken(toAddress: string, amount: string) {
  const provider = new ethers.BrowserProvider(window.ethereum);
  const signer = await provider.getSigner();
  const tokenContract = new ethers.Contract(TOKEN_ADDRESS, TOKEN_ABI, signer);

  // 将用户输入的数量转为带 decimals 的整数
  const parsedAmount = ethers.parseEther(amount); // 假设 18 decimals
  const tx = await tokenContract.transfer(toAddress, parsedAmount);
  console.log("Transaction hash:", tx.hash);

  // 等待交易确认
  const receipt = await tx.wait();
  console.log("Transaction confirmed in block:", receipt.blockNumber);
  return receipt;
}
```
:::

::: tip
在前端发起交易前，建议先检查用户的代币余额是否充足、目标地址是否合法（非零地址），并在 UI 上明确展示交易详情（数量、gas 费预估）让用户确认。
:::
