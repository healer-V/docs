# DApp 开发实战

## 核心优势

- **全栈实践**：从智能合约到前端界面，完整经历 DApp 开发全流程
- **标准项目**：ERC-20 代币和 ERC-721 NFT 是最通用的实战项目
- **工程化开发**：使用 Hardhat 框架实现编译、测试、部署一体化

## 适用场景

DApp 开发实战适用于以下学习目标：

- 构建你的第一个完整 DApp
- 学习 ERC 标准代币和 NFT 的开发
- 掌握智能合约测试和部署流程
- 实现前端钱包连接和合约交互

## 技术栈

- **开发框架**：Hardhat
- **合约库**：OpenZeppelin
- **前端框架**：React + TypeScript
- **钱包集成**：wagmi + Ethers.js
- **存储服务**：IPFS（Pinata）

## 学习路线

1. **Hardhat 开发框架**：项目初始化、编译测试部署、插件生态
2. **ERC-20 代币开发**：标准实现、OpenZeppelin 扩展、测试用例
3. **ERC-721 NFT 开发**：铸造逻辑、元数据、IPFS 存储
4. **DApp 前端集成**：React + wagmi 钱包连接、合约交互、交易状态管理
