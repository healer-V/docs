# Vue/React 双项目实战

## 一、项目概述

::: tip 双项目架构
在实际开发中，我们可能需要同时维护 Vue 和 React 项目，或者在一个项目中同时使用两种框架。通过 Vite 的 Monorepo 架构，可以优雅地管理多个项目。
:::

### 1、应用场景

::: info 适用场景
- 🏢 **企业级项目**：不同团队使用不同框架
- 🔄 **技术迁移**：逐步从 Vue 迁移到 React
- 📦 **组件库**：需要同时支持 Vue 和 React
- 🎯 **学习对比**：对比两种框架的实现
:::

### 2、架构方案

::: details 架构对比

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **Monorepo** | 代码共享、统一管理 | 配置复杂 | 多项目协作 |
| **独立项目** | 简单清晰 | 代码重复 | 独立项目 |
| **微前端** | 完全隔离 | 通信复杂 | 大型应用 |

:::

```typescript
// packages/shared/utils/index.ts
export function formatDate(date: Date): string {
  return date.toLocaleDateString('zh-CN');
}

export function debounce<T extends (...args: any[]) => any>(
  fn: T,
  delay: number
): (...args: Parameters<T>) => void {
  let timer: NodeJS.Timeout;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}
```

```typescript
  data: T;
```

```typescript
import UserList from './components/UserList';
import { debounce } from '@monorepo/shared/utils';
import type { User } from '@monorepo/shared/types';

function App() {
  const [users, setUsers] = useState<User[]>([]);

  useEffect(() => {
    const fetchUsers = debounce(async () => {
      const response = await fetch('/api/users');

    fetchUsers();
  }, []);

      <h1>React 应用</h1>
      <UserList users={users} />
    </div>
  );
}

export default App;
```

## 五、共享组件开发

### 1、API 服务共享

#### 1.1、API 客户端

```typescript
// packages/shared/api/client.ts
import type { ApiResponse } from '../types';

export class ApiClient {
  private baseURL: string;

  constructor(baseURL: string) {
    this.baseURL = baseURL;
  }

  async request<T>(endpoint: string, options?: RequestInit): Promise<T> {
    const response = await fetch(`${this.baseURL}${endpoint}`, {
      ...options,
      headers: {
        'Content-Type': 'application/json',
        ...options?.headers,
      },
    });

    if (!response.ok) {
      throw new Error(`HTTP error! status: ${response.status}`);
    }

    const data: ApiResponse<T> = await response.json();
    return data.data;
  }

  get<T>(endpoint: string): Promise<T> {
    return this.request<T>(endpoint, { method: 'GET' });
  }

  post<T>(endpoint: string, data: any): Promise<T> {
    return this.request<T>(endpoint, {
      method: 'POST',
      body: JSON.stringify(data),
    });
  }
}
```

#### 1.2、用户 API

```typescript
// packages/shared/api/user.ts
import { ApiClient } from './client';
import type { User } from '../types';

export class UserApi {
  private client: ApiClient;

  constructor(client: ApiClient) {
    this.client = client;
  }

  async getUsers(): Promise<User[]> {
    return this.client.get<User[]>('/users');
  }

  async getUser(id: string): Promise<User> {
    return this.client.get<User>(`/users/${id}`);
  }

  async createUser(user: Omit<User, 'id'>): Promise<User> {
    return this.client.post<User>('/users', user);
  }
}
```

### 2、Vue 中使用共享 API

```typescript
// packages/vue-app/src/composables/useUsers.ts
import { ref } from 'vue';
import { ApiClient } from '@monorepo/shared/api/client';
import { UserApi } from '@monorepo/shared/api/user';
import type { User } from '@monorepo/shared/types';

const client = new ApiClient('/api');
const userApi = new UserApi(client);

export function useUsers() {
  const users = ref<User[]>([]);
  const loading = ref(false);

  const fetchUsers = async () => {
    loading.value = true;
    try {
      users.value = await userApi.getUsers();
    } finally {
      loading.value = false;
    }
  };

  return {
    users,
    loading,
    fetchUsers,
  };
}
```

### 3、React 中使用共享 API

```typescript
// packages/react-app/src/hooks/useUsers.ts
import { useState, useEffect } from 'react';
import { ApiClient } from '@monorepo/shared/api/client';
import { UserApi } from '@monorepo/shared/api/user';
import type { User } from '@monorepo/shared/types';

const client = new ApiClient('/api');
const userApi = new UserApi(client);

export function useUsers() {
  const [users, setUsers] = useState<User[]>([]);
  const [loading, setLoading] = useState(false);

  useEffect(() => {
    const fetchUsers = async () => {
      setLoading(true);
      try {
        const data = await userApi.getUsers();
        setUsers(data);
      } finally {
        setLoading(false);
      }
    };

    fetchUsers();
  }, []);

  return { users, loading };
}
```

## 七、最佳实践

### 1、代码组织

::: tip 组织原则
1. **共享代码**：放在 `packages/shared` 中
2. **框架特定代码**：放在各自的应用目录
3. **类型定义**：统一在 shared/types 中
4. **工具函数**：统一在 shared/utils 中
:::

### 2、类型安全

```typescript
// packages/shared/types/index.ts
export interface User {
  id: string;
  name: string;
  email: string;
```
