# 企业级项目打包优化全链路

## 一、打包优化概述

::: tip 优化目标
企业级项目的打包优化目标是：**更小的体积、更快的加载速度、更好的用户体验**。
:::

### 1、优化指标

::: info 关键指标
- 📦 **包体积**：减少打包后的文件大小
- ⚡ **加载速度**：首屏加载时间（FCP、LCP）
- 🔄 **缓存策略**：合理利用浏览器缓存
- 🎯 **代码分割**：按需加载，减少初始包大小
- 📊 **性能分析**：使用工具分析性能瓶颈
:::

### 2、优化策略

::: details 优化策略矩阵

| 优化方向 | 开发阶段 | 构建阶段 | 运行时 |
|---------|---------|---------|--------|
| **代码优化** | Tree Shaking | 压缩混淆 | 懒加载 |
| **资源优化** | 图片压缩 | 资源压缩 | CDN |
| **依赖优化** | 按需引入 | 外部化 | 预加载 |
| **缓存优化** | 模块化 | 文件哈希 | HTTP 缓存 |

:::

## 二、代码优化

### 1、Tree Shaking

#### 1.1、原理

::: tip Tree Shaking
Tree Shaking 是一种死代码消除技术，通过静态分析找出未使用的代码并在打包时移除。
:::

```typescript
// 源文件 utils.ts
export function used() {
  return 'used';
}

export function unused() {
  return 'unused';
}

// 使用文件
import { used } from './utils';
console.log(used());

// 打包后（unused 被移除）
function used() {
  return 'used';
}
console.log(used());
```

#### 1.2、配置优化

```typescript
// vite.config.ts
export default defineConfig({
  build: {
    // 启用 Tree Shaking
    minify: 'terser',
    terserOptions: {
      compress: {
        drop_console: true, // 移除 console
        drop_debugger: true, // 移除 debugger
        pure_funcs: ['console.log'], // 移除特定函数
      },
    },
  },
});
```

#### 1.3、按需引入

```typescript

// ✅ 正确：按需引入
```

### 2、代码分割

#### 2.1、手动代码分割

```typescript
// vite.config.ts
export default defineConfig({
  build: {
    rollupOptions: {
      output: {
        // 手动分割
        manualChunks: {
          // 第三方库
          'vendor': ['react', 'react-dom'],
          'antd': ['antd'],
          'utils': ['lodash', 'dayjs'],
          // 业务模块
          'common': ['./src/utils', './src/components'],
        },
        // 文件命名
        chunkFileNames: 'js/[name]-[hash].js',
        entryFileNames: 'js/[name]-[hash].js',
        assetFileNames: 'assets/[name]-[hash].[ext]',
      },
    },
  },
});
```

#### 2.2、自动代码分割

```typescript
// vite.config.ts
export default defineConfig({
  build: {
    rollupOptions: {
      output: {
        // 自动分割策略
        manualChunks(id) {
          // node_modules 中的包单独打包
          if (id.includes('node_modules')) {
            // 大型库单独打包
            if (id.includes('antd')) {
              return 'antd';
            }
            if (id.includes('react') || id.includes('react-dom')) {
              return 'react-vendor';
            }
            // 其他第三方库
            return 'vendor';
          }
          
          // 业务代码按目录分割
          if (id.includes('/src/pages/')) {
            const match = id.match(/\/src\/pages\/([^/]+)/);
            if (match) {
              return `page-${match[1]}`;
            }
          }
        },
      },
    },
  },
});
```

### 3、静态资源优化

#### 3.1、资源压缩

```typescript
// vite.config.ts
export default defineConfig({
  build: {
    assetsInlineLimit: 4096, // 小于 4KB 的资源内联为 base64
    assetsDir: 'assets',
    // 资源文件命名
    assetFileNames: (assetInfo) => {
      const info = assetInfo.name.split('.');
      const ext = info[info.length - 1];
      if (/png|jpe?g|svg|gif|tiff|bmp|ico/i.test(ext)) {
        return `images/[name]-[hash][extname]`;
      }
      if (/woff|woff2|eot|ttf|otf/i.test(ext)) {
        return `fonts/[name]-[hash][extname]`;
      }
      return `assets/[name]-[hash][extname]`;
    },
  },
});
```

### 3、性能监控

#### 3.1、性能指标收集

```typescript
// utils/performance.ts
export function measurePerformance() {
  // FCP (First Contentful Paint)
  new PerformanceObserver((entryList) => {
    const entries = entryList.getEntries();
    const fcp = entries[0];
    console.log('FCP:', fcp.startTime);
  }).observe({ entryTypes: ['paint'] });
  
  // LCP (Largest Contentful Paint)
  new PerformanceObserver((entryList) => {
    const entries = entryList.getEntries();
    const lcp = entries[entries.length - 1];
    console.log('LCP:', lcp.renderTime);
  }).observe({ entryTypes: ['largest-contentful-paint'] });
  
  // CLS (Cumulative Layout Shift)
  new PerformanceObserver((entryList) => {
    let cls = 0;
    for (const entry of entryList.getEntries()) {
      if (!entry.hadRecentInput) {
        cls += entry.value;
      }
    }
    console.log('CLS:', cls);
  }).observe({ entryTypes: ['layout-shift'] });
}
```
