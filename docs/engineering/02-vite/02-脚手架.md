# 企业级脚手架落地

## 一、脚手架概述

::: tip 什么是脚手架
脚手架（Scaffold）是一种快速生成项目初始代码的工具，通过预设模板和配置，帮助开发者快速搭建项目结构，提高开发效率。
:::

### 1、脚手架的价值

::: info 核心价值
- ⚡ **快速启动**：秒级创建项目，无需手动配置
- 📦 **标准化**：统一项目结构，便于团队协作
- 🔧 **最佳实践**：内置行业最佳实践和配置
- 🎯 **减少错误**：避免手动配置导致的错误
- 📚 **文档完善**：自动生成 README 和文档
:::

### 2、常见脚手架工具


| 工具 | 特点 | 适用场景 |
|------|------|----------|
| **Vite** | 快速、现代、开箱即用 | Vue/React 新项目 |

#### 2.2、项目创建逻辑

```typescript
// src/commands/create.ts
import fs from 'fs-extra';
import path from 'path';
import { promisify } from 'util';
import { exec } from 'child_process';
import inquirer from 'inquirer';
import chalk from 'chalk';
import ora from 'ora';

const execAsync = promisify(exec);

interface CreateOptions {
  template?: string;
  force?: boolean;
}

export async function createProject(
  projectName: string,
  options: CreateOptions
) {
  const targetDir = path.resolve(process.cwd(), projectName);
  
  // 1. 检查目录是否存在
  if (fs.existsSync(targetDir)) {
    if (options.force) {
      await fs.remove(targetDir);
    } else {
      const { overwrite } = await inquirer.prompt([
        {
          type: 'confirm',
          name: 'overwrite',
          message: '目录已存在，是否覆盖？',
        },
      ]);
      
      if (overwrite) {
        await fs.remove(targetDir);
      } else {
        console.log(chalk.red('操作已取消'));
        return;
      }
    }
  }
  
  // 2. 选择模板
  const template = options.template || await selectTemplate();
  
  // 3. 收集项目信息
  const answers = await collectProjectInfo();
  
  // 4. 创建项目
  const spinner = ora('正在创建项目...').start();
  
  try {
    // 复制模板文件
    await copyTemplate(template, targetDir, answers);
    
    // 安装依赖
    spinner.text = '正在安装依赖...';
    await installDependencies(targetDir);
    
    spinner.succeed('项目创建成功！');
    
    // 5. 显示后续步骤
    console.log(chalk.green('\n下一步：'));
    console.log(`  cd ${projectName}`);
    console.log('  npm run dev');
  } catch (error) {
    spinner.fail('项目创建失败');
    console.error(error);
  }
}
```

#### 2.3、模板复制与变量替换

```typescript
// src/utils/file.ts
import fs from 'fs-extra';
import path from 'path';
import { render } from 'ejs';

export async function copyTemplate(
  template: string,
  targetDir: string,
  variables: Record<string, any>
) {
  const templateDir = path.resolve(__dirname, '../../templates', template);
  
  // 递归复制文件
  await copyDirectory(templateDir, targetDir, variables);
}

async function copyDirectory(
  src: string,
  dest: string,
  variables: Record<string, any>
) {
  const entries = await fs.readdir(src, { withFileTypes: true });
  
  for (const entry of entries) {
    const srcPath = path.join(src, entry.name);
    const destPath = path.join(dest, entry.name);
    
    if (entry.isDirectory()) {
      await fs.ensureDir(destPath);
      await copyDirectory(srcPath, destPath, variables);
    } else {
      // 处理模板文件
      if (entry.name.endsWith('.tpl')) {
        const content = await fs.readFile(srcPath, 'utf-8');
        const rendered = render(content, variables);
        const finalPath = destPath.replace(/\.tpl$/, '');
        await fs.writeFile(finalPath, rendered);
      } else {
        await fs.copy(srcPath, destPath);
      }
    }
  }
}
```

      message: '包管理器：',
      choices: ['npm', 'yarn', 'pnpm'],
      default: 'npm',
    },
  ]);
  
  return answers;

export const routerPlugin: Plugin = {
  name: 'router',
  apply(api) {
    api.addDependency('react-router-dom', '^6.15.0');
    api.addTemplate('src/router/index.tsx', routerTemplate);

### 2、Git 集成

#### 2.1、自动初始化 Git

```typescript
// src/utils/git.ts
import { execSync } from 'child_process';
import fs from 'fs-extra';
import path from 'path';

export async function initGit(targetDir: string) {
  const gitDir = path.join(targetDir, '.git');
  
  if (fs.existsSync(gitDir)) {
    return;
  }
  
  // 初始化 Git
  execSync('git init', { cwd: targetDir });
  
  // 创建 .gitignore
  const gitignore = `
node_modules
dist
.DS_Store
*.log
.env.local
  `.trim();
  
  await fs.writeFile(
    path.join(targetDir, '.gitignore'),
    gitignore
  );
  
  // 创建初始提交
  execSync('git add .', { cwd: targetDir });
  execSync('git commit -m "Initial commit"', { cwd: targetDir });
}
```
