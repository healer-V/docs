# 阿里云完整部署流程（企业级 SOP）

## 一、部署前准备

::: tip 准备工作
在开始部署之前，需要准备好阿里云账号、域名、服务器等资源，并完成相关配置。
:::

### 1、资源清单

::: details 所需资源

- ✅ **阿里云账号**：已实名认证
- ✅ **ECS 服务器**：CentOS 7+ 或 Ubuntu 20.04+
- ✅ **域名**：已备案（如使用国内服务器）
- ✅ **SSL 证书**：免费证书或付费证书
- ✅ **OSS 存储**：可选，用于静态资源存储
- ✅ **CDN**：可选，用于加速

:::

### 2、服务器规格建议

::: info 配置推荐

| 环境 | CPU | 内存 | 带宽 | 适用场景 |
|------|-----|------|------|----------|
| **开发环境** | 1核 | 2GB | 1Mbps | 个人开发 |
| **测试环境** | 2核 | 4GB | 3Mbps | 团队测试 |
| **生产环境** | 4核+ | 8GB+ | 5Mbps+ | 正式上线 |

:::

## 二、服务器初始化

### 1、连接服务器

#### 1.1、SSH 连接

```bash
# 使用密码连接
ssh root@your-server-ip

# 使用密钥连接
ssh -i ~/.ssh/your-key.pem root@your-server-ip
```

#### 1.2、配置 SSH 密钥

```bash
# 生成密钥对
ssh-keygen -t rsa -b 4096

# 复制公钥到服务器
ssh-copy-id root@your-server-ip

# 测试连接
ssh root@your-server-ip
```

### 2、系统初始化

#### 2.1、更新系统

```bash
# CentOS
yum update -y

# Ubuntu
apt update && apt upgrade -y
```

#### 2.2、安装基础工具

```bash
# CentOS
yum install -y wget curl git vim

# Ubuntu
apt install -y wget curl git vim
```

#### 2.3、创建非 root 用户

```bash
# 创建用户
adduser deploy
usermod -aG sudo deploy  # Ubuntu
usermod -aG wheel deploy  # CentOS

# 配置 SSH 密钥
mkdir -p /home/deploy/.ssh
cp ~/.ssh/authorized_keys /home/deploy/.ssh/
chown -R deploy:deploy /home/deploy/.ssh
chmod 700 /home/deploy/.ssh
chmod 600 /home/deploy/.ssh/authorized_keys
```

### 3、防火墙配置

#### 3.1、开放端口

```bash
# CentOS (firewalld)
firewall-cmd --permanent --add-service=http
firewall-cmd --permanent --add-service=https
firewall-cmd --permanent --add-port=3000/tcp
firewall-cmd --reload

# Ubuntu (ufw)
ufw allow 80/tcp
ufw allow 443/tcp
ufw allow 3000/tcp
ufw enable
```

#### 3.2、阿里云安全组配置

::: warning 重要
在阿里云控制台配置安全组规则：
- 入方向：开放 80、443、22 端口
- 出方向：全部开放
:::

## 四、项目部署

### 1、代码部署

#### 1.1、创建部署目录

```bash
# 创建项目目录
mkdir -p /var/www/vite-app
chown -R deploy:deploy /var/www/vite-app

# 创建备份目录
mkdir -p /var/www/backup
chown -R deploy:deploy /var/www/backup
```

#### 1.2、部署脚本

```bash
#!/bin/bash
# /var/www/vite-app/deploy.sh

set -e

PROJECT_DIR="/var/www/vite-app"
BACKUP_DIR="/var/www/backup"
TIMESTAMP=$(date +%Y%m%d-%H%M%S)

echo "开始部署..."

# 1. 备份当前版本
if [ -d "$PROJECT_DIR/dist" ]; then
    echo "备份当前版本..."
    tar -czf "$BACKUP_DIR/vite-app-$TIMESTAMP.tar.gz" -C "$PROJECT_DIR" dist
    echo "备份完成: vite-app-$TIMESTAMP.tar.gz"
fi

# 2. 拉取最新代码
cd "$PROJECT_DIR"
git pull origin main

# 3. 安装依赖
echo "安装依赖..."
npm ci --production=false

# 4. 构建项目
echo "构建项目..."
npm run build

# 5. 验证构建结果
if [ ! -d "$PROJECT_DIR/dist" ]; then
    echo "构建失败：dist 目录不存在"
    exit 1
fi

# 6. 重启 Nginx
echo "重启 Nginx..."
sudo systemctl reload nginx

echo "部署完成！"
```

#### 1.3、设置执行权限

```bash
chmod +x /var/www/vite-app/deploy.sh
```

### 2、Nginx 配置

#### 2.1、创建配置文件

```bash
# 创建配置文件
sudo vim /etc/nginx/conf.d/vite-app.conf
```

#### 2.2、配置文件内容

```nginx
# /etc/nginx/conf.d/vite-app.conf
upstream backend {
    server localhost:3000;
    keepalive 64;
}

# HTTP 重定向到 HTTPS
server {
    listen 80;
    server_name your-domain.com www.your-domain.com;
    
    # Let's Encrypt 验证
    location /.well-known/acme-challenge/ {
        root /var/www/certbot;
    }
    
    # 重定向到 HTTPS
    location / {
        return 301 https://$server_name$request_uri;
    }
}

# HTTPS 配置
server {
    listen 443 ssl http2;
    server_name your-domain.com www.your-domain.com;
    root /var/www/vite-app/dist;
    index index.html;

    # SSL 证书配置
    ssl_certificate /etc/nginx/ssl/your-domain.com.crt;
    ssl_certificate_key /etc/nginx/ssl/your-domain.com.key;
    
    # SSL 优化配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;
    ssl_session_cache shared:SSL:10m;
    ssl_session_timeout 10m;

    # 安全头
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    # Gzip 压缩
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_comp_level 6;
    gzip_types text/plain text/css text/xml text/javascript 
               application/javascript application/xml+rss 
               application/json application/xml image/svg+xml;

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
        access_log off;
    }

    # HTML 不缓存
    location ~* \.(html)$ {
        expires -1;
        add_header Cache-Control "no-cache, no-store, must-revalidate";
        add_header Pragma "no-cache";
    }

    # SPA 路由支持
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 代理
    location /api {
        proxy_pass http://backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        proxy_read_timeout 300s;
        proxy_connect_timeout 75s;
    }

    # 禁止访问隐藏文件
    location ~ /\. {
        deny all;
        access_log off;
        log_not_found off;
    }

    # 日志配置
    access_log /var/log/nginx/vite-app-access.log;
    error_log /var/log/nginx/vite-app-error.log;
}
```

#### 2.3、测试并重载配置

```bash
# 测试配置
sudo nginx -t

# 重载配置
sudo systemctl reload nginx
```

## 五、SSL 证书配置

### 1、申请免费证书

#### 1.1、使用 Let's Encrypt

```bash
# 安装 Certbot
# CentOS
yum install -y certbot python3-certbot-nginx

# Ubuntu
apt install -y certbot python3-certbot-nginx

# 申请证书
sudo certbot --nginx -d your-domain.com -d www.your-domain.com

# 自动续期测试
sudo certbot renew --dry-run
```

#### 1.2、配置自动续期

```bash
# 编辑 crontab
sudo crontab -e

# 添加定时任务（每月1号凌晨3点检查续期）
0 3 1 * * /usr/bin/certbot renew --quiet
```

### 2、使用阿里云证书

#### 2.1、下载证书

::: info 步骤
1. 登录阿里云控制台
2. 进入 SSL 证书管理
3. 下载 Nginx 格式证书
4. 上传到服务器
:::

#### 2.2、配置证书

```bash
# 创建证书目录
sudo mkdir -p /etc/nginx/ssl

# 上传证书文件
# your-domain.com.crt
# your-domain.com.key

# 设置权限
```


## 七、自动化部署

### 1、GitHub Actions 部署

#### 1.1、配置 Secrets

::: warning 重要
在 GitHub 仓库设置中添加以下 Secrets：
- `SERVER_HOST`: 服务器 IP
- `SERVER_USER`: 服务器用户名
- `SERVER_SSH_KEY`: SSH 私钥
:::

#### 1.2、部署工作流

```yaml
# .github/workflows/deploy-aliyun.yml
name: Deploy to Aliyun

on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest
    
    steps:
      - name: Checkout code
        uses: actions/checkout@v3
      
      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '18'
          cache: 'npm'
      
      - name: Install dependencies
        run: npm ci
      
      - name: Build
        run: npm run build
        env:
          VITE_API_URL: ${{ secrets.API_URL }}
      
      - name: Deploy to server
        uses: appleboy/scp-action@master
        with:
          host: ${{ secrets.SERVER_HOST }}
          username: ${{ secrets.SERVER_USER }}
          key: ${{ secrets.SERVER_SSH_KEY }}
          source: "dist/*"
          target: "/var/www/vite-app"
      
      - name: Restart Nginx
        uses: appleboy/ssh-action@master
        with:
          host: ${{ secrets.SERVER_HOST }}
          username: ${{ secrets.SERVER_USER }}
          key: ${{ secrets.SERVER_SSH_KEY }}
          script: |
            sudo systemctl reload nginx
            echo "部署完成！"
```

### 2、本地部署脚本

```bash
#!/bin/bash
# local-deploy.sh

SERVER_HOST="your-server-ip"
SERVER_USER="deploy"
DEPLOY_PATH="/var/www/vite-app"

# 构建项目
echo "构建项目..."
npm run build

# 上传文件
echo "上传文件..."
scp -r dist/* $SERVER_USER@$SERVER_HOST:$DEPLOY_PATH/dist/

# 重启服务
echo "重启服务..."
ssh $SERVER_USER@$SERVER_HOST "sudo systemctl reload nginx"

echo "部署完成！"
```

```bash
    missingok
    rotate 14
    compress
    delaycompress
    notifempty
    create 0640 www-data adm
    sharedscripts
    postrotate
        [ -f /var/run/nginx.pid ] && kill -USR1 `cat /var/run/nginx.pid`
```

```bash
#!/bin/bash
# /var/www/backup/backup.sh

BACKUP_DIR="/var/www/backup"
PROJECT_DIR="/var/www/vite-app"
```
