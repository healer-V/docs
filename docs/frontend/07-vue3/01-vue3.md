# Vue 3 概述

Vue 3 是一个用于构建用户界面的渐进式 JavaScript 框架，既可以作为简单页面的增强库，也能支撑复杂的单页应用（SPA）。

## 一、安装与项目搭建

### 1. 使用 Vite 创建项目（推荐）

官方推荐使用 Vite 作为构建工具，它启动速度极快，且对 Vue 3 有原生支持。

::: details 创建项目命令

```bash
# 使用 npm
npm create vue@latest

# 使用 pnpm
pnpm create vue@latest

# 使用 yarn
yarn create vue@latest
```

运行后按照提示选择需要的功能（TypeScript、Router、Pinia 等），然后：

```bash
cd your-project-name
npm install
npm run dev
```
:::

### 2. CDN 引入（原型或快速验证）

::: details CDN 方式引入

```html
<!-- index.html -->
<!DOCTYPE html>
<html>
<head>
  <title>Vue 3 Demo</title>
</head>
<body>
  <div id="app">{{ message }}</div>

  <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
  <script>
    const { createApp, ref } = Vue

    createApp({
      setup() {
        const message = ref('Hello, Vue 3!')
        return { message }
      }
    }).mount('#app')
  </script>
</body>
</html>
```
:::

### 3. 项目目录结构

使用 `create vue` 创建的标准项目结构如下：

```
my-vue-app/
├── public/           # 静态资源（不经过打包处理）
├── src/
│   ├── assets/       # 需要打包处理的静态资源
│   ├── components/   # 通用组件
│   ├── views/        # 页面级组件
│   ├── router/       # 路由配置
│   ├── stores/       # Pinia 状态管理
│   ├── App.vue       # 根组件
│   └── main.js       # 应用入口
├── index.html        # HTML 入口
└── vite.config.js    # Vite 配置
```

## 二、createApp 应用实例

### 1. 基本用法

Vue 3 使用 `createApp` 替代 Vue 2 的 `new Vue()`，每个 `createApp` 创建一个独立的应用实例，实例之间不会相互干扰。

::: details main.js 入口文件示例

```js{4,7,10}
// src/main.js
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'
import { createPinia } from 'pinia'

const app = createApp(App)  // 创建应用实例

app.use(router)             // 注册路由插件
app.use(createPinia())      // 注册状态管理插件

app.mount('#app')           // 挂载到 DOM
```
:::

### 2. 全局配置

应用实例提供 `app.config` 对象用于全局配置：

::: details 全局配置示例

```js
// src/main.js
import { createApp } from 'vue'
import App from './App.vue'

const app = createApp(App)

// 全局错误处理
app.config.errorHandler = (err, vm, info) => {
  console.error('全局错误捕获:', err, info)
}

// 注册全局组件
import BaseButton from '@/components/BaseButton.vue'
app.component('BaseButton', BaseButton)

// 注册全局指令
app.directive('focus', {
  mounted(el) {
    el.focus()
  }
})

// 提供全局依赖注入值
app.provide('apiBaseUrl', 'https://api.example.com')

app.mount('#app')
```
:::

## 三、模板语法

### 1. 文本插值与表达式

双花括号 `{{ }}` 用于渲染文本内容，支持 JavaScript 表达式：

::: details 插值语法示例

```vue
<template>
  <div>
    <!-- 文本插值 -->
    <p>用户名：{{ username }}</p>

    <!-- JavaScript 表达式 -->
    <p>{{ isVip ? '会员用户' : '普通用户' }}</p>
    <p>{{ price.toFixed(2) }} 元</p>
    <p>{{ items.length > 0 ? '有商品' : '购物车为空' }}</p>

    <!-- 原始 HTML（注意 XSS 风险）-->
    <div v-html="htmlContent"></div>
  </div>
</template>

<script setup>
import { ref } from 'vue'

const username = ref('Alice')
const isVip = ref(true)
const price = ref(99.9)
const items = ref([{ id: 1, name: '商品A' }])
const htmlContent = ref('<strong>加粗内容</strong>')
</script>
```
:::

### 2. 属性绑定

使用 `v-bind`（简写 `:`）动态绑定 HTML 属性：

::: details 属性绑定示例

```vue
<template>
  <!-- 绑定单个属性 -->
  <img :src="avatarUrl" :alt="username" />

  <!-- 绑定 class -->
  <div :class="{ active: isActive, 'text-danger': hasError }">状态样式</div>
  <div :class="[baseClass, isVip ? 'vip-style' : '']">数组语法</div>

  <!-- 绑定 style -->
  <div :style="{ color: textColor, fontSize: fontSize + 'px' }">内联样式</div>

  <!-- 动态属性名 -->
  <button :[dynamicAttr]="attrValue">动态属性</button>

  <!-- 批量绑定对象属性 -->
  <input v-bind="inputAttrs" />
</template>

<script setup>
import { ref, reactive } from 'vue'

const avatarUrl = ref('https://example.com/avatar.png')
const username = ref('Alice')
const isActive = ref(true)
const hasError = ref(false)
const isVip = ref(true)
const baseClass = ref('card')
const textColor = ref('#333')
const fontSize = ref(16)
const dynamicAttr = ref('disabled')
const attrValue = ref(true)

const inputAttrs = reactive({
  type: 'email',
  placeholder: '请输入邮箱',
  maxlength: 100
})
</script>
```
:::

### 3. 条件渲染

::: details v-if / v-show 示例

```vue
<template>
  <!-- v-if：条件为 false 时，元素从 DOM 中移除 -->
  <div v-if="userRole === 'admin'">管理员面板</div>
  <div v-else-if="userRole === 'editor'">编辑器面板</div>
  <div v-else>普通用户视图</div>

  <!-- v-show：条件为 false 时，元素添加 display:none，保留在 DOM -->
  <div v-show="isMenuOpen">侧边菜单</div>
</template>

<script setup>
import { ref } from 'vue'

const userRole = ref('editor')
const isMenuOpen = ref(false)
</script>
```

> **选择原则**：频繁切换显示状态用 `v-show`（减少 DOM 操作）；条件很少改变或涉及权限控制用 `v-if`（避免渲染不必要的内容）。
:::

### 4. 列表渲染

::: details v-for 示例

```vue
<template>
  <!-- 遍历数组 -->
  <ul>
    <li v-for="(product, index) in products" :key="product.id">
      {{ index + 1 }}. {{ product.name }} - ¥{{ product.price }}
    </li>
  </ul>

  <!-- 遍历对象 -->
  <div v-for="(value, key) in userProfile" :key="key">
    {{ key }}：{{ value }}
  </div>

  <!-- 遍历数字范围 -->
  <span v-for="n in 5" :key="n">{{ n }}</span>
</template>

<script setup>
import { ref, reactive } from 'vue'

const products = ref([
  { id: 1, name: '无线耳机', price: 299 },
  { id: 2, name: '机械键盘', price: 599 },
  { id: 3, name: '显示器', price: 1299 }
])

const userProfile = reactive({
  name: 'Alice',
  email: 'alice@example.com',
  role: '管理员'
})
</script>
```
:::

::: warning v-for 的 key 属性
`v-for` 中 `:key` 是必填项，且应使用唯一、稳定的值（如数据库 ID），不要使用数组下标作为 key，否则在排序或删除场景下会引发渲染错误。
:::

### 5. 事件处理

::: details v-on 事件绑定示例

```vue
<template>
  <!-- 内联处理器 -->
  <button @click="count++">点击次数：{{ count }}</button>

  <!-- 方法处理器 -->
  <button @click="handleSubmit">提交订单</button>

  <!-- 传递参数 -->
  <button @click="removeItem(item.id)">删除</button>

  <!-- 事件修饰符 -->
  <form @submit.prevent="handleSubmit">
    <input @keyup.enter="search" v-model="keyword" placeholder="按回车搜索" />
    <div @click.stop="handleCardClick">阻止冒泡</div>
  </form>
</template>

<script setup>
import { ref } from 'vue'

const count = ref(0)
const keyword = ref('')

function handleSubmit() {
  console.log('表单提交，默认行为已阻止')
}

function removeItem(id) {
  console.log('删除商品:', id)
}

function search() {
  console.log('搜索关键词:', keyword.value)
}

function handleCardClick() {
  console.log('点击卡片，不会触发父级点击事件')
}
</script>
```
:::

### 6. 双向绑定 v-model

::: details v-model 表单绑定示例

```vue
<template>
  <form @submit.prevent="handleSubmit">
    <!-- 文本输入 -->
    <input v-model="form.username" type="text" placeholder="用户名" />

    <!-- 密码 -->
    <input v-model="form.password" type="password" placeholder="密码" />

    <!-- 多选框 -->
    <label>
      <input v-model="form.agreeTerms" type="checkbox" />
      同意用户协议
    </label>

    <!-- 单选框 -->
    <label><input v-model="form.gender" type="radio" value="male" /> 男</label>
    <label><input v-model="form.gender" type="radio" value="female" /> 女</label>

    <!-- 下拉选择 -->
    <select v-model="form.city">
      <option value="beijing">北京</option>
      <option value="shanghai">上海</option>
      <option value="guangzhou">广州</option>
    </select>

    <button type="submit">注册</button>
  </form>
</template>

<script setup>
import { reactive } from 'vue'

const form = reactive({
  username: '',
  password: '',
  agreeTerms: false,
  gender: 'male',
  city: 'beijing'
})

function handleSubmit() {
  console.log('表单数据:', form)
}
</script>
```
:::

## 四、单文件组件（SFC）

Vue 3 的单文件组件由三个部分组成：

```vue
<!-- src/components/UserCard.vue -->
<template>
  <!-- 模板：定义组件的 HTML 结构 -->
  <div class="user-card">
    <h3>{{ user.name }}</h3>
    <p>{{ user.email }}</p>
  </div>
</template>

<script setup>
// 逻辑：响应式数据、方法、生命周期等
import { reactive } from 'vue'

const user = reactive({ name: 'Alice', email: 'alice@example.com' })
</script>

<style scoped>
/* 样式：scoped 属性使样式仅作用于当前组件 */
.user-card {
  padding: 16px;
  border: 1px solid #e0e0e0;
  border-radius: 8px;
}
</style>
```

::: tip script setup 语法糖
`<script setup>` 是 Vue 3 推荐的写法，相比普通 `<script>` 更简洁：
- 顶层声明的变量和函数自动暴露给模板
- 组件导入后无需注册，直接在模板中使用
- 配合 TypeScript 有更好的类型推断
:::
