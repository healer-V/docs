# 设计理念

## 一、 Vue 2 是什么

::: tip Vue 2 定义
1. `Vuejs`是一套用于构建用户界面的 **渐进式 JavaScript 框架**。
2. `Vuejs` 被设计为可以自底向上、逐层应用。
3. `Vue2` 是`Vuejs`的第二个版本。
:::

## 二、核心特性

### 2.1 渐进式框架

::: tip 渐进式
- Vue 的核心库只关注视图层
- 易于上手，也便于与第三方库或既有项目整合
- 可以根据项目需求逐步采用 Vue 的功能
:::

### 2.2 响应式

::: tip 响应式系统
- 基于 `Object.defineProperty` 实现响应式系统
- 数据变化时自动更新视图
- 支持双向数据绑定（`v-model`）
:::

### 2.3 组件化开发

::: tip 组件化
- 将页面拆分为可复用的组件
- 组件可以嵌套、组合
- 支持单文件组件（`.vue`）
:::

### 2.4 虚拟 DOM

::: tip 虚拟 DOM
- 使用虚拟 DOM 提高渲染性能
- 通过 diff 算法最小化 DOM 操作
- 支持服务端渲染（`SSR`）
:::

## 三、设计理念

### 3.1 易用性

::: tip 易用性
- 学习曲线平缓
- API 设计直观
- 文档完善
:::

### 3.2 灵活性

::: tip 灵活性
- 可以逐步采用
- 不强制特定的项目结构
- 支持多种开发方式
:::

### 3.3 高效性

::: tip 高效性
- 体积小（运行时约 34KB）
- 性能优秀
- 支持按需加载
:::

## 四、MVVM 模式

Vue 2 采用 **MVVM（Model-View-ViewModel）** 架构模式：

::: details 示意图
```
┌─────────┐         ┌──────────────┐         ┌─────────┐
│  Model  │ ◄─────► │ ViewModel    │ ◄─────► │  View   │
│  (数据) │         │  (Vue实例)   │         │  (模板) │
└─────────┘         └──────────────┘         └─────────┘
```
:::

::: tip MVVM 模式
- `Model（模型）`：数据层，存储应用的数据
- `View（视图）`：展示层，用户看到的界面
- `ViewModel（视图模型）`：连接层，Vue 实例，负责数据绑定和视图更新
:::

## 五、适用场景

::: tip 适用场景
- 单页应用（`SPA`）
- 移动端 `H5` 应用
- 后台管理系统
- 中小型项目快速开发
:::

## 六、生态系统

::: tip Vue 2 生态系统
- `Vue Router`：官方路由管理器
- `Vuex`：官方状态管理库
- `Vue CLI`：官方脚手架工具
- `Vue DevTools`：浏览器调试工具
- `Vue(official)`:语法高亮插件
:::
