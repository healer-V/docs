# Number类型

>[!note] 解释
> 1. JavaScript不区分整数和浮点数，统一用Number表示
> - `123` // 整数
> - `0.456` // 浮点数
> - `1.34e3` // 科学计数法
> - `-99` // 负数
> - `NaN` // 表示 Not a Number ，当无法计算时用NaN表示。
> -`Infinity` // 无限大，超过了JS的Number表示的最大值。
