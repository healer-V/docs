# ES2016-ES2020 新特性

## 一、ES2016（ES7）

### 1. Array.prototype.includes

`includes()` 判断数组是否包含某个值，支持 `NaN` 检测，弥补了 `indexOf` 的不足。

| 方法 | 返回值 | 能检测 NaN |
|------|--------|-----------|
| `arr.indexOf(val)` | 索引或 `-1` | 否 |
| `arr.includes(val)` | `boolean` | 是 |

::: details includes 示例

```js{5,8}
const fruits = ['苹果', '香蕉', NaN, undefined];

// indexOf 无法检测 NaN
console.log(fruits.indexOf(NaN));     // -1（错误结果）

// includes 可以正确检测 NaN
console.log(fruits.includes(NaN));    // true
console.log(fruits.includes('苹果')); // true
console.log(fruits.includes('葡萄')); // false

// 第二个参数：从指定索引开始搜索
console.log(fruits.includes('苹果', 1)); // false（从索引1开始）
```
:::

### 2. 指数运算符（**）

`**` 是 `Math.pow()` 的语法糖，支持赋值简写 `**=`。

::: details 指数运算符示例

```js
// 等价于 Math.pow(2, 10)
console.log(2 ** 10);  // 1024
console.log(3 ** 3);   // 27

// 赋值简写
let base = 2;
base **= 8;
console.log(base); // 256

// 注意：一元运算符优先级低于 **，负号需加括号
console.log(-2 ** 2);    // 语法错误（某些环境）
console.log((-2) ** 2);  // 4
```
:::

## 二、ES2017（ES8）

### 1. Object.values / Object.entries

在 `Object.keys()` 的基础上，补充了取值和取键值对的能力。

::: details Object.values 与 Object.entries 示例

```js
const config = {
  host: 'localhost',
  port: 3000,
  debug: true,
};

// Object.values —— 返回所有值组成的数组
console.log(Object.values(config));
// ['localhost', 3000, true]

// Object.entries —— 返回 [key, value] 对数组
console.log(Object.entries(config));
// [['host','localhost'], ['port',3000], ['debug',true]]

// 常见用途：遍历对象
for (const [key, value] of Object.entries(config)) {
  console.log(`${key}: ${value}`);
}

// 将对象转为 Map
const configMap = new Map(Object.entries(config));
```
:::

### 2. String padding

`padStart()` 和 `padEnd()` 用于将字符串填充到指定长度，常用于格式化输出。

::: details String padding 示例

```js
// 补零格式化时间
const hours   = String(9).padStart(2, '0');  // '09'
const minutes = String(5).padStart(2, '0');  // '05'
console.log(`${hours}:${minutes}`);          // '09:05'

// padEnd 右侧填充
console.log('加载中'.padEnd(10, '.')); // '加载中.......'

// 对齐输出
const items = [
  ['苹果', 3.5],
  ['香蕉', 1.2],
  ['火龙果', 8.8],
];
items.forEach(([name, price]) => {
  console.log(`${name.padEnd(5, '　')} ¥${String(price).padStart(5)}`);
});
```
:::

### 3. Atomics 与 SharedArrayBuffer

`SharedArrayBuffer` 允许多个 Worker 共享同一块内存，`Atomics` 提供原子操作保证线程安全。

::: warning 安全限制
由于 Spectre 漏洞，`SharedArrayBuffer` 需要页面开启跨域隔离（COOP + COEP 响应头）才能使用。
:::

::: details Atomics 基本示例

```js
// 主线程
const sharedBuffer = new SharedArrayBuffer(4); // 4 字节
const sharedArray  = new Int32Array(sharedBuffer);

// 原子加法（线程安全）
Atomics.add(sharedArray, 0, 1);    // 索引0的值 +1
console.log(Atomics.load(sharedArray, 0)); // 1

// 原子比较并交换：若当前值为1，则改为100
Atomics.compareExchange(sharedArray, 0, 1, 100);
console.log(Atomics.load(sharedArray, 0)); // 100
```
:::

## 三、ES2018（ES9）

### 1. 对象展开与剩余语法

数组的展开/剩余语法（`...`）在 ES2018 正式扩展到对象字面量。

::: details 对象展开与剩余示例

```js{4,10}
const defaults = { theme: 'light', lang: 'zh', fontSize: 14 };
const userPrefs = { lang: 'en', fontSize: 16 };

// 对象展开：后面的属性会覆盖前面的
const finalConfig = { ...defaults, ...userPrefs };
// { theme: 'light', lang: 'en', fontSize: 16 }

// 对象剩余：提取指定属性，其余收集到 rest
const { theme, ...rest } = finalConfig;
console.log(theme); // 'light'
console.log(rest);  // { lang: 'en', fontSize: 16 }

// 常用于函数参数处理
function renderComponent({ id, className, ...props }) {
  console.log('id:', id, 'class:', className);
  console.log('其余属性:', props);
}
```
:::

### 2. Promise.finally

无论 Promise 成功还是失败，`.finally()` 都会执行，且不改变 Promise 的结果值。

::: details Promise.finally 示例

```js{10}
function loadData(url) {
  showLoading(); // 显示加载动画

  return fetch(url)
    .then((res) => res.json())
    .catch((err) => {
      console.error('加载失败:', err.message);
      throw err; // 继续传递错误
    })
    .finally(() => {
      hideLoading(); // 无论成功失败都隐藏加载动画
    });
}
```
:::

### 3. 异步迭代（for await...of）

详见异步编程文档中的「异步迭代器」章节，ES2018 正式纳入规范。

### 4. 正则改进

ES2018 新增四项正则特性：

| 特性 | 语法 | 说明 |
|------|------|------|
| 命名捕获组 | `(?<name>...)` | 用名称引用捕获结果 |
| 反向断言 | `(?<=...)` `(?<!...)` | 匹配前面有/没有指定内容 |
| dotAll 模式 | `/s` 标志 | `.` 可以匹配换行符 |
| Unicode 属性转义 | `\p{...}` | 按 Unicode 属性匹配字符 |

::: details 正则改进示例

```js
// 命名捕获组
const dateReg = /(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/;
const { groups } = '2026-03-17'.match(dateReg);
console.log(groups.year, groups.month, groups.day); // 2026 03 17

// dotAll 模式：. 匹配换行符
const html = '<div>\n  内容\n</div>';
console.log(/<div>(.*?)<\/div>/s.test(html)); // true（无 /s 则为 false）

// Unicode 属性转义：匹配所有中文字符
const chineseReg = /\p{Script=Han}+/u;
console.log(chineseReg.test('Hello 世界')); // true
```
:::

## 四、ES2019（ES10）

### 1. Array.flat 与 Array.flatMap

`flat()` 展平嵌套数组，`flatMap()` 是 `map()` + 一层 `flat()` 的组合。

::: details flat 与 flatMap 示例

```js{4,12}
// flat：默认展平一层，传 Infinity 展平所有层
const nested = [1, [2, [3, [4]]]];
console.log(nested.flat());           // [1, 2, [3, [4]]]
console.log(nested.flat(Infinity));   // [1, 2, 3, 4]

// 过滤空槽
const withHoles = [1, , , 4, , 6];
console.log(withHoles.flat()); // [1, 4, 6]

// flatMap：先 map 再 flat（只展平一层）
const sentences = ['Hello World', 'foo bar'];
const words = sentences.flatMap((s) => s.split(' '));
console.log(words); // ['Hello', 'World', 'foo', 'bar']

// flatMap 还可以过滤元素（返回空数组则过滤）
const numbers = [1, 2, 3, 4, 5];
const evenDoubled = numbers.flatMap((n) => (n % 2 === 0 ? [n * 2] : []));
console.log(evenDoubled); // [4, 8]
```
:::

### 2. Object.fromEntries

`Object.fromEntries()` 是 `Object.entries()` 的逆操作，将键值对数组（或 Map）转为对象。

::: details Object.fromEntries 示例

```js
// 键值对数组 → 对象
const entries = [['name', '张三'], ['age', 28]];
const obj = Object.fromEntries(entries);
console.log(obj); // { name: '张三', age: 28 }

// Map → 对象
const map = new Map([['x', 10], ['y', 20]]);
console.log(Object.fromEntries(map)); // { x: 10, y: 20 }

// 实用场景：URLSearchParams → 对象
const params = new URLSearchParams('page=1&size=20&sort=desc');
const query = Object.fromEntries(params);
console.log(query); // { page: '1', size: '20', sort: 'desc' }

// 配合 entries + map 转换对象值
const prices = { apple: 3.5, banana: 1.2 };
const discounted = Object.fromEntries(
  Object.entries(prices).map(([k, v]) => [k, v * 0.8])
);
console.log(discounted); // { apple: 2.8, banana: 0.96 }
```
:::

### 3. String.trimStart / trimEnd

去除字符串首尾空白的语义化方法，替代非标准的 `trimLeft`/`trimRight`。

::: details trimStart / trimEnd 示例

```js
const text = '   Hello World   ';

console.log(text.trimStart()); // 'Hello World   '（去除左侧空白）
console.log(text.trimEnd());   // '   Hello World'（去除右侧空白）
console.log(text.trim());      // 'Hello World'（去除两侧，ES5已有）
```
:::

### 4. 可选 catch 绑定

当不需要使用错误对象时，可以省略 `catch` 的参数。

::: details 可选 catch 绑定示例

```js
// ES2019 之前：必须声明 error 变量，即使不使用
try {
  JSON.parse('{invalid}');
} catch (e) {
  console.log('JSON 格式错误');
}

// ES2019 之后：省略 catch 参数
try {
  JSON.parse('{invalid}');
} catch {
  console.log('JSON 格式错误');
}

// 实用场景：检测功能是否可用
function isLocalStorageAvailable() {
  try {
    localStorage.setItem('test', '1');
    localStorage.removeItem('test');
    return true;
  } catch {
    return false;
  }
}
```
:::

## 五、ES2020（ES11）

### 1. BigInt

`BigInt` 用于表示任意精度的整数，解决了 `Number` 无法精确表示超过 `2^53 - 1` 的整数的问题。

::: warning BigInt 与 Number 不能混合运算
`1n + 1` 会抛出 `TypeError`，需要显式转换：`BigInt(1) + 1n` 或 `Number(1n) + 1`。
:::

::: details BigInt 示例

```js{3}
// 字面量：数字后加 n
const big = 9007199254740993n; // Number 无法精确表示的值
console.log(big);              // 9007199254740993n（精确）
console.log(9007199254740993); // 9007199254740992（精度丢失）

// 运算
console.log(10n ** 20n);     // 100000000000000000000n
console.log(100n / 3n);      // 33n（整除，小数部分截断）

// 比较（可以与 Number 比较，但不能混合运算）
console.log(1n === 1);   // false（类型不同）
console.log(1n == 1);    // true（宽松比较）
console.log(2n > 1);     // true

// 转换
console.log(Number(42n));  // 42
console.log(String(42n));  // '42'
```
:::

### 2. 可选链（?.）

`?.` 在访问链式属性时，遇到 `null` 或 `undefined` 时短路返回 `undefined`，避免抛出错误。

::: details 可选链示例

```js{4,7,10}
const user = {
  name: '张三',
  address: {
    city: '北京',
  },
};

// 访问可能不存在的属性
console.log(user?.address?.city);        // '北京'
console.log(user?.profile?.avatar);      // undefined（不报错）

// 可选方法调用
console.log(user.greet?.());             // undefined（方法不存在时不报错）

// 可选下标访问
const arr = null;
console.log(arr?.[0]);                   // undefined

// 结合空值合并
const city = user?.address?.city ?? '未知城市';
console.log(city); // '北京'
```
:::

### 3. 空值合并（??）

`??` 只在左侧为 `null` 或 `undefined` 时才返回右侧，区别于 `||`（空字符串和 `0` 也会触发 `||`）。

::: details ?? vs || 对比

```js{8,9}
const config = { timeout: 0, title: '' };

// || 的问题：0 和 '' 被视为假值
const timeout1 = config.timeout || 5000;  // 5000（错误！应为0）
const title1   = config.title   || '默认'; // '默认'（错误！应为空字符串）

// ?? 只检测 null/undefined
const timeout2 = config.timeout ?? 5000;  // 0（正确）
const title2   = config.title   ?? '默认'; // ''（正确）

// 实用场景：API 返回值处理
function getPageSize(params) {
  return params.size ?? 20; // 只有未传时才用默认值，传0也生效
}
```
:::

### 4. Promise.allSettled

等待所有 Promise 敲定（不管成功还是失败），返回每个 Promise 的结果描述对象。（见一、4 中的组合方法对比表格）

### 5. globalThis

提供统一的全局对象访问方式，在浏览器（`window`）、Node.js（`global`）、Web Worker（`self`）等不同环境中均适用。

::: details globalThis 示例

```js
// 不同环境中的全局对象
// 浏览器：window
// Node.js：global
// Web Worker：self

// 使用 globalThis 统一访问
console.log(globalThis === window);  // 在浏览器中为 true

// 在通用库中安全访问全局变量
function getEnvVar(key) {
  return globalThis?.process?.env?.[key] ?? globalThis?.[key];
}
```
:::

### 6. String.matchAll

返回所有匹配结果的迭代器，每个结果包含完整的捕获组信息，需要正则带 `g` 标志。

::: details matchAll 示例

```js{3}
const text = '价格：¥12.5，优惠价：¥9.9，到手价：¥8.0';
const priceReg = /¥(\d+\.\d+)/g;

// match 只返回匹配字符串，不含捕获组详情
console.log(text.match(priceReg)); // ['¥12.5', '¥9.9', '¥8.0']

// matchAll 返回完整捕获信息
for (const match of text.matchAll(priceReg)) {
  console.log(`完整匹配: ${match[0]}, 数字: ${match[1]}, 位置: ${match.index}`);
}
// 完整匹配: ¥12.5, 数字: 12.5, 位置: 3
// 完整匹配: ¥9.9,  数字: 9.9,  位置: 12
// 完整匹配: ¥8.0,  数字: 8.0,  位置: 21

// 转为数组处理
const prices = [...text.matchAll(priceReg)].map((m) => Number(m[1]));
console.log(prices); // [12.5, 9.9, 8.0]
```
:::
