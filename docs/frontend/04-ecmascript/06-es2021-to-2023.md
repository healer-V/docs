# ES2021-ES2023 新特性

## 一、ES2021（ES12）

### 1. String.replaceAll

`replaceAll()` 替换字符串中所有匹配项，无需再使用带 `g` 标志的正则表达式。

::: details replaceAll 示例

```js{4,7}
const text = '苹果很好吃，苹果营养丰富，苹果价格实惠';

// ES2021 之前：需要正则 + g 标志
console.log(text.replace(/苹果/g, '香蕉'));

// ES2021：直接使用 replaceAll
console.log(text.replaceAll('苹果', '香蕉'));
// '香蕉很好吃，香蕉营养丰富，香蕉价格实惠'

// 模板字符串中转义特殊字符
function escapeHtml(str) {
  return str
    .replaceAll('&', '&amp;')
    .replaceAll('<', '&lt;')
    .replaceAll('>', '&gt;')
    .replaceAll('"', '&quot;');
}
console.log(escapeHtml('<div class="test">Hello & World</div>'));
```
:::

### 2. 逻辑赋值运算符

三个逻辑赋值运算符将逻辑运算与赋值合并，使代码更简洁。

| 运算符 | 展开形式 | 触发赋值的条件 |
|--------|----------|----------------|
| `a &&= b` | `a && (a = b)` | `a` 为真值 |
| `a \|\|= b` | `a \|\| (a = b)` | `a` 为假值 |
| `a ??= b` | `a ?? (a = b)` | `a` 为 `null` 或 `undefined` |

::: details 逻辑赋值运算符示例

```js{3,9,15}
// &&= ：当左侧为真值时才赋值（常用于更新已存在的值）
let user = { name: '张三', profile: { bio: '前端工程师' } };
user.profile &&= { ...user.profile, updatedAt: '2026-03-17' };
console.log(user.profile); // { bio: '前端工程师', updatedAt: '2026-03-17' }

// ||= ：当左侧为假值时才赋值（常用于设置默认值，注意 0 和 '' 也是假值）
let settings = { theme: '', fontSize: 0 };
settings.theme    ||= 'light'; // '' 是假值，所以赋值
settings.fontSize ||= 14;      // 0 是假值，所以赋值（有时不符合预期）
console.log(settings); // { theme: 'light', fontSize: 14 }

// ??= ：只有 null/undefined 时才赋值（最安全的默认值设置方式）
let config = { timeout: 0, retries: null };
config.timeout ??= 5000;  // 0 不是 null/undefined，不赋值
config.retries ??= 3;     // null，赋值
console.log(config); // { timeout: 0, retries: 3 }
```
:::

### 3. Promise.any

`Promise.any()` 在任意一个 Promise 成功时 resolve，只有全部失败时才 reject（抛出 `AggregateError`）。

::: details Promise.any 示例

```js{5}
const mirrors = [
  fetch('https://mirror1.example.com/file'),
  fetch('https://mirror2.example.com/file'),
  fetch('https://mirror3.example.com/file'),
];

// 使用最快成功的镜像
Promise.any(mirrors)
  .then((response) => console.log('从最快镜像下载:', response.url))
  .catch((err) => {
    // err 是 AggregateError，包含所有错误
    console.error('所有镜像失败:', err.errors);
  });
```
:::

### 4. WeakRef 与 FinalizationRegistry

`WeakRef` 保持对对象的弱引用，不阻止垃圾回收；`FinalizationRegistry` 在对象被回收后执行回调。

::: warning 谨慎使用
WeakRef 的行为依赖 GC 实现，不同引擎的回收时机不同，不应将其用于关键业务逻辑。
:::

::: details WeakRef 与 FinalizationRegistry 示例

```js
// 弱引用缓存：不阻止对象被回收
class WeakCache {
  #cache = new Map();

  set(key, value) {
    this.#cache.set(key, new WeakRef(value));
  }

  get(key) {
    const ref = this.#cache.get(key);
    if (!ref) return undefined;
    const value = ref.deref(); // 获取引用的对象，已被回收则返回 undefined
    if (!value) this.#cache.delete(key); // 清理失效缓存项
    return value;
  }
}

// 资源释放回调
const registry = new FinalizationRegistry((label) => {
  console.log(`对象 "${label}" 已被垃圾回收`);
});

let obj = { data: '大量数据' };
registry.register(obj, '数据对象'); // 注册回调
obj = null; // 解除引用，允许 GC 回收
```
:::

## 二、ES2022（ES13）

### 1. class 私有字段（#）

使用 `#` 前缀声明真正私有的类字段和方法，外部无法访问或枚举。

::: tip 与 TypeScript private 的区别
TypeScript 的 `private` 仅在编译时检查，运行时仍可访问。ES2022 的 `#` 是运行时强制私有，访问会抛出语法错误。
:::

::: details class 私有字段示例

```js{2,3,16}
class BankAccount {
  #balance = 0;         // 私有字段
  #transactionLog = []; // 私有字段

  constructor(initialBalance) {
    this.#balance = initialBalance;
  }

  deposit(amount) {
    if (amount <= 0) throw new Error('存款金额必须大于0');
    this.#balance += amount;
    this.#log(`存款 ${amount}`);
  }

  // 私有方法
  #log(action) {
    this.#transactionLog.push({ action, time: new Date().toISOString() });
  }

  get balance() {
    return this.#balance;
  }

  // 静态私有字段
  static #instanceCount = 0;
  static getInstanceCount() {
    return BankAccount.#instanceCount;
  }
}

const account = new BankAccount(1000);
account.deposit(500);
console.log(account.balance);  // 1500
console.log(account.#balance); // SyntaxError: 无法从外部访问私有字段
```
:::

### 2. 顶层 await

在 ES Module 的顶层作用域中直接使用 `await`，无需包裹 `async` 函数。

::: warning 仅限 ES Module
顶层 `await` 只在 ESM（`.mjs` 文件或 `type: "module"` 的 `.js` 文件）中有效，CommonJS 不支持。
:::

::: details 顶层 await 示例

```js
// config.mjs —— 顶层 await 加载配置
const response = await fetch('/api/app-config');
export const config = await response.json();

// db.mjs —— 延迟模块初始化
export const db = await createDatabaseConnection({
  host: config.db.host,
  port: config.db.port,
});

// main.mjs —— 导入时会等待上述模块完成初始化
import { config } from './config.mjs';
import { db } from './db.mjs';

console.log('应用配置已加载:', config.appName);
```
:::

### 3. Array.at()

`at()` 支持负数索引访问数组元素，`-1` 表示最后一个元素。

::: details Array.at() 示例

```js
const stack = ['第一帧', '第二帧', '第三帧'];

// 传统方式访问最后一个元素
console.log(stack[stack.length - 1]); // '第三帧'

// 使用 at()
console.log(stack.at(-1));  // '第三帧'
console.log(stack.at(-2));  // '第二帧'
console.log(stack.at(0));   // '第一帧'

// 同样适用于字符串和 TypedArray
const str = 'Hello';
console.log(str.at(-1)); // 'o'
```
:::

### 4. Object.hasOwn()

`Object.hasOwn(obj, key)` 是 `Object.prototype.hasOwnProperty.call(obj, key)` 的简洁替代，更安全。

::: details Object.hasOwn 示例

```js{7}
const obj = Object.create(null); // 没有原型链，无法调用 hasOwnProperty
obj.name = '张三';

// 旧方式：Object.create(null) 的对象调用会报错
// obj.hasOwnProperty('name') // TypeError

// Object.hasOwn 始终安全
console.log(Object.hasOwn(obj, 'name'));    // true
console.log(Object.hasOwn(obj, 'toString')); // false（继承的方法不算）

// 过滤掉原型链上的属性
function filterOwnProps(obj) {
  return Object.fromEntries(
    Object.entries(obj).filter(([key]) => Object.hasOwn(obj, key))
  );
}
```
:::

### 5. Error cause

创建错误时可以通过 `{ cause }` 选项附加原始错误，便于链式错误追踪。

::: details Error cause 示例

```js{6}
async function fetchUserData(userId) {
  try {
    const res = await fetch(`/api/users/${userId}`);
    return await res.json();
  } catch (err) {
    throw new Error(`获取用户 ${userId} 数据失败`, { cause: err });
  }
}

try {
  await fetchUserData(42);
} catch (err) {
  console.error(err.message);        // '获取用户 42 数据失败'
  console.error(err.cause.message);  // 原始网络错误信息
}
```
:::

## 三、ES2023（ES14）

### 1. Array.findLast / findLastIndex

从数组末尾开始查找，是 `find()` 和 `findIndex()` 的反向版本，避免手动 `reverse()` 带来的副作用。

::: details findLast 与 findLastIndex 示例

```js{6,9}
const transactions = [
  { id: 1, type: 'credit', amount: 100 },
  { id: 2, type: 'debit',  amount: 50  },
  { id: 3, type: 'credit', amount: 200 },
  { id: 4, type: 'debit',  amount: 30  },
];

// 找最后一笔收入
const lastCredit = transactions.findLast((t) => t.type === 'credit');
console.log(lastCredit); // { id: 3, type: 'credit', amount: 200 }

// 找最后一笔收入的索引
const lastCreditIndex = transactions.findLastIndex((t) => t.type === 'credit');
console.log(lastCreditIndex); // 2

// 对比 find（从头找）
const firstCredit = transactions.find((t) => t.type === 'credit');
console.log(firstCredit); // { id: 1, type: 'credit', amount: 100 }
```
:::

### 2. Hashbang 语法

支持在脚本文件首行使用 `#!` 指定解释器，使 JS 文件可直接作为可执行脚本运行。

::: details Hashbang 示例

```js
#!/usr/bin/env node
// cli.mjs —— 可直接执行：chmod +x cli.mjs && ./cli.mjs

const args = process.argv.slice(2);
console.log('参数:', args);
```
:::

### 3. WeakMap 支持 Symbol 作为键

ES2023 之前，WeakMap 的键只能是对象。现在支持使用非注册 Symbol（非 `Symbol.for()` 创建的）作为键。

::: details WeakMap Symbol 键示例

```js{4}
const weakMap = new WeakMap();

// 现在可以用 Symbol 作为键
const key = Symbol('私有标识');
const data = { secret: '敏感数据' };

weakMap.set(key, data);
console.log(weakMap.get(key)); // { secret: '敏感数据' }

// 注意：Symbol.for() 创建的全局 Symbol 不允许作为 WeakMap 键
// weakMap.set(Symbol.for('global'), {}); // TypeError
```
:::

### 4. Array 非破坏性方法

ES2023 新增四个非破坏性（返回新数组/对象，不修改原数据）的数组方法：

| 方法 | 说明 | 对应的破坏性方法 |
|------|------|-----------------|
| `toSorted(compareFn)` | 返回排序后的新数组 | `sort()` |
| `toReversed()` | 返回翻转后的新数组 | `reverse()` |
| `toSpliced(start, deleteCount, ...items)` | 返回修改后的新数组 | `splice()` |
| `with(index, value)` | 返回替换指定索引后的新数组 | `arr[index] = value` |

::: details 非破坏性方法示例

```js{4,10,15,20}
const scores = [85, 92, 78, 96, 88];

// toSorted —— 不修改原数组
const sorted = scores.toSorted((a, b) => b - a);
console.log(sorted); // [96, 92, 88, 85, 78]
console.log(scores); // [85, 92, 78, 96, 88]（原数组未变）

// toReversed —— 不修改原数组
const reversed = scores.toReversed();
console.log(reversed); // [88, 96, 78, 92, 85]

// with —— 替换指定位置的值
const updated = scores.with(2, 100);
console.log(updated); // [85, 92, 100, 96, 88]
console.log(scores);  // [85, 92, 78, 96, 88]（原数组未变）

// toSpliced —— 不修改原数组
const spliced = scores.toSpliced(1, 2, 99, 100);
console.log(spliced); // [85, 99, 100, 96, 88]

// 在 React/Vue 等框架中非常实用（状态不可变）
// const newItems = items.toSpliced(index, 1); // 删除元素，不影响原状态
```
:::
