# HTTP

## 一、HTTP协议
::: tip 介绍
HTTP协议（Hypertext Transfer Protocol，超文本传输协议）是互联网上应用最为广泛的协议之一。它是一个客户端-服务器协议，通过请求-响应的方式传送数据。
:::

HTTP协议是基于TCP/IP协议的，它规定了客户端如何向服务器发送请求、服务器如何响应请求、以及客户端如何解析服务器的响应内容。HTTP协议是无状态的，也就是说，对于同一个客户端的多个请求，服务器必须为每个请求都建立新的连接。

HTTP协议的主要特点有：

1. 简单快速：HTTP协议是基于TCP/IP协议的，因此它是一个快速协议。
2. 灵活：HTTP协议允许传输任意类型的数据对象，包括文本、图片、视频、音频、应用程序等。
3. 无连接：HTTP协议是无连接协议，不保持长连接，一次连接只处理一个请求。
4. 无状态：HTTP协议是无状态协议，不对请求和响应之间的通信状态进行保存。

## 二、HTTP请求方法

HTTP协议定义了八种请求方法，它们分别是：

1. GET：请求获取指定的资源。
2. POST：向指定资源提交数据进行处理请求（例如提交表单或者上传文件）。
3. PUT：请求服务器存储一个资源，并用请求内容更新该资源。
4. DELETE：请求服务器删除指定的资源。
5. HEAD：类似于GET请求，只不过返回的响应中没有具体的内容，用于获取报头。
6. OPTIONS：请求获取由Request-URI所指定资源支持的方法。
7. TRACE：回显服务器收到的请求，主要用于测试或诊断。


## 三、HTTP状态码

HTTP协议定义了五种状态码，它们分别是：

1. 1xx：指示信息——表示请求已接收，继续处理。
2. 2xx：成功——表示请求已被成功接收、理解、并接受。
3. 3xx：重定向——要完成请求必须进行更进一步的操作。
4. 4xx：客户端错误——请求有语法错误或请求无法实现。
5. 5xx：服务器错误——服务器未能实现合法的请求。

## 四、HTTP首部字段
::: tip 介绍
HTTP首部字段（Header Field）是HTTP协议的组成部分，它是由冒号(:)分隔的键值对，用来提供额外的请求或响应信息。
HTTP协议定义了很多首部字段，它们可以帮助客户端和服务器传递附加信息。常用的HTTP首部字段有：
1. Cache-Control：控制缓存的行为。
2. Connection：允许客户端和服务器指定与连接相关的选项。
3. Content-Encoding：对实体内容进行编码。
4. Content-Type：指示实体内容的类型和字符编码。
5. Date：创建响应的日期和时间。
6. Expires：响应过期的日期和时间。
7. Host：请求的主机名和端口号。
8. Last-Modified：请求资源的最后修改日期和时间。
9. Location：请求资源的新位置。
10. Pragma：实现特定的功能，例如no-cache。
11. Server：服务器软件的信息。
12. Set-Cookie：设置HTTP cookie。   
:::
## 五、OSI 7层模型
::: tip 介绍
OSI（Open Systems Interconnection，开放式系统互联）七层模型是网络通信的模型，它将计算机网络分为七层，分别为物理层、数据链路层、网络层、传输层、会话层、表示层、应用层。

1. 物理层：物理层的作用是实现比特流的透明传输，它定义了物理连接的硬件特性，如双绞线、同轴电缆、光纤等。
2. 数据链路层：数据链路层的作用是实现数据包的透明传输，它定义了如何将数据包从一台计算机发送到另一台计算机。
3. 网络层：网络层的作用是实现从源到目的地址的路由选择，它定义了网络互连的规则，如IP协议、ICMP协议、ARP协议等。
4. 传输层：传输层的作用是实现端到端的可靠数据传输，它定义了传输层协议，如TCP协议、UDP协议等。
5. 会话层：会话层的作用是管理会话，它定义了如何建立、维护和终止会话。
6. 表示层：表示层的作用是对数据进行翻译、加密和解密，它定义了数据格式、压缩、加密等。
7. 应用层：应用层的作用是为用户提供各种网络服务，它定义了各种网络应用，如WWW、FTP、SMTP、DNS等。
:::
