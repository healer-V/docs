# Vue2
## 一、Vue2 基础
### 1.1、 Vue2 简介
::: tip vue2是什么
- 1. 一套用于构建用户界面的`渐进式`JavaScript 框架。
- 2. Vue 被设计为可以`自底向上逐层应用`。
- 3. `易用`：Vue 的核心库只关注视图层，易于上手。
- 4. `生态系统丰富`：Vue 生态系统提供了大量的插件、工具和库，便于与第三方库或既有项目整合。
- 5. `性能高效`：Vue 相比于其他 Virtual DOM 库和框架，有着出色的性能表现。
- 6. `轻量级`: Vue 的核心库只有 7kb 大小。

:::

### 1.2、 Vue2 语法特性
::: tip 
- 1. `组件化`：基于组件的开发方式，允许开发者使用自定义组件封装可重用代码。
- 2. `双向数据绑定`：Vue 提供完整的双向数据绑定系统，从而实现 View 和 Model 之间的同步更新。
- 3. `响应式`：Vue 实现了响应式系统，能够自动追踪依赖关系并在数据变化时重新渲染组件。
:::

### 1.3、 MVVM 模式
::: tip 
- 1. `Model`：Vue 实例的数据对象。
- 2. `View`：Vue 实例的模板，即将数据渲染成视图的 HTML。
- 3. `ViewModel`：Vue 实例的视图模型，连接 View 和 Model。
:::

## 二、Vue2语法
### 2.1、 Vue2指令
::: tip 
- 1. `v-text`：绑定文本内容。
- 2. `v-html`：绑定 HTML 内容。
- 3. `v-model`：实现表单输入和数据双向绑定。
- 4. `v-if`：条件渲染。
- 5. `v-show`：条件展示。
- 6. `v-for`：循环渲染。
- 7. `v-on`：绑定事件。
- 8. `v-bind`：绑定属性。
- 9. `v-cloak`：延迟显示未编译的模板内容。
:::
### 2.2、插值表达式
#### 2.2.1、 作用
::: tip  
- 1. `{{ }}`：双大括号，用于绑定数据。
:::
#### 2.2.2、 示例
```html
<div id="app">
  <p>{{ message }}</p>
</div>

<script>
  var app = new Vue({
    el: '#app',

    }
```

### 2.3、 指令
::: tip 
- 1. `v-text`：绑定文本内容。
- 2. `v-html`：绑定 HTML 内容。
- 3. `v-model`：实现表单输入和数据双向绑定。
- 4. `v-if`：条件渲染。
- 5. `v-show`：条件展示。
- 6. `v-for`：循环渲染。
- 7. `v-on`：绑定事件, 简写 `@`。
- 8. `v-bind`：绑定属性, 简写 `:`。
- 9. `v-pre`：跳过当前节点的编译过程。
- 10. `v-once`：只渲染元素和组件一次。
- 11. `v-cloak`：延迟显示未编译的模板内容。
:::

### 2.3、自定义指令 
>- 全局指令：指令可以全局注册，所有组件实例均可使用。
>- 局部指令：指令只能在当前组件实例中使用。
#### 2.3.1、 全局指令
::: tip 
- 1. `Vue.directive`：注册全局指令。
- 2. `el`：指令所在元素。
- 3. `binding`：指令绑定的数据对象。
- 4. `vnode`：Vue 编译生成的虚拟节点。
- 5. `oldVnode`：上一个虚拟节点。
::: 
示例：
```js
// 注册全局指令
Vue.directive('my-directive', {
  bind: function(el, binding, vnode, oldVnode) {
    // 指令绑定时执行的函数
  },
  update: function(el, binding, vnode, oldVnode) {
    // 指令更新时执行的函数
  },
  componentUpdated: function(el, binding, vnode, oldVnode) {
    // 指令所在组件的更新完毕时执行的函数
  },
  unbind: function(el, binding, vnode, oldVnode) {
    // 指令解绑时执行的函数
  }
})
```
#### 2.3.2、 局部指令
::: tip 
- 1. `directives`：注册局部指令。
- 2. `bind`：指令绑定时执行的函数。
- 3. `update`：指令更新时执行的函数。
- 4. `componentUpdated`：指令所在组件的更新完毕时执行的函数。
- 5. `unbind`：指令解绑时执行的函数。
::: 
示例：
```js
// 注册局部指令
var vm = new Vue({
  el: '#app',
  data: {
    message: 'Hello Vue!'
  },
  directives: {
    'focus': {
      bind: function(el, binding) {
        el.focus()
      }
    }
  }
})
```

### 2.5、插槽 
::: tip 作用
1. 实现组件的内容分发。
  - 内容定制 ：内部部分内容可以由外部使用者传入，从而使组件具有更高的灵活性和复用性
  - 分离逻辑与内容：将组件的逻辑和展示内容分离开，使得组件更加容易维护和扩展。
2. 支持组件的布局定制。
  - 灵活布局：使用者能够自定义组件的布局，从而调整组件内部元素的排列方式。
  - 适配不同场景：不同的媒体查询条件下，通过插槽能够轻松地适配不同的屏幕尺寸和设备类型
3. 实现组件的可扩展性。
  - 插件化开发：插槽使得组件可以像插件一样进行扩展。
  - 组件组合：多个组件可以通过插槽相互嵌套和通信，形成更高级、更复杂的组件结构，从而实现更丰富的页面功能。
::: 
#### 2.5.1、默认插槽
##### 子组件中：
```html
<!-- MyBox.vue -->
<template>
  <div class="box">
    <slot>
      <!-- 这里可以设置插槽的默认内容 -->
      这是默认内容，当没有插入其他内容时会显示。
    </slot>
  </div>
</template>

<script>
export default {
  name: 'MyBox'
}
</script>
```
##### 父组件中：
```html
<template>
  <div>
    <my-box>
      <p>这里是插槽内容</p>
    </my-box>
  </div>
</template>

<script>
import MyBox from './MyBox.vue'
export default {
  name: 'App',
  components: {
    MyBox
  }
}
</script>
```
#### 2.5.2、具名插槽
> v-slot指令有缩写形式`#`，使用缩写语法可以更简洁地指定具名插槽
##### 子组件中：
```html
<!-- MyLayout -->
<template>
  <div class="layout">
    <!-- 定义名为header的具名插槽，设置默认内容 -->
    <slot name="header"><h2>默认头部内容</h2></slot>
    <!-- 定义名为content的具名插槽，设置默认内容 -->
    <slot name="content"><p>默认主体内容</p></slot>
    <!-- 定义名为footer的具名插槽，设置默认内容 -->
    <slot name="footer"><p>默认底部内容</p></slot>
  </div>
</template>

<script>
export default {
  name: 'MyLayout'
}
</script>
```
##### 父组件中：
```html
<template>
  <div>
    <h1>使用具名插槽 - 缩写语法</h1>
    <MyLayout>
      <!-- 插入到header具名插槽中，使用缩写语法 -->
      <template #header>
        <h2>这是头部内容</h2>
      </template>
      <!-- 插入到content具名插槽中，使用缩写语法 -->
      <template #content>
        <p>这是主体内容</p>
      </template>
      <!-- 插入到footer具名插槽中，使用缩写语法 -->
      <template #footer>
        <p>这是底部内容</p>
      </template>
    </MyLayout>
  </div>
</template>

<script>
import MyLayout from './MyLayout.vue'

export default {
  name: 'App',
  components: {
    MyLayout
  }
}
</script>
```

#### 2.5.3、作用域插槽

> 作用域插槽可以让我们将父组件的数据和方法传递给子组件，从而实现更灵活的组件间通信。

##### 子组件中：
```html
<template>
  <ul>
    <li v-ide="item in items">
      <!-- 通过slot-scope属性绑定作用域数据 -->
      <slot :item="item" :index="index">{{ item.name }}</slot>
    </li>
  </ul>
</template>

<script>
export default {
    name: 'ItemList',
    data() {
        return {
            items: [
                { id: 1, name: 'Item 1' },
                { id: 2, name: 'Item 2' },
                { id: 3, name: 'Item 3' },
            ]
        }
    }
}
</script>
```

##### 父组件中：
```html
<template>
  <div>
    <h1>使用作用域插槽 - 缩写语法</h1>
    <ItemList>
      <template #default="slotProps">
        <!-- 访问作用域数据 -->
        <span>{{ slotProps.index + 1 }}. {{ slotProps.item.name }}</span>
      </template>
    <ItemList>
  </div>
</template>

<script>
import ItemList from './ItemList.vue'

export default {
  name: 'App',
  components: {
    ItemList
  }
}
</script>
```

### 2.6、动态组件
> 动态组件可以让我们在运行时根据条件渲染不同的组件。

#### 2.6.1、 基本用法

```html
<template>
  <div>
    <component :is="currentView"></component>
    <button @click="changeView">切换视图</button>
  </div>
</template>

<script>
export default {
  name: 'App',
  components: {
    Child1: { template: '<div>子组件1</div>' },
    Child2: { template: '<div>子组件2</div>' }
  },
  data() {
    return {
      currentView: 'Child1'
    }
  },
  methods: {
    changeView() {
      this.currentView = this.currentView === 'Child1' ? 'Child2' : 'Child1'
    }
  }
}
</script>
```

#### 2.6.2、 异步组件

> 异步组件可以实现组件的按需加载，从而提升应用的性能。

```html
<template>
  <div>
    <component :is="currentView"></component>
    <button @click="changeView">切换视图</button>
  </div>
</template>

<script>
export default {
  name: 'App',
  components: {
    Child1: () => import('./Child1.vue'),
    Child2: () => import('./Child2.vue')
  },
  data() {
    return {
      currentView: 'Child1'
    }
  },
  methods: {
    changeView() {
      this.currentView = this.currentView === 'Child1' ? 'Child2' : 'Child1'
    }
  }
}
</script>
```


## 三、Vue2 传值
### 3.1、父子组件传值
#### 3.1.1、 父传子
::: tip 
- 1. 父组件通过`props`属性向子组件传递数据。
- 2. 子组件通过`this.$emit()`方法触发一个事件，并将数据作为参数传递给父组件。
::: 
示例：
```html
<!-- 父组件 -->
<template>
  <div>
    <child :msg="message"></child>
  </div>
</template>

<script>
import Child from './Child.vue'
export default {
  name: 'Parent',
  components: {
    Child
  },
  data() {
    return {
      message: 'Hello Vue!'
    }
  }
}
</script>
```
```html
<!-- 子组件 -->
<template>
  <div>
    <p>{{ msg }}</p>
    <button @click="emitMessage">触发事件</button>
  </div>
</template>

<script>
export default {
  name: 'Child',
  props: ['msg'],
  methods: {
    emitMessage() {
      this.$emit('update:msg', 'Hello Vue2!')
    }
  }
}
</script>
```
#### 3.1.2、 子传父
::: tip 
- 1. 子组件通过`$emit()`方法触发一个事件，并将数据作为参数传递给父组件。
- 2. 父组件通过`v-on`指令监听子组件的事件，并将数据作为属性绑定到父组件的`data`对象上。
::: 
示例：
```html
<!-- 父组件 -->
<template>
  <div>
    <child @update:msg="message = $event"></child>
    <p>{{ message }}</p>
  </div>
</template>

<script>
import Child from './Child.vue'
export default {
  name: 'Parent',
  components: {
    Child
  },
  data() {
    return {
      message: ''
    }
  }
}
</script>
```
```html
<!-- 子组件 -->
<template>
  <div>
    <p>{{ msg }}</p>
    <button @click="emitMessage">触发事件</button>
  </div>
</template>

<script>
export default {
  name: 'Child',
  props: ['msg'],
  methods: {
    emitMessage() {
      this.$emit('update:msg', 'Hello Vue2!')
    }
  }
}
</script>
```

- 1. 兄弟组件之间通过`props`属性进行通信。
- 2. 父组件通过`props`属性向子组件传递数据，子组件通过`this.$emit()`方法触发一个事件，并将数据作为参数传递给父组件。
- 3. 父组件通过`v-on`指令监听子组件的事件，并将数据作为属性绑定到父组件的`data`对象上。

### 3.3、跨级组件传值
::: tip 
- 1. 跨级组件之间通过`provide`和`inject`进行通信。
- 2. 父组件通过`provide`方法提供数据，子组件通过`inject`方法注入数据。
- 3. 父组件通过`v-on`指令监听子组件的事件，并将数据作为属性绑定到父组件的`data`对象上。
::: 
示例：
```html
<!-- 父组件 -->
<template>
  <div>
    <child :msg="message"></child>
    <p>{{ message }}</p>
  </div>
</template>

<script>
import Child from './Child.vue'
export default {
  name: 'Parent',
  components: {
    Child
  },
  data() {
    return {
      message: ''
    }
  },
  provide() {
    return {
      message: this.message
    }
  }
}
</script>
```
```html
<!-- 子组件 -->
<template>
  <div>
    <p>{{ msg }}</p>
    <button @click="emitMessage">触发事件</button>
  </div>
</template>

<script>
export default {
  name: 'Child',
  props: ['msg'],
  inject: ['message'],
  methods: {
    emitMessage() {
      this.$emit('update:msg', 'Hello Vue2!')
    }
  }
}
</script>
``` 
### 3.4、Vuex 状态管理
::: tip 
- 1. Vuex 是一个专为 Vue.js 应用程序开发的状态管理模式。
- 2. Vuex 采用集中式存储管理应用的所有组件的状态，并以相应的规则保证状态以一种可预测的方式发生变化。
- 3. Vuex 的状态存储是响应式的。
- 4. Vuex 包含了模块化、插件化、工具化的概念，使得它成为一个灵活的状态管理方案。
::: 
示例：
```html
<!-- 父组件 -->
<template>
  <div>
    <child :msg="message"></child>
    <p>{{ message }}</p>
  </div>
</template>
<script>
import Child from './Child.vue'
import { mapState } from 'vuex'
import { store } from '../store'

export default {
  name: 'Parent',
  components: {
    Child
  },
  computed: {
   ...mapState(['message'])
  },
  created() {
    this.$store.dispatch('getMessage')
  }
}
</script>
```
```html
<!-- 子组件 -->
<template>
  <div>
    <p>{{ msg }}</p>
    <button @click="emitMessage">触发事件</button>
  </div>
</template>

<script>
export default {
  name: 'Child',
  props: ['msg'],
  methods: {
    emitMessage() {
      this.$emit('update:msg', 'Hello Vue2!')
    }
  }
}
</script>
``` 
```js
// store.js
import Vue from 'vue'
import Vuex from 'vuex'

Vue.use(Vuex)

export const store = new Vuex.Store({
  state: {
    message: 'Hello Vue!'
  },
  mutations: {
    updateMessage(state, message) {
      state.message = message
    }
  },
  actions: {
    getMessage({ commit }) {
      commit('updateMessage', 'Hello Vue2!')
    }
  }
})
``` 
### 3.5、自定义事件
::: tip 
- 1. 自定义事件是一种触发自定义行为的机制。
- 2. 自定义事件可以绑定在元素、组件或根实例上。
- 3. 自定义事件可以触发任意 JavaScript 代码。
- 4. 自定义事件可以传递任意数据。
::: 
示例：
```html
<!-- 父组件 -->
<template>
  <div>
    <child :msg="message"></child>
    <p>{{ message }}</p>
  </div>
</template>

<script>
import Child from './Child.vue'
export default {
  name: 'Parent',
  components: {
    Child
  },
  data() {
    return {
      message: ''
    }
  },
  created() {
    this.$on('updateMessage', this.updateMessage)
  },
  methods: {
    updateMessage(message) {
      this.message = message
    }
  }
}
</script>
```
```html
<!-- 子组件 -->
<template>
  <div>
    <p>{{ msg }}</p>
    <button @click="emitMessage">触发事件</button>
  </div>
</template>

<script>
export default {
  name: 'Child',
  props: ['msg'],
  methods: {
    emitMessage() {
      this.$emit('updateMessage', 'Hello Vue2!')
    }
  }
}
</script>
``` 

### 3.6、路由传参
::: tip 
- 1. 路由传参是指在路由中通过路径参数的方式向组件传递数据。
- 2. 路由传参可以传递任意类型的数据，包括字符串、数字、布尔值、数组、对象等。
- 3. 路由传参可以用在 URL 中，也可以用在 query 参数中。
- 4. 路由传参可以用在动态路由中。
::: 
示例：
```html
<!-- 父组件 -->
<template>
  <div>
    <router-view></router-view>
  </div>
</template>

<script>
export default {
  name: 'Parent'
}
</script>
```
```html
<!-- 子组件 -->
<template>
  <div>
    <p>{{ msg }}</p>
  </div>
</template>

<script>
export default {
  name: 'Child',
  props: ['msg'],
  created() {
    console.log(this.$route.params.id)
  }
}
</script>
``` 
```js
// router.js
import Vue from 'vue'
import Router from 'vue-router'

Vue.use(Router)

export default new Router({
``` 

## 四、Vue2 生命周期
::: tip 
- 1. `beforeCreate`：实例创建之前。
- 2. `created`：实例创建之后。
- 3. `beforeMount`：实例挂载之前。
- 4. `mounted`：实例挂载之后。
- 5. `beforeUpdate`：数据更新之前。
- 6. `updated`：数据更新之后。
- 7. `beforeDestroy`：实例销毁之前。
- 8. `destroyed`：实例销毁之后。
::: 
示例：
```html
<template>
  <div>
    <p>{{ message }}</p>
    <button @click="changeMessage">改变消息</button>
  </div>
</template>

<script>
export default {
  name: 'App',
  data() {
    return {
      message: 'Hello Vue!'
    }
  },
  methods: {
    changeMessage() {
      this.message = 'Hello Vue2!'
    }
  },
  created() {
    console.log('created')
  },
  mounted() {
    console.log('mounted')
  },
  updated() {
    console.log('updated')
  },
  beforeDestroy() {
    console.log('beforeDestroy')
  },
}
</script>
```

## 六、Vue2 路由
### 6.1、Vue2 路由介绍
::: tip 
- 1. 路由是指将 URL 与特定组件进行映射的过程。
- 2. 路由可以帮助我们实现 URL 与视图的映射，同时也提供了导航功能，让用户在不同的视图之间进行切换。 
- 3. Vue Router 是 Vue.js 官方的路由管理器。
- 4. Vue Router 是一个轻量级的路由管理器，它和 Vue.js 的核心库没有任何依赖。
- 5. Vue Router 提供了许多功能，如：动态路由、嵌套路由、命名视图、路由过渡效果、路由懒加载等。
::: 
### 6.2、Vue2 路由安装
```
npm install vue-router
```
### 6.3、Vue2 路由基本使用

```html
      name: 'About',

  ]
```
