# Vue2
## 一、Vue2 基础
### 1、 Vue2 简介
::: tip vue2是什么
- 1. 一套用于构建用户界面的`渐进式`JavaScript 框架。
- 2. Vue 被设计为可以`自底向上逐层应用`。
- 3. `易用`：Vue 的核心库只关注视图层，易于上手。
- 4. `生态系统丰富`：Vue 生态系统提供了大量的插件、工具和库，便于与第三方库或既有项目整合。
- 5. `性能高效`：Vue 相比于其他 Virtual DOM 库和框架，有着出色的性能表现。
- 6. `轻量级`: Vue 的核心库只有 7kb 大小。

:::

### 2、 Vue2 语法特性
::: tip 
- 1. `组件化`：基于组件的开发方式，允许开发者使用自定义组件封装可重用代码。
- 2. `双向数据绑定`：Vue 提供完整的双向数据绑定系统，从而实现 View 和 Model 之间的同步更新。
- 3. `响应式`：Vue 实现了响应式系统，能够自动追踪依赖关系并在数据变化时重新渲染组件。
:::

### 3、 MVVM 模式
::: tip 
- 1. `Model`：Vue 实例的数据对象。
- 2. `View`：Vue 实例的模板，即将数据渲染成视图的 HTML。
- 3. `ViewModel`：Vue 实例的视图模型，连接 View 和 Model。
:::

## 二、Vue2 语法
### 1、Vue2 指令
::: tip 
- 1. `v-text`：绑定文本内容。
- 2. `v-html`：绑定 HTML 内容。
- 3. `v-model`：实现表单输入和数据双向绑定。
- 4. `v-if`：条件渲染。
- 5. `v-show`：条件展示。
- 6. `v-for`：循环渲染。
- 7. `v-on`：绑定事件。
- 8. `v-bind`：绑定属性。
- 9. `v-cloak`：延迟显示未编译的模板内容。
:::
### 2、插值表达式
::: tip  
- 1. `{ {` `} }`：双大括号，用于绑定数据。
:::
**示例**
```vue
<div id="app">
  <p>{{ message }}</p>
</div>

<script>
  var app = new Vue({
    el: '#app',
    data: {
      message: 'Hello Vue!'
    }
  })
</script>
```

### 3、自定义指令 
>[!tip]
>- 全局指令：指令可以全局注册，所有组件实例均可使用。
>- 局部指令：指令只能在当前组件实例中使用。
#### 3.1、 全局指令
::: tip 
- 1. `Vue.directive`：注册全局指令。
- 2. `el`：指令所在元素。
- 3. `binding`：指令绑定的数据对象。
- 4. `vnode`：Vue 编译生成的虚拟节点。
- 5. `oldVnode`：上一个虚拟节点。
::: 
示例：
```js
// 注册全局指令
Vue.directive('my-directive', {
  bind: function(el, binding, vnode, oldVnode) {
    // 指令绑定时执行的函数
  },
  update: function(el, binding, vnode, oldVnode) {
    // 指令更新时执行的函数
  },
  componentUpdated: function(el, binding, vnode, oldVnode) {
    // 指令所在组件的更新完毕时执行的函数
  },
  unbind: function(el, binding, vnode, oldVnode) {
    // 指令解绑时执行的函数
  }
})
```
#### 3.2、 局部指令
::: tip 
- 1. `directives`：注册局部指令。
- 2. `bind`：指令绑定时执行的函数。
- 3. `update`：指令更新时执行的函数。
- 4. `componentUpdated`：指令所在组件的更新完毕时执行的函数。
- 5. `unbind`：指令解绑时执行的函数。
::: 
示例：
```js
// 注册局部指令
var vm = new Vue({
  el: '#app',
  data: {
    message: 'Hello Vue!'
  },
  directives: {
    'focus': {
      bind: function(el, binding) {
        el.focus()
      }
    }
  }
})
```

### 5、插槽 
::: tip 作用
1. 实现组件的内容分发。
  - 内容定制 ：内部部分内容可以由外部使用者传入，从而使组件具有更高的灵活性和复用性
  - 分离逻辑与内容：将组件的逻辑和展示内容分离开，使得组件更加容易维护和扩展。
2. 支持组件的布局定制。
  - 灵活布局：使用者能够自定义组件的布局，从而调整组件内部元素的排列方式。
  - 适配不同场景：不同的媒体查询条件下，通过插槽能够轻松地适配不同的屏幕尺寸和设备类型
3. 实现组件的可扩展性。
  - 插件化开发：插槽使得组件可以像插件一样进行扩展。
  - 组件组合：多个组件可以通过插槽相互嵌套和通信，形成更高级、更复杂的组件结构，从而实现更丰富的页面功能。
::: 
#### 5.1、默认插槽
>[!tip]
>- 默认插槽：没有被指定名字的插槽，会被渲染为默认插槽。
>- 使用：
>   - 在父组件中，使用`<slot>`标签作为默认插槽的占位符；
>   - 在子组件中使用`slot`属性指定默认插槽的名字。

::: details 子组件
```vue
<!-- MyBox.vue -->
<template>
  <div class="box">
    <slot>
      <!-- 这里可以设置插槽的默认内容 -->
      这是默认内容，当没有插入其他内容时会显示。
    </slot>
  </div>
</template>

<script>
export default {
  name: 'MyBox'
}
</script>
```
:::

::: details 父组件
```vue
<template>
  <div>
    <my-box>
      <p>这里是插槽内容</p>
    </my-box>
  </div>
</template>

<script>
import MyBox from './MyBox.vue'
export default {
  name: 'App',
  components: {
    MyBox
  }
}
</script>
```
:::

#### 5.3、作用域插槽
>[!tip] 作用域插槽
>- 作用域插槽：可以让我们将父组件的数据和方法传递给子组件，从而实现更灵活的组件间通信。
>- 使用：
>   - 在父组件中，使用`slot-scope`属性定义作用域插槽；
>   - 在子组件中，使用`slot-scope`属性绑定作用域数据。

:::details 子组件
```vue
<template>
  <ul>
    <li v-ide="item in items">
      <!-- 通过slot-scope属性绑定作用域数据 -->
      <slot :item="item" :index="index">{{ item.name }}</slot>
    </li>
  </ul>
</template>

<script>
export default {
    name: 'ItemList',
    data() {
        return {
            items: [
                { id: 1, name: 'Item 1' },
                { id: 2, name: 'Item 2' },
                { id: 3, name: 'Item 3' },
            ]
        }
    }
}
</script>
```
:::

::: details 父组件
```vue
<template>
  <div>
    <h1>使用作用域插槽 - 缩写语法</h1>
    <ItemList>
      <template #default="slotProps">
        <!-- 访问作用域数据 -->
        <span>{{ slotProps.index + 1 }}. {{ slotProps.item.name }}</span>
      </template>
    <ItemList>
  </div>
</template>

<script>
import ItemList from './ItemList.vue'

export default {
  name: 'App',
  components: {
    ItemList
  }
}
</script>
```

### 6、动态组件
>[!tip]动态组件
>- 是一种在运行时动态切换不同组件的技术，通过 `<component>` 内置组件和 is 属性实现。
>- ` <component>` 元素
>   - Vue 的内置组件，作为动态组件的容器占位符。
>- `is` 属性
>   - 决定当前渲染哪个组件，值可以是：
>   - 组件选项对象（直接导入的组件对象）
>   - 已注册的组件名（字符串）
>   - 异步组件（defineAsyncComponent）

#### 6.1、 基本用法
::: details 动态组件 Vue2版本
```vue 
<template>
  <div>
    <component :is="currentView"></component>
    <button @click="changeView">切换视图</button>
  </div>
</template>

<script>
export default {
  name: 'App',
  components: {
    Child1: { template: '<div>子组件1</div>' },
    Child2: { template: '<div>子组件2</div>' }
  },
  data() {
    return {
      currentView: 'Child1'
    }
  },
  methods: {
    changeView() {
      this.currentView = this.currentView === 'Child1' ? 'Child2' : 'Child1'
    }
  }
}
</script>
```
:::
::: details 动态组件 Vue3版本
```vue 
<template>
  <component :is="currentComponent"></component>
</template>

<script setup>
import ComponentA from './ComponentA.vue'
import ComponentB from './ComponentB.vue'
import { ref } from 'vue'

const currentComponent = ref('ComponentA') // 默认显示 ComponentA
</script>
```
:::


#### 6.2、异步组件
>[!tip]
>-  异步组件可以实现组件的按需加载，从而提升应用的性能。


## 三、组件通信
### 1、父子组件传值
#### 1.1、 父传子
::: tip 
- 1. 父组件通过`props`属性向子组件传递数据。
- 2. 子组件通过`this.$emit()`方法触发一个事件，并将数据作为参数传递给父组件。
::: 
示例：
::: details 父组件
```vue
<!-- 父组件 -->
<template>
    <child :msg="message"></child>
</template>

<script>
import Child from './Child.vue'
export default {
  data() {
    return {
      message: 'Hello Vue!'
    }
  }
}
</script>
```
:::


::: details 子组件
```vue
<!-- 子组件 -->
<template>
  <div>
    <p>{{ msg }}</p>
    <button @click="emitMessage">触发事件</button>
  </div>
</template>

<script>
export default {
  name: 'Child',
  props: ['msg'],
  methods: {
    emitMessage() {
      this.$emit('update:msg', 'Hello Vue2!')
    }
  }
}
</script>
```
:::

#### 1.2、 子传父
::: tip 
- 1. 子组件通过`$emit()`方法触发一个事件，并将数据作为参数传递给父组件。
- 2. 父组件通过`v-on`指令监听子组件的事件，并将数据作为属性绑定到父组件的`data`对象上。
::: 

**示例：**

::: details 父组件
```vue
<!-- 父组件 -->
<template>
  <div>
    <child @update:msg="message = $event"></child>
    <p>{{ message }}</p>
  </div>
</template>

<script>
export default {
  data() {
    return {
      message: ''
    }
  }
}
</script>
```
:::

::: details 子组件
```vue
<!-- 子组件 -->
<template>
  <div>
    <p>{{ msg }}</p>
    <button @click="emitMessage">触发事件</button>
  </div>
</template>

<script>
export default {
  name: 'Child',
  props: ['msg'],
  methods: {
    emitMessage() {
      this.$emit('update:msg', 'Hello Vue2!')
    }
  }
}
</script>
```
:::

### 2、兄弟组件传值
::: tip 兄弟组件通信说明
- **兄弟组件**：指拥有同一个父组件的两个子组件，它们之间不能直接通信。
- **通信方式**：兄弟组件之间需要通过共同的父组件作为中介进行通信。
- **实现原理**：
  1. 子组件1 通过 `$emit()` 触发事件，将数据传递给父组件
  2. 父组件通过 `v-on` 监听子组件1 的事件，更新父组件的数据
  3. 父组件通过 `props` 将更新后的数据传递给子组件2
  4. 这样就实现了子组件1 向子组件2 传递数据
- **适用场景**：两个兄弟组件需要共享数据或进行数据同步
:::

**示例:**

:::details 父组件 - 数据桥梁
```vue
<!-- 父组件 -->
<template>
  <div>
    <child1 @send-message="handleMessage"></child1>
    <child2 :message="sharedMessage"></child2>
  </div>
</template>

<script>
import Child1 from './Child1.vue'
import Child2 from './Child2.vue'

export default {
  name: 'Parent',
  components: {
    Child1,
    Child2
  },
  data() {
    return {
      sharedMessage: '' // 共享数据
    }
  },
  methods: {
    // 监听子组件1 的事件，更新共享数据
    handleMessage(msg) {
      this.sharedMessage = msg
    }
  }
}
</script>
```
:::

:::details 子组件1 - 发送数据
```vue
<!-- 子组件1 - 发送数据 -->
<template>
  <div>
    <h3>子组件1</h3>
    <button @click="sendToSibling">向兄弟组件发送消息</button>
  </div>
</template>

<script>
export default {
  name: 'Child1',
  methods: {
    sendToSibling() {
      // 触发事件，将数据传递给父组件
      this.$emit('send-message', '这是来自子组件1的消息')
    }
  }
}
</script>
```
:::

:::details 子组件2 - 接收数据
```vue
<!-- 子组件2 - 接收数据 -->
<template>
  <div>
    <h3>子组件2</h3>
    <p>接收到的消息：{{ message }}</p>
  </div>
</template>

<script>
export default {
  name: 'Child2',
  props: {
    message: {
      type: String,
      default: ''
    }
  }
}
</script>
```
:::


:::warning 注意事项
- 兄弟组件不能直接通过 `props` 通信，必须通过父组件作为中介
- 父组件需要维护共享状态，监听子组件事件并更新数据
- 如果兄弟组件通信频繁，可以考虑使用事件总线（EventBus）或状态管理工具（Vuex）
::: 

### 3、跨级组件传值
::: tip 
- 1. 跨级组件之间通过`provide`和`inject`进行通信。
- 2. 父组件通过`provide`方法提供数据，子组件通过`inject`方法注入数据。
- 3. 父组件通过`v-on`指令监听子组件的事件，并将数据作为属性绑定到父组件的`data`对象上。
::: 
示例：
::: details 父组件
```vue
<!-- 父组件 -->
<template>
  <div>
    <child :msg="message"></child>
    <p>{{ message }}</p>
  </div>
</template>

<script>
import Child from './Child.vue'
export default {
  name: 'Parent',
  components: {
    Child
  },
  data() {
    return {
      message: ''
    }
  },
  provide() {
    return {
      message: this.message
    }
  }
}
</script>
```
:::

::: details 子组件
```vue
<!-- 子组件 -->
<template>
  <div>
    <p>{{ msg }}</p>
    <button @click="emitMessage">触发事件</button>
  </div>
</template>

<script>
export default {
  name: 'Child',
  props: ['msg'],
  inject: ['message'],
  methods: {
    emitMessage() {
      this.$emit('update:msg', 'Hello Vue2!')
    }
  }
}
</script>
``` 
:::
### 4、Vuex 状态管理
::: tip 
- 1. Vuex 是一个专为 Vue.js 应用程序开发的状态管理模式。
- 2. Vuex 采用集中式存储管理应用的所有组件的状态，并以相应的规则保证状态以一种可预测的方式发生变化。
- 3. Vuex 的状态存储是响应式的。
- 4. Vuex 包含了模块化、插件化、工具化的概念，使得它成为一个灵活的状态管理方案。
::: 
示例：
::: details 父组件
```vue
<!-- 父组件 -->
<template>
  <div>
    <child :msg="message"></child>
    <p>{{ message }}</p>
  </div>
</template>
<script>
import Child from './Child.vue'
import { mapState } from 'vuex'
import { store } from '../store'

export default {
  name: 'Parent',
  components: {
    Child
  },
  computed: {
   ...mapState(['message'])
  },
  created() {
    this.$store.dispatch('getMessage')
  }
}
</script>
```
:::


::: details 子组件
```vue
<!-- 子组件 -->
<template>
  <div>
    <p>{{ msg }}</p>
    <button @click="emitMessage">触发事件</button>
  </div>
</template>

<script>
export default {
  name: 'Child',
  props: ['msg'],
  methods: {
    emitMessage() {
      this.$emit('update:msg', 'Hello Vue2!')
    }
  }
}
</script>
``` 
::: 

::: details store.js
```js
// store.js
import Vue from 'vue'
import Vuex from 'vuex'

Vue.use(Vuex)

export const store = new Vuex.Store({
  state: {
    message: 'Hello Vue!'
  },
  mutations: {
    updateMessage(state, message) {
      state.message = message
    }
  },
  actions: {
    getMessage({ commit }) {
      commit('updateMessage', 'Hello Vue2!')
    }
  }
})
```

### 5、自定义事件
::: tip 
- 1. 自定义事件是一种触发自定义行为的机制。
- 2. 自定义事件可以绑定在元素、组件或根实例上。
- 3. 自定义事件可以触发任意 JavaScript 代码。
- 4. 自定义事件可以传递任意数据。
::: 
示例：
```vue
<!-- 父组件 -->
<template>
  <div>
    <child :msg="message"></child>
    <p>{{ message }}</p>
  </div>
</template>

<script>
import Child from './Child.vue'
export default {
  name: 'Parent',

  },

  }
}
```

## 六、Vue2 路由
### 1、Vue2 路由介绍
::: tip 
- 1. 路由是指将 URL 与特定组件进行映射的过程。
- 2. 路由可以帮助我们实现 URL 与视图的映射，同时也提供了导航功能，让用户在不同的视图之间进行切换。 
- 3. Vue Router 是 Vue.js 官方的路由管理器。
- 4. Vue Router 是一个轻量级的路由管理器，它和 Vue.js 的核心库没有任何依赖。
- 5. Vue Router 提供了许多功能，如：动态路由、嵌套路由、命名视图、路由过渡效果、路由懒加载等。
::: 

### 2、路由安装

#### 2.1、依赖安装

```
npm install vue-router
```

#### 2.2、路由配置

:::tip 路由配置步骤
- 1. 创建路由实例文件（通常为 `router/index.js`）
- 2. 在 `main.js` 中引入路由实例并挂载到 Vue 实例
- 3. 配置路由规则，定义路径与组件的映射关系
:::

**创建路由实例（router/index.js）：**
:::details
```javascript
// router/index.js

import VueRouter from 'vue-router'

// 使用 Vue Router 插件

// 导入组件
import Home from '@/views/Home.vue'
import About from '@/views/About.vue'

// 定义路由规则
const routes = [
  {
    path: '/',
    name: 'Home',
    component: Home
  },
  {
    path: '/about',
    name: 'About',
    component: About
  }
]

// 创建路由实例
const router = new VueRouter({
  mode: 'history', // 路由模式：hash 或 history
  base: process.env.BASE_URL,
  routes
})

export default router
```
:::

**在 main.js 中引入路由：**
:::details
```javascript
import Vue from 'vue'
import App from './App.vue'
import router from './router'

new Vue({
  router, // 挂载路由实例
  render: h => h(App)
}).$mount('#app')
```

### 3、路由传参
:::tip 几种方式
1. **params 传参**：通过动态路由参数传递，参数会显示在 URL 路径中
2. **query 传参**：通过查询字符串传递，参数会显示在 URL 的 `?` 后面
3. **props 传参**：将路由参数作为组件的 props 传递，更符合组件化开发规范
:::

#### 3.1、params 传参（动态路由参数）

:::tip 说明
`params` 传参是通过动态路由参数传递数据的方式。参数会直接显示在 URL 路径中，格式如 `/user/123`。这种方式适合传递必需的、结构化的参数，如用户 ID、文章 ID 等。

**特点：**
- 参数会显示在 URL 路径中
- 使用动态路由占位符 `:id` 定义参数
- 参数是路由的一部分，刷新页面参数不会丢失
- 使用 `params` 传参时，必须使用命名路由（`name`），不能使用 `path`
- 适合传递必需的、结构化的参数
:::

**路由配置：**

:::details
```javascript
// router/index.js
export default new VueRouter({
  routes: [
    {
      path: '/user/:id',  // 动态路由参数
      name: 'User',
      component: () => import('@/views/User.vue')
    },
    {
      path: '/user/:id/:name',  // 多个参数
      name: 'UserDetail',
      component: () => import('@/views/UserDetail.vue')
    }
  ]
})
```
:::

**传递参数：**

:::details
```vue
<template>
  <div>
    <!-- 方式1：使用 router-link 传递 -->
    <router-link :to="'/user/' + userId">用户详情</router-link>
    
    <!-- 方式2：使用对象形式传递 -->
    <router-link :to="{ name: 'User', params: { id: userId } }">用户详情</router-link>
    
    <!-- 方式3：编程式导航 -->
    <button @click="goToUser">跳转到用户页</button>
  </div>
</template>

<script>
export default {
  data() {
    return {
      userId: '123'
    }
  },
  methods: {
    goToUser() {
      // 使用路径跳转
      this.$router.push('/user/' + this.userId)
      // 或使用对象形式
      this.$router.push({ name: 'User', params: { id: this.userId } })
    }
  }
}
</script>
```
:::

**接收参数：**

:::details

#### 3.2、query 传参（查询参数）

:::tip 说明
- `query` 传参是通过查询字符串传递数据的方式。
- 参数会显示在 URL 的 `?` 后面，格式如 `/search?keyword=vue&page=1`。这种方式适合传递可选的、非必需的参数，如搜索关键词、分页信息、筛选条件等。

**特点：**
- 参数会显示在 URL 查询字符串中（`?` 后面）
- 参数格式为 `key=value`，多个参数用 `&` 连接
- 刷新页面参数不会丢失
- 可以使用 `path` 或 `name` 进行路由跳转
- 适合传递可选的、非必需的参数
- 常用于搜索、筛选、分页等场景
:::

**传递参数：**

:::details
```vue
<template>
  <div>
    <!-- 方式1：使用 router-link 传递 -->
    <router-link :to="{ path: '/search', query: { keyword: 'vue', page: 1 } }">
      搜索
    </router-link>
    
    <!-- 方式2：直接在 URL 中拼接 -->
    <router-link to="/search?keyword=vue&page=1">搜索</router-link>
    
    <!-- 方式3：编程式导航 -->
    <button @click="goToSearch">跳转到搜索页</button>
  </div>
</template>

<script>
export default {
  data() {
    return {
      keyword: 'vue',
      page: 1
    }
  },
  methods: {
    goToSearch() {
      // 使用对象形式传递 query 参数
      this.$router.push({
        path: '/search',
        query: {
          keyword: this.keyword,
          page: this.page
        }
      })
      // 或使用命名路由
      this.$router.push({
        name: 'Search',
        query: {
          keyword: this.keyword,
          page: this.page
        }
      })
    }
  }
}
</script>
```
:::

**接收参数：**

:::details
```vue
<template>
```

#### 3.3、props 传参

:::tip 说明
- `props` 传参是将路由参数作为组件的 `props` 传递的方式。
- 这是最符合 Vue 组件化开发规范的传参方式，可以让组件不直接依赖 `$route` 对象，提高组件的可复用性和可测试性。

**特点：**
- 将路由参数转换为组件的 `props`，组件不直接依赖 `$route`
- 提高组件的可复用性和可测试性
- 支持三种模式：布尔模式、对象模式、函数模式
- 更符合组件化开发规范
- 组件可以在非路由环境下使用（如单元测试）

**三种模式：**
- **布尔模式**：`props: true`，将 `params` 作为 `props` 传递
- **对象模式**：`props: { type: 'detail' }`，传递静态 `props`
- **函数模式**：`props: route => ({ ... })`，自定义返回 `props` 对象
:::

**路由配置（推荐方式）：**

:::details
```javascript
// router/index.js
export default new VueRouter({
  routes: [
    {
      path: '/user/:id',
      name: 'User',
      component: () => import('@/views/User.vue'),
      // 方式1：布尔模式，将 params 作为 props 传递
      props: true,
      // 方式2：对象模式，传递静态 props
      // props: { type: 'detail' },
      // 方式3：函数模式，返回一个对象作为 props
      // props: route => ({ id: route.params.id, query: route.query })
    }
  ]
})
```
:::

**组件接收：**

:::details
```vue
<template>
  <div>
    <h2>用户详情</h2>
    <p>用户ID：{{ id }}</p>
    <p>类型：{{ type }}</p>
  </div>
</template>

<script>
export default {
  name: 'User',
  // 通过 props 接收路由参数
  props: {
    id: {
      type: String,
      required: true
    },
    type: {
      type: String,
      default: 'default'
    }
  },
  created() {
    // 可以直接使用 props，不需要通过 $route.params
    console.log('用户ID：', this.id)
  }
}
</script>
```
:::

#### 3.4、注意事项
:::warning 
- **params 传参**：使用 `params` 时，不能使用 `path`，必须使用 `name` 来跳转
- **query 传参**：参数会显示在 URL 中，刷新页面参数不会丢失
- **props 传参**：更符合组件化开发规范，组件不直接依赖 `$route`，便于测试和复用
:::

### 4、路由命名视图
:::tip 路由命名视图说明
- 1. 路由命名视图允许在同一个路由下渲染多个组件
- 2. 通过给 `<router-view>` 添加 `name` 属性来指定渲染哪个组件
- 3. 在路由配置中使用 `components`（复数）来定义多个组件
- 4. 适用于需要同时显示多个视图的场景，如侧边栏 + 主内容区
:::

**路由配置：**

:::details
```javascript
// router/index.js
export default new VueRouter({
  routes: [
    {
      path: '/',
      name: 'Layout',
      // 使用 components（复数）定义多个命名视图
      components: {
        // default 是默认视图，对应没有 name 的 router-view
        default: () => import('@/views/Home.vue'),
        // left 对应 name="left" 的 router-view
        left: () => import('@/views/Sidebar.vue'),
        // right 对应 name="right" 的 router-view
        right: () => import('@/views/Content.vue')
      }
    }
  ]
})
```
:::

**组件使用：**

:::details
```vue
<template>
  <div class="layout">
    <!-- 左侧边栏 -->
    <aside>
      <router-view name="left"></router-view>
    </aside>
    
    <!-- 主内容区 -->
    <main>
      <router-view></router-view>
    </main>
    
    <!-- 右侧内容区 -->
    <aside>
      <router-view name="right"></router-view>
    </aside>
  </div>
</template>

<script>
export default {
  name: 'Layout'
}
</script>

<style scoped>

  width: 200px;

  flex: 1;
}
</style>
```

### 5、动态路由(路由懒加载)
:::tip 路由懒加载说明
- **路由懒加载**：也称为代码分割或按需加载，是指将路由对应的组件打包成独立的代码块，只有在访问该路由时才加载对应的组件代码。
- **优势**：
  - 减少初始加载时间：只加载当前路由需要的组件，而不是一次性加载所有组件
  - 减小初始包体积：将代码分割成多个小的代码块，按需加载
  - 提升用户体验：首屏加载更快，后续路由切换时再加载对应组件
  - 优化性能：减少内存占用，提高应用运行效率
- **实现方式**：使用动态 `import()` 语法，返回一个 Promise，Vue Router 会在需要时自动加载组件
:::

**基本用法：**

:::details
```javascript
// router/index.js
import Vue from 'vue'
import VueRouter from 'vue-router'

Vue.use(VueRouter)

export default new VueRouter({
  routes: [
    {
      path: '/',
      name: 'Home',
      // 方式1：直接使用动态 import
      component: () => import('@/views/Home.vue')
    },
    {
      path: '/about',
      name: 'About',
      // 方式2：先定义再使用
      component: () => import('@/views/About.vue')
    }
  ]
})
```
:::

**分组打包（推荐）：**

:::details
```javascript
// router/index.js
import Vue from 'vue'
import VueRouter from 'vue-router'

Vue.use(VueRouter)

export default new VueRouter({
  routes: [
    {
      path: '/',
      name: 'Home',

      component: () => import(/* webpackChunkName: "home" */ '@/views/Home.vue')
```

## 七、VueX 状态管理库
### 1、vuex介绍
::: tip VueX 是什么
- **VueX**：Vue.js 官方提供的状态管理库，用于集中管理应用的所有组件的状态。
- **为什么需要 VueX**：
  - 当应用变得复杂时，组件之间的数据共享变得困难
  - 通过 props 和事件传递数据在深层嵌套组件中非常繁琐
  - VueX 提供了统一的状态管理方案，让数据流更加清晰和可预测
- **核心概念**：
  - `State`：存储应用的状态数据（类似组件的 data）
  - `Getters`：从 state 中派生出一些状态（类似组件的 computed）
  - `Mutations`：同步修改 state 的方法（类似组件的 methods，但只能同步）
  - `Actions`：异步操作，提交 mutations 来修改 state
  - `Modules`：将 store 分割成多个模块，便于管理大型应用
- **适用场景**：
  - 多个组件需要共享状态
  - 组件之间需要频繁通信
  - 需要统一管理全局状态（如用户信息、购物车等）
:::

### 2、安装配置
:::tip 安装配置步骤
- 1. 使用 npm 或 yarn 安装 VueX
- 2. 创建 store 实例并配置
- 3. 在 main.js 中引入并挂载到 Vue 实例
- 4. 在组件中使用 `this.$store` 访问状态
:::

### 3、多store配置（Modules）

:::tip Modules 模块化说明
- **Modules**：将 store 分割成多个模块，每个模块拥有自己的 state、mutations、actions、getters
- **优势**：
  - 代码组织更清晰，便于维护
  - 避免命名冲突
  - 适合大型应用的状态管理
  - 每个模块可以独立开发和测试
- **命名空间**：默认情况下，模块内部的 action、mutation 和 getter 是注册在全局命名空间的，可以通过 `namespaced: true` 开启命名空间
:::

```javascript
const userModule = {
  // 开启命名空间
  namespaced: true,
  
  state: {
    name: '',
    age: 0,
    token: ''
  },
  
  getters: {
    // 模块内部的 getter，第一个参数是模块的局部 state
    userName: state => state.name,
    // 可以访问根节点的 state
    fullInfo: (state, getters, rootState) => {
      return `${state.name} - ${rootState.appName}`
    }
  },
  
  mutations: {
    SET_USER(state, user) {
      state.name = user.name
      state.age = user.age
    },
    SET_TOKEN(state, token) {
      state.token = token
    }
  },
  
  actions: {
    // 模块内部的 action，context.state 是局部状态
    login({ commit, state }, userInfo) {
      // 模拟登录
      return new Promise((resolve) => {
        setTimeout(() => {
          commit('SET_USER', userInfo)
          commit('SET_TOKEN', 'token123', { root: true }) // 提交到根节点
          resolve()
        }, 1000)
      })
    },
    // 可以访问根节点的 action
    logout({ commit, dispatch, rootState }) {
      commit('SET_USER', { name: '', age: 0 })
      dispatch('app/clearCache', null, { root: true }) // 调用根节点的 action
    }
  }
}

export default userModule
```

```javascript
// store/modules/cart.js
const cartModule = {
  namespaced: true,
  
  state: {
    items: [],
    total: 0
  },
  
  getters: {
    itemCount: state => state.items.length,
    totalPrice: state => {
      return state.items.reduce((total, item) => {
        return total + item.price * item.quantity
      }, 0)
    }
  },
  
  mutations: {
    ADD_ITEM(state, item) {
      const existItem = state.items.find(i => i.id === item.id)
      if (existItem) {
        existItem.quantity += item.quantity
      } else {
        state.items.push(item)
      }
    },
    REMOVE_ITEM(state, itemId) {
      state.items = state.items.filter(item => item.id !== itemId)
    },
    CLEAR_CART(state) {
      state.items = []
      state.total = 0
    }
  },
  
  actions: {
    addToCart({ commit, state }, item) {
      commit('ADD_ITEM', item)
      // 可以访问其他模块的 state
      console.log('当前购物车商品数：', state.items.length)
    },
    checkout({ commit, dispatch, rootState }) {
      // 结账逻辑
      commit('CLEAR_CART')
      // 可以调用其他模块的 action
      dispatch('user/updatePoints', 100, { root: true })
    }
  }
}

export default cartModule
```

```javascript
  return {
    namespaced: true,
    state: {
      items: []
    },
    getters: {
      itemCount: state => state.items.length
    },
    mutations: {
      ADD_ITEM(state, item) {
        state.items.push(item)
      },
      REMOVE_ITEM(state, index) {
        state.items.splice(index, 1)
      }
```

### 4、数据通信
:::tip 数据通信方式
- **访问 State**：使用 `this.$store.state.xxx` 或 `mapState` 辅助函数

### 5、数据持久化
:::tip 数据持久化说明
- **数据持久化**：将 VueX 中的状态数据保存到本地存储（localStorage 或 sessionStorage），刷新页面后数据不丢失。
- **实现方式**：使用 `vuex-persistedstate` 插件
- **适用场景**：用户信息、购物车、设置项等需要持久保存的数据
- **注意事项**：敏感信息不建议存储在 localStorage 中
:::

**安装插件：**

:::details 安装命令
```bash
# 使用 npm
npm install vuex-persistedstate

# 使用 yarn
yarn add vuex-persistedstate
```
:::

**配置使用：**

:::details store/index.js - 配置持久化
```javascript
// store/index.js
import Vue from 'vue'
import Vuex from 'vuex'
import createPersistedState from 'vuex-persistedstate'

Vue.use(Vuex)

export default new Vuex.Store({
  state: {
    count: 0,
    user: null,
    settings: {
      theme: 'light',
      language: 'zh-CN'
    }
  },
  
  mutations: {
    increment(state) {
      state.count++
    },
    setUser(state, user) {
      state.user = user
    },
    setTheme(state, theme) {
      state.settings.theme = theme
    }
  },
  
  // 配置持久化插件
  plugins: [
    createPersistedState({
      // 存储方式：localStorage（默认）或 sessionStorage
      storage: window.localStorage,
      // 指定需要持久化的 state 键名
      paths: ['user', 'settings']
      // 如果不指定 paths，默认持久化所有 state
    })
  ]
})
```

```javascript
Vue.use(Vuex)

export default new Vuex.Store({
  state: {
    count: 0,
    user: null,
    cart: []
  },
  
  mutations: {
    increment(state) {
      state.count++
    },
    setUser(state, user) {
      state.user = user
    },
    addToCart(state, item) {
      state.cart.push(item)
    }
  },
  
  plugins: [
    // 多个持久化配置
    createPersistedState({
      key: 'user', // 存储的 key 名称
      paths: ['user'], // 只持久化 user
      storage: window.localStorage
    }),
    createPersistedState({
      key: 'cart',
      paths: ['cart'],
      storage: window.sessionStorage // 使用 sessionStorage
    })
  ]
})
```

**自定义存储：**

:::details store/index.js - 自定义存储方式
```javascript
// store/index.js
import Vue from 'vue'
import Vuex from 'vuex'
import createPersistedState from 'vuex-persistedstate'

Vue.use(Vuex)

// 自定义存储对象
const myStorage = {
  getItem: (key) => {
    // 自定义获取逻辑
    return localStorage.getItem(key)
  },
  setItem: (key, value) => {
    // 自定义设置逻辑，可以添加加密等操作
    localStorage.setItem(key, value)
  },
  removeItem: (key) => {
    localStorage.removeItem(key)
  }
}

export default new Vuex.Store({
  state: {
    user: null
  },
  
  mutations: {
    setUser(state, user) {
      state.user = user
    }
  },
  
  plugins: [
    createPersistedState({
      storage: myStorage, // 使用自定义存储
      paths: ['user']
    })
  ]
})
```
:::

:::warning 注意事项
- 持久化会占用浏览器存储空间，不要持久化过大的数据
- 敏感信息（如密码、token）不建议存储在 localStorage 中
- 使用 `paths` 选项可以精确控制哪些数据需要持久化
- 可以同时使用多个持久化配置，分别存储不同的数据
:::
