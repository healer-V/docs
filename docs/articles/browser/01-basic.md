## 浏览器基础

### 一、浏览器市场占比
::: tip 注意
截至 2021 年 10 月，全球浏览器市场份额排名依次为：
1. Chrome
2. Safari
3. Firefox
4. Edge
5. Internet Explorer
:::
### 二、浏览器内核
::: tip 注意
浏览器内核（又称渲染引擎）是指浏览器用来呈现网页的软件。目前，常见的浏览器内核有以下几种：
1. Trident：微软开发的用于 Internet Explorer 的内核，从 IE7 开始使用。
2. Gecko：Mozilla 开发的用于 Firefox、Mozilla 火狐浏览器的内核。
3. Blink：Google 开发的用于 Chrome、Opera、Safari 的内核。
4. Webkit：Apple 开发的用于 Safari 的内核。
:::
### 三、浏览器渲染原理
::: tip 注意
浏览器渲染原理是指浏览器将 HTML、CSS、JavaScript 代码转换为可视化页面的过程。渲染原理可以分为以下几个步骤：
1. 解析 HTML 代码：浏览器将 HTML 代码解析为 DOM 树。
2. 解析 CSS 代码：浏览器将 CSS 代码解析为 CSSOM 树。
3. 合并 DOM 树和 CSSOM 树：将 DOM 树和 CSSOM 树合并为渲染树。
4. 布局：计算渲染树中各元素的位置。
5. 绘制：将渲染树绘制成页面。
6. 合成：将页面的各层合成到一起。
:::
