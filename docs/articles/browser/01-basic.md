# 线程与进程
>[!info]
> **工厂比喻**：浏览器是一座工厂，进程是工厂中的车间，线程是车间内的流水线（实际运作的最小单位）。

## 概念
::: tip 进程
- **定义**：一个正在运行的程序实例，是操作系统分配资源（内存、I/O 等）的基本单位。
- **特性**：
  - 拥有独立的内存空间和系统资源（如文件描述符）。
  - 可包含一个或多个线程。
:::

::: tip 线程
- **定义**：进程内的执行单元，是操作系统调度的最小单位。
- **特性**：
  - 同一进程的线程共享进程资源（如内存地址空间）。
  - 每个线程拥有独立的执行流，支持并发执行。
:::

## 并行与并发
>[!tip]
>- **并发**：多个任务在同一时间段内交替执行（看似同时，实为快速切换）。
>- **并行**：多个任务在同一时刻真正同时执行（需多核 CPU 支持）。

## 进程通信（IPC）
::: tip IPC 机制
- **管道（Pipe）**：半双工通信，分匿名管道（父子进程）和命名管道（任意进程）。
- **消息队列（Message Queue）**：异步通信，进程通过发送/接收消息交互。
- **共享内存（Shared Memory）**：多个进程直接读写同一内存区域（需同步机制如信号量）。
- **信号量（Semaphore）**：控制共享资源访问，解决进程同步问题。
- **套接字（Socket）**：支持跨主机或同主机进程通信（如网络请求）。
- **信号（Signal）**：软件中断，通知进程特定事件（如 `SIGKILL`）。
:::

## 浏览器的进程模型
::: tip 多进程架构
- **浏览器进程 (Browser Process)**：主控进程，管理界面、用户输入、子进程协调。
- **渲染进程 (Renderer Process)**：每个 Tab 页独立进程，负责 HTML/CSS/JS 解析渲染（沙盒隔离）。
- **网络进程 (Network Process)**：统一处理网络请求、DNS 解析、SSL/TLS 加密。
- **GPU 进程 (GPU Process)**：加速页面渲染、图形处理（如 CSS 3D 变换）。
:::

## 浏览器的线程模型
::: tip 渲染进程内的 5 类线程
1. **GUI 渲染线程**：解析 HTML/CSS、构建 DOM/CSSOM、绘制页面（与 JS 引擎互斥）。
2. **JS 引擎线程**：执行 JavaScript 代码（如 V8 引擎，单线程运行）。
3. **事件触发线程**：管理事件队列（点击、键盘事件），通知 JS 引擎处理回调。
4. **定时器线程**：处理 `setTimeout`/`setInterval` 计时，到期后通知事件线程。
5. **异步 HTTP 线程**：执行 `XMLHttpRequest`/`Fetch` 请求，完成后通知事件线程。
:::

## 网络进程详解
::: tip 核心职责
1. 管理网络请求（HTTP/WebSocket）和响应。
2. 执行 DNS 解析、建立 TCP 连接。
3. 处理 SSL/TLS 加密、证书验证。
4. 管理 HTTP 缓存策略（强缓存/协商缓存）。
:::

::: tip 内部线程分工
- **DNS 解析线程**：专责域名 → IP 的转换。
- **SSL 线程**：处理加密握手、证书校验。
- **网络 I/O 线程**：收发网络数据包（TCP/UDP 层）。
- **IPC 线程**：与其他进程（如渲染进程）通信。
:::

## 事件循环机制
::: tip 核心概念
- **单线程模型**：JS 引擎线程同一时间只能执行一个任务。
- **运行机制**：
  1. 同步任务在主线程直接执行。
  2. 异步任务（网络请求、定时器）交由对应线程处理。
  3. 异步任务完成后，回调函数推入**任务队列**。
  4. 主线程空闲时，按优先级轮询队列（微任务 → 宏任务）。
- **队列类型**：
  - **微任务队列**：`Promise.then`、`MutationObserver`（优先执行）。
  - **宏任务队列**：`setTimeout`、`setInterval`、DOM 事件。
:::
