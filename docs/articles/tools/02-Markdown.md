# Markdown 语法

>[!tip] 介绍
> - `Markdown`是一种轻量级标记语言，创始人为约翰·格鲁伯（John Gruber）,
> - 文档后缀为 .md 或 .markdown，目前它已是 GitHub 的御用书写格式,
> 弥补了传统纯文本缺少样式的不足,降低了传统 Word、HTML 等样式文本的技术门槛



## 1. 标题
>[!tip]
> - 以 `#` 号开头，后面至少**一个空格**，和H1~H6一样的

**输入**
```md
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```
## 2. 列表

### 2.1 无序列表
>[!tip]
>- 以 `*` 或 `+` 或 `-` 开头，后面至少**一个空格**

**输入**

```md
* 这是第1句
+ 这是第2句
- 这是第3句
```

**输出**
* 这是第1句
+ 这是第2句
- 这是第3句

**输入**

```md
* 中国
  * 北京
    * 海淀区
      * 百度
  * 浙江
    * 杭州
      * 阿里巴巴
  * 广东
    * 深圳
      * 腾讯
```
**输出**
::: details
* 中国
  * 北京
    * 海淀区
      * 百度
  * 浙江
    * 杭州
      * 阿里巴巴
  * 广东
    * 深圳
      * 腾讯
:::

### 2.2 有序列表
>[!tip]
>- 以数字和点号开头，后面至少**一个空格**

输入：

```
1. 这是第1句
2. 这是第2句
3. 这是第3句
```
输出：

::: details
1. 这是第1句
2. 这是第2句
3. 这是第3句
:::


### 2.3 任务列表
>[!tip]
>- 格式如下， [ ] 里面是空格，若完成了， [ ] 里的空格换成X

**输入**


```md
* [ ] 吃饭
* [ ] 睡觉
* [x] 打豆豆
* [ ] 打豆腐
```
**输出**
::: details
* [ ] 吃饭
* [ ] 睡觉
* [x] 打豆豆
* [ ] 打豆腐
:::






## 3. 块引用
>[!tip]
>- 引用比较简单，符号是 `>`，可以**多层嵌套**

**输入**

```
> 青玉案·元夕
>> 辛弃疾
>>>东风夜放花千树。更吹落、星如雨。宝马雕车香满路。凤箫声动，玉壶光转，一夜鱼龙舞。
>>>蛾儿雪柳黄金缕。笑语盈盈暗香去。众里寻他千百度。蓦然回首，那人却在，灯火阑珊处。
```
**输出**
> 青玉案·元夕
>> 辛弃疾
>>>东风夜放花千树。更吹落、星如雨。宝马雕车香满路。凤箫声动，玉壶光转，一夜鱼龙舞。

## 5. 图片链接
>[!tip]
>- 此方法，适用于图片/视频/音频等，有链接都可以


**输入**
```md
![替代文字](图片地址)

<!-- 注：[ ]中括号的替代文字可留空 -->
```


## 6. 超链接
**输入**
```md
<!-- 格式1：[这里填文字](这里是跳转的网址) -->

<!-- 格式2：[这里填文字](这里是跳转的网址 "这里填鼠标放上去显示的文字") -->

- [百度](http://www.baidu.com)
- [百度](http://www.baidu.com "百度一下，你就知道")
```
**输出**
::: details
- [百度](http://www.baidu.com)
- [百度](http://www.baidu.com "百度一下，你就知道")
:::


## 7. 分割线

> [!tip]
> - 三个以上的星号或减号或下划线
> - HTML 的 `<hr>` 标签。

**输入**
```md
---
***
___
```

**输出**
::: details
---
***
___
:::



## 8. 转义反引号
> [!tip]
> 如果要表示为代码的单词或短语包含**一个或者多个反引号**，则通过将单词或者短语括在双反引号（``）中来对其进行转义。

**输入**
```markdown
``Use`code`in your markdown  file.``
```

**输出**

``Use`code`in your markdown  file.``

## 9. 表格
>[!tip]
>- 语法：使用 `|` 来分隔不同的单元格，使用 `-` 来分隔表头和内容。
>- 冒号 `:` 两侧需要**至少一个空格**，否则会被识别为任务列表。
>
> -  **对齐方式**
> - 可以通过在标题行内连字符的左侧、右侧或者两侧添加冒号（），来将列中的文本向左、向右或居中对齐。

**输入**
```markdown
| 语法 |描述 | 测试 |
| ---  |  ---  | --- |
|标题  | 标题 |  测试  |
| 段落| 段落 | 测试 |
```

**输出**

| 语法 | 描述 | 测试 |
| ---- | ---- | ---- |
| 标题 | 标题 | 测试 |
| 段落 | 段落 | 测试 |


## 10. 脚注
> [!tip]
>- 脚注：脚注是对文本的补充说明，可以放在文章的任意位置，并不要求一定要放在文末。

**输入**
```markdown
- 这是一个简单的脚注[^1]，这是一个更长的脚注[^2]
- [^1]: 秦时明月
- [^2]: 汉时关
```
**输出**
- 这是一个简单的脚注[^1]，这是一个更长的脚注[^2]
- [^1]: 秦时明月
- [^2]: 汉时关



## 11. 链接标题ID
>[!tip]
>- 链接到标题ID，可以直接使用标题的ID，链接到标题的位置。

**输入**
```markdown
- [标题](#h-id)
```
**输出**
::: details
- [标题]（#h-id）
:::

## 15. 徽章

### 15.1 什么是徽章
>[!tip]
>- 徽章是一种小巧精美的图标，一般配有相关文字进行辅助说明，可对数据进行监控，链接跳转等，富有表现力。

### 15.2 徽章的使用
**输入**
```shell
格式：
[![图片文字说明]（图片源地址）](超链接地址) #既超链接嵌套图片

语法：
![AppVeyor tests](https://img.shields.io/appveyor/tests/%E7%94%B5%E6%94%BE/%E9%A3%9E)

```


**输出**

![AppVeyor tests](https://img.shields.io/appveyor/tests/%E7%94%B5%E6%94%BE/%E9%A3%9E)
