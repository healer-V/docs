# 1.1 认识 Linux

## Linux 是什么？

Linux 严格来说只是一个**内核（Kernel）**，由 Linus Torvalds 在 1991 年作为个人项目发布。它负责管理硬件资源（CPU、内存、磁盘、网络），并为上层应用程序提供统一的接口。

我们日常所说的"Linux 系统"，准确的叫法是 **GNU/Linux**，是 Linux 内核 + GNU 工具集（ls、grep、bash 等）+ 其他软件的组合。

```
┌─────────────────────────────────────┐
│           用户应用程序               │  ← 你写的代码、nginx、mysql...
├─────────────────────────────────────┤
│         Shell / 命令行工具           │  ← bash、zsh、ls、grep...
├─────────────────────────────────────┤
│         系统调用接口 (syscall)        │  ← 程序与内核沟通的桥梁
├─────────────────────────────────────┤
│           Linux 内核                 │  ← 进程调度、内存管理、驱动...
├─────────────────────────────────────┤
│             硬件                     │  ← CPU、内存、磁盘、网卡...
└─────────────────────────────────────┘
```

## Linux 发行版

发行版（Distribution，简称 Distro）= Linux 内核 + 一套预装软件 + 包管理器 + 配置工具的整体打包。

主流发行版及其特点：

| 发行版 | 包管理器 | 适用场景 | 代表版本 |
|--------|----------|----------|----------|
| **Ubuntu** | APT (`.deb`) | 新手友好，桌面 & 服务器 | 22.04 LTS |
| **Debian** | APT (`.deb`) | 稳定优先，生产服务器 | Debian 12 |
| **CentOS Stream** | DNF (`.rpm`) | 企业环境，RedHat 兼容 | Stream 9 |
| **Rocky Linux** | DNF (`.rpm`) | CentOS 替代，企业级稳定 | Rocky 9 |
| **Arch Linux** | Pacman | 高度可定制，进阶用户 | 滚动更新 |
| **Alpine Linux** | APK | 极简主义，Docker 镜像常用 | 3.x |

::: tip 初学者推荐
**Ubuntu 22.04 LTS** 是最好的入门选择：
- 社区庞大，遇到问题容易搜到解决方案
- 文档和教程最多
- LTS（长期支持版）稳定可靠，5 年官方维护
:::

## Linux 的核心设计哲学

理解这几个原则，能帮你更快建立对 Linux 的直觉：

### 1. 一切皆文件

Linux 中几乎所有东西都被抽象为文件：
- 普通文档 → 文件
- 硬盘、U盘 → `/dev/sda`、`/dev/sdb`
- 键盘、鼠标 → `/dev/input/`
- 进程信息 → `/proc/1234/`
- 系统配置 → `/etc/nginx/nginx.conf`

这意味着你可以用统一的方式（读/写文件）来操作几乎所有系统资源。

### 2. 小工具组合完成复杂任务

Linux 提供大量只做一件事的小工具，通过**管道（`|`）**组合：

```bash
# 找出占用内存最多的5个进程
$ ps aux | sort -k4 -rn | head -5

# 统计某个 IP 访问 nginx 的次数
$ cat /var/log/nginx/access.log | grep "192.168.1.100" | wc -l
```

### 3. 配置即文本文件

几乎所有软件的配置都是纯文本，存放在 `/etc/` 下。这意味着：
- 配置可以版本控制（git）
- 配置可以脚本化
- 出了问题直接看文件就能排查

## Linux vs Windows vs macOS

| 对比项 | Linux | Windows | macOS |
|--------|-------|---------|-------|
| 核心优势 | 稳定、免费、可定制 | 生态丰富、易用 | Unix 内核、开发友好 |
| 服务器份额 | ~96% | ~3% | <1% |
| 图形界面 | 可选（桌面版有） | 强制 | 强制 |
| 文件系统 | ext4、xfs、btrfs | NTFS | APFS |
| 命令行 | bash/zsh（原生强大） | PowerShell/CMD（较弱） | zsh（基于 BSD） |
| 开源 | 是 | 否 | 部分 |

---

## 小结

- Linux 是一个内核，搭配 GNU 工具集组成完整操作系统
- 主流发行版分为 **Debian 系**（Ubuntu）和 **RedHat 系**（CentOS/Rocky）两大阵营
- "一切皆文件"和"管道组合"是 Linux 的核心设计哲学
- 初学者推荐从 Ubuntu 22.04 LTS 开始
