# Linux 系统学习指南

## 为什么要学 Linux？

Linux 是服务器领域的绝对主流。全球超过 96% 的服务器运行 Linux，几乎所有主流云平台（AWS、阿里云、腾讯云）的默认系统都是 Linux。对于开发者来说，掌握 Linux 不是加分项，而是基本技能。

**你将获得的能力：**
- 在服务器上独立部署和维护应用
- 通过命令行高效完成各类系统操作
- 理解程序在操作系统层面的运行机制
- 排查线上环境的各类故障


## 学习路线

```
第1章：认识 Linux          ← 从这里开始，建立整体认知
  ↓

  ↓

  ↓
第4章：文本处理             ← 服务器上最常用的技能

  ↓
```

## 各章内容概览

### 第 1 章：认识 Linux
- Linux 的历史与发行版选择
- 在本地搭建 Linux 学习环境（WSL / 虚拟机 / 云服务器）
- Shell 与终端的基本概念

### 第 2 章：文件系统
- Linux 的目录结构（`/etc`、`/var`、`/home` 等都是什么）
- 文件与目录的增删改查
- 文件查找：`find`、`locate`、`which`

### 第 3 章：权限与用户管理
- 用户、用户组的创建与管理
- `rwx` 权限模型详解
- `sudo` 的正确使用姿势

### 第 4 章：文本处理
- Vim 编辑器：从恐惧到顺手
- `grep`：在文件中搜索内容
- `sed`：批量替换文本
- `awk`：提取和处理结构化数据

### 第 5 章：进程与系统管理
- 进程查看、终止、后台运行
- CPU / 内存 / 磁盘的监控命令
- `systemd` 服务管理

### 第 6 章：网络管理
- IP 配置、DNS 解析
- `curl`、`wget`、`netstat`、`ss` 等网络工具
- `iptables` / `firewalld` 防火墙配置

### 第 7 章：软件包管理
- APT（Ubuntu / Debian 系）
- YUM / DNF（CentOS / RHEL 系）


## 学习建议

::: tip 边学边练
光看文档记不住。每学一个命令，立刻在终端里敲一遍，改改参数看看效果。
:::

::: warning 不要死背命令
命令太多，背不完。重要的是理解**每个命令在做什么**，遇到不熟悉的参数查 `man` 手册即可。
:::

**推荐环境：** Windows 用户建议安装 WSL2（Windows Subsystem for Linux），Mac 用户直接使用内置终端即可。


## 约定说明

文档中的命令示例遵循以下约定：

```bash
# 以 $ 开头的行，表示普通用户执行的命令
$ ls -la

# 以 # 开头的行，表示需要 root 权限的命令
# systemctl restart nginx

# 尖括号 <> 表示需要替换为实际值
$ ssh <username>@<host>

# 方括号 [] 表示可选参数
$ ls [-l] [-a]
```
