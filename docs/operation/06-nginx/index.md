# Nginx

Nginx 是一款高性能的 HTTP 和反向代理服务器，同时也是 IMAP/POP3/SMTP 代理服务器。凭借事件驱动、异步非阻塞的架构设计，Nginx 能以极低的资源消耗处理大量并发连接，是当前互联网最主流的 Web 服务器之一。

## 核心优势

- **高性能**：基于事件驱动的异步架构，轻松支撑数万并发连接
- **低资源消耗**：相比 Apache，内存和 CPU 占用极低
- **反向代理**：作为反向代理转发请求到后端服务，是微服务架构的标配
- **负载均衡**：内置多种负载均衡策略，实现流量的智能分发
- **高可用**：支持热部署、平滑重载配置，做到服务零停机

## 适用场景

Nginx 适用于以下场景：

- 静态资源托管（HTML、CSS、JS、图片）
- 反向代理后端 API 服务（Node.js、Java、Python）
- 多服务负载均衡
- HTTPS 证书终结
- 前端 SPA 应用部署
- WebSocket 代理
- 限流和访问控制

## 技术栈

- **核心软件**：Nginx / OpenResty
- **证书工具**：Let's Encrypt、Certbot
- **配置语法**：Nginx 指令与上下文
- **日志分析**：GoAccess、ELK

## 学习路线

1. **安装与配置**：在 Ubuntu/CentOS/macOS 上安装 Nginx，了解启停和基本管理命令
2. **配置文件详解**：理解 nginx.conf 的层级结构，掌握 http、server、location 三大上下文
3. **静态资源服务**：配置静态文件托管，部署前端 SPA 应用
4. **反向代理**：将请求转发到后端服务，解决跨域问题
5. **负载均衡**：配置多后端节点的流量分发策略
6. **HTTPS 配置**：申请证书、配置 SSL/TLS、强制 HTTPS 跳转
7. **性能优化**：Gzip 压缩、缓存策略、连接复用、Worker 调优
8. **日志管理**：访问日志与错误日志的配置和分析
9. **实战案例**：前后端分离部署、多域名配置、WebSocket 代理
