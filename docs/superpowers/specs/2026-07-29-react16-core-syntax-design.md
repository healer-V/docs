# React 16.8 核心语法章节设计

## 一、设计目标

第 1 章面向具备 JavaScript 基础、尚未系统学习 React 的读者。读者应能只按 sidebar 顺序阅读当前四篇文档，理解 React 16.8 如何创建元素、提交界面、填充数据、选择分支和渲染列表。

文档不以术语清单或 API 罗列为主。每个知识点先解决一个可以观察的问题，再解释代码、运行结果、规则和边界。代码示例只承担当前步骤需要的职责，不提前依赖 State、事件、Hooks 或组件通信。

本章不创建示例工程。必要的 HTML 宿主节点、入口代码和执行上下文直接放在相关示例前，保证读者能够判断代码所属位置和预期结果。

## 二、章节边界

React 16.8 模块固定使用以下六章：

| 顺序 | 章节 |
|------|------|
| 1 | 核心语法 |
| 2 | 数据流 |
| 3 | 组件 |
| 4 | Hooks |
| 5 | 高级能力 |
| 6 | 运行机制与性能优化 |

第 1 章只处理静态数据到 React 界面的描述过程：

```text
创建元素
→ 提交到 DOM
→ 使用 JSX 描述结构
→ 在 JSX 中读取数据
→ 根据数据选择分支
→ 把数组转换为元素列表
```

Props、State、事件和表单属于第 2 章；组件职责和组合属于第 3 章；Hooks 属于第 4 章；协调和组件身份属于第 6 章。

## 三、文档结构

第 1 章包含四篇文档：

| 顺序 | 文档 | 核心问题 | 学习结果 |
|------|------|----------|----------|
| 1.1 | React 元素与 JSX | React 如何把一个元素显示到页面 | 能创建元素、提交元素并使用 JSX 描述结构 |
| 1.2 | JSX 数据与属性 | JavaScript 数据如何进入 JSX | 能输出动态内容并正确设置 DOM 属性与样式 |
| 1.3 | 条件渲染 | 不同数据状态如何选择不同界面 | 能使用控制流、三元表达式和逻辑与组织分支 |
| 1.4 | 列表渲染与 Key | 数组如何转换为稳定列表 | 能使用 `map`、`filter` 和稳定 Key 渲染集合 |

文章标题只描述知识主题，不使用“学习路线”“理解与应用”“实践任务”等模板化名称。

## 四、代码示例规范

每个核心代码示例必须形成以下闭环：

| 位置 | 必须说明的内容 |
|------|----------------|
| 代码前 | 当前问题、代码所属文件或上下文、需要观察的结果 |
| 代码中 | 只包含当前知识需要的代码；函数、方法和回调具有必要注释 |
| 代码后 | 解释关键语句及其关系，不逐行翻译显而易见的赋值 |
| 结果 | 给出页面文本、DOM 结构、控制台输出或真实错误表现 |
| 结论 | 明确示例证明的规则和当前尚未解决的问题 |
| 衔接 | 说明下一节为什么建立在当前结论之上 |

禁止连续堆叠多个代码块而不解释差异。正确示例与错误示例必须同时说明错误现象、原因和修正方式。
