# 首页精选学习资源扩充设计

## 一、设计目标

在首页“精选学习资源”区域新增两张资源卡片，补充 Vue 源码分析与 JavaScript 系统教程内容。新增内容沿用现有卡片数据结构、主题色变量和内联 SVG 图标方案，不调整组件布局与交互。

## 二、资源内容

| 资源 | 标签 | 描述 | 链接 |
|---|---|---|---|
| Vue.js 技术揭秘 | Vue 原理 | 深入分析 Vue 运行机制与源码实现 | `https://ustbhuangyi.github.io/vue-analysis/` |
| 现代 JavaScript 教程 | JavaScript | 从语言基础到浏览器能力的系统化教程 | `https://zh.javascript.info/` |

## 三、图标设计

### 1. Vue.js 技术揭秘

图标采用“Vue 标志与源码节点”组合语义，使用现有绿色主题变量，突出 Vue 源码分析属性。SVG 保持 `32 × 32` 视口以及 `28 × 28` 展示尺寸，与当前资源卡片一致。

### 2. 现代 JavaScript 教程

图标采用“JS 字样与打开的书本”组合语义，使用现有黄色主题变量，表达 JavaScript 系统教程属性。SVG 尺寸、描边和视觉重量与现有图标保持一致。

## 四、实现约束

1. 仅修改 `HomeBento.vue` 中的 `cards` 数据，不新增组件或图片文件。
2. 两个链接继续使用现有 `target="_blank"` 与 `rel="noopener"` 行为。
3. 两张卡片均使用 `span-1`，保持当前响应式网格规则。
4. 图标使用主题 CSS 变量，兼容亮色与暗色模式。
5. 修改后执行项目现有构建检查，确认 Vue 模板与 SVG 字符串能够正常编译。

## 五、验收标准

| 序号 | 验收项 | 通过条件 |
|---:|---|---|
| 1 | 内容 | 首页显示两张新增资源卡片，标题、标签与描述准确 |
| 2 | 跳转 | 两张卡片分别打开用户指定的网址 |
| 3 | 图标 | 图标清晰表达 Vue 源码与 JavaScript 教程语义 |
| 4 | 视觉 | 图标颜色、尺寸及卡片布局与现有设计一致 |
| 5 | 构建 | VitePress 构建无新增错误 |
