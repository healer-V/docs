# About 页面分类配色设计

## 一、问题与目标

### 1. 当前问题

`/docs/about/` 页面中的分类图标、数量标签、资源图标和悬停反馈全部使用品牌蓝色。卡片结构清晰，但五个分类缺少视觉区分，连续浏览时容易形成单一色块。

本次调整只增强分类识别，不改变页面布局、卡片尺寸、资源内容、标题间距和响应式行为。页面背景、卡片背景、正文和默认边框继续使用中性色，避免形成高饱和度的彩色卡片墙。

### 2. 设计目标

页面使用品牌蓝、翡翠绿、紫罗兰三种现有主题色。颜色需要表达分类层级，而不是装饰每一张卡片；浅色与深色主题共用同一组主题令牌，通过低透明度背景和边框控制视觉强度。

## 二、方案选择

| 方案 | 处理方式 | 优点 | 限制 | 结论 |
|------|----------|------|------|------|
| 分类统一强调色 | 同一分类内的标题图标、数量标签、资源图标和悬停状态使用同一色调 | 分类语义稳定，颜色克制，便于扫描 | 需要为分类增加色调标识 | 采用 |
| 卡片循环配色 | 每张卡片按顺序循环三种颜色 | 视觉更活跃 | 同一分类内部颜色杂乱，缺少语义 | 不采用 |
| 仅改变悬停色 | 默认状态继续保持品牌蓝，只在悬停时切换颜色 | 修改量最少 | 静态页面仍然单调，分类识别弱 | 不采用 |

## 三、配色与应用

### 1. 分类颜色映射

只复用项目已有 CSS 变量，不新增十六进制色值。分类映射如下：

| 分类 | 色调 | 主题变量 |
|------|------|----------|
| 知识文档 | 品牌蓝 | `--color-brand`、`--color-brand-rgb` |
| 原理拆解 | 翡翠绿 | `--color-success`、`--color-success-rgb` |
| 面试题库 | 紫罗兰 | `--color-purple`、`--color-purple-rgb` |
| GitHub文档 | 品牌蓝 | `--color-brand`、`--color-brand-rgb` |
| 博客系统 | 翡翠绿 | `--color-success`、`--color-success-rgb` |

颜色按“蓝 → 绿 → 紫 → 蓝 → 绿”的顺序重复，整页只有三种强调色，且相邻分类能够快速区分。

### 2. 样式落点

每个分类通过色调类设置局部 CSS 变量，现有子元素读取该变量。颜色应用范围如下：

1. 分类 SVG 图标使用实色；
2. 数量标签使用实色文字和低透明度背景；
3. 分隔线从分类色的轻透明状态过渡到默认边框色；
4. 卡片字母图标使用实色文字和低透明度背景；
5. 卡片悬停时，边框、标题和箭头使用分类色，阴影保持低透明度；
6. 卡片默认背景、正文、描述和边框保持现有中性色。

## 四、实现边界与验证

### 1. 修改边界

`sections` 数据只增加色调标识，不修改资源名称、描述或链接。模板为分类节点增加稳定的色调类，样式集中在 `AboutPage.vue` 的 scoped CSS 中，不修改全局主题变量或其他页面。

### 2. 验收标准

完成修改后必须满足以下条件：

1. 页面只出现品牌蓝、翡翠绿和紫罗兰三种分类强调色；
2. 五个分类按设计映射使用颜色，分类内部保持一致；
3. 浅色与深色主题下文字、图标和数量标签均清晰可辨；
4. 桌面端与移动端的卡片、标题和分隔线没有重叠或溢出；
5. 悬停反馈不改变卡片尺寸，不产生布局跳动；
6. VitePress 全量构建成功，且代码修改仅涉及 `AboutPage.vue`。
