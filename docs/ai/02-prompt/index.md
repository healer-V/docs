# Prompt 工程

## 核心优势

- **即学即用**：无需编程基础，掌握 Prompt 技巧就能高效使用大语言模型
- **显著提升效果**：同一个模型，好的 Prompt 和差的 Prompt 输出质量天差地别
- **通用技能**：适用于 ChatGPT、Claude、Gemini 等所有主流大模型

## 适用场景

Prompt 工程技巧适用于以下场景：

- 日常使用 AI 助手提升工作效率
- 开发 AI 应用时设计系统提示词
- 构建自动化工作流中的 LLM 调用
- 技术文档、代码生成等垂直场景优化

## 技术栈

- **大模型平台**：ChatGPT、Claude、Gemini
- **核心技术**：Zero-shot / Few-shot、Chain of Thought
- **高级模式**：ReAct、Tree of Thought、Self-Consistency

## 学习路线

1. **Prompt 基础**：掌握 Prompt 的四要素（角色、任务、上下文、格式），学会 Zero-shot 和 Few-shot
2. **高级 Prompt 技巧**：学习 Chain of Thought、ReAct 等高级策略，掌握结构化输出和 Prompt 链式调用
