# 成本与部署运营概述

成本与部署运营关注 AI 应用的运行成本、性能优化、本地部署和资源规划。企业级 AI 应用不仅要能跑通，还要控制 Token 成本、模型成本、GPU 资源和高并发下的稳定性。

## 核心定位

- **控制成本**：通过模型选型、路由、缓存、批处理和 Prompt 压缩降低消耗。
- **提升性能**：优化延迟、吞吐、上下文长度和高频请求处理能力。
- **支撑部署**：规划本地模型、vLLM、GPU 资源、高可用和容量评估。

## 运营能力

| 能力 | 说明 |
|---|---|
| 成本模型 | 理解 Token、模型单价、请求量、上下文长度和预算配额 |
| 性能优化 | 使用模型路由、缓存、批处理、Prompt 压缩和小模型替代 |
| 私有部署 | 使用 Ollama、vLLM 和 GPU 资源部署本地模型服务 |
| 运维治理 | 建立容量评估、高可用、灾备和成本看板 |

## 学习路线

1. 先建立 Token 成本模型，明确哪些因素决定 AI 应用成本。
2. 再学习缓存、批处理、模型路由和 Prompt 压缩等优化手段。
3. 最后掌握本地与私有化部署方案，支撑企业生产环境运行。
