# 模型网关概述

模型网关是企业 AI 应用的统一模型接入层，负责屏蔽不同模型供应商之间的接口差异，并提供路由、限流、审计、降级、缓存和成本统计等通用能力。

## 核心定位

- **统一入口**：业务系统不直接依赖某个模型厂商，而是通过统一网关访问模型能力。
- **稳定性保障**：通过超时、重试、熔断、降级和多模型路由提升生产可用性。
- **治理能力**：集中管理密钥、模型准入、调用日志、Token 消耗和租户配额。

## 典型能力

| 能力 | 说明 |
|---|---|
| 多供应商接入 | 接入 OpenAI 兼容接口、Claude、国产模型和本地模型 |
| 推理封装 | 统一 Chat、Responses、流式输出、工具调用和结构化输出 |
| 路由策略 | 按任务类型、成本、延迟、稳定性选择合适模型 |
| 调用治理 | 管理限流、配额、审计、缓存、降级和异常追踪 |

## 学习路线

1. 理解模型网关的职责边界，避免在业务代码中直接散落模型调用逻辑。
2. 掌握常见模型 API 的接入方式，形成统一请求和响应抽象。
3. 建立企业级模型网关能力，包括路由、限流、审计、缓存和容灾。
