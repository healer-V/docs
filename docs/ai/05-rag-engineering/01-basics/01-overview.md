# RAG 应用工程概述

RAG 是检索增强生成，用来让大模型基于企业知识、业务文档和外部资料回答问题。RAG 应用工程关注的不只是向量检索，而是从知识处理、召回、重排、上下文压缩、答案生成到引用溯源的完整链路。

## 核心定位

- **降低幻觉**：让模型回答时依赖可追溯的知识来源。
- **连接企业知识**：把内部文档、制度、工单和业务数据接入 AI 应用。
- **提升答案质量**：通过检索、重排、压缩、引用和评测持续优化效果。

## 工程链路

| 环节 | 说明 |
|---|---|
| 知识处理 | 文档解析、切分、清洗、元数据标注和索引构建 |
| 检索召回 | 向量检索、关键词检索、混合检索和 Query 改写 |
| 答案生成 | 重排、上下文压缩、Prompt 拼装、答案合成和引用溯源 |
| 质量优化 | 相关性评估、幻觉控制、检索缓存和反馈闭环 |

## 学习路线

1. 先理解 RAG 的工作流和适用边界，避免把所有问题都交给 RAG。
2. 再掌握检索、重排、答案生成和引用溯源的核心实现。
3. 最后学习 LangChain RAG 实战和高级 RAG 方案，形成可复用项目结构。
