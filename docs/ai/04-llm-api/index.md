# LLM API 开发

## 核心优势

- **快速集成**：通过 API 调用即可为你的应用添加 AI 能力，无需自建模型
- **功能丰富**：Chat Completions、Function Calling、Embeddings、Vision 等多种能力
- **双语言支持**：Python 和 Node.js SDK 均有完善支持

## 适用场景

LLM API 适用于以下开发场景：

- 为 Web 应用集成智能对话功能
- 构建 AI 驱动的内容生成工具
- 实现语义搜索和文本分析
- 开发具备工具调用能力的 AI 助手

## 技术栈

- **API 平台**：OpenAI（GPT-4）、Anthropic（Claude）
- **编程语言**：Python、TypeScript / Node.js
- **核心能力**：Chat Completions、Tool Use、Embeddings、Streaming

## 学习路线

1. **OpenAI API**：Chat Completions、流式响应、Function Calling、Embeddings、Token 计费
2. **Claude API**：Messages API、Tool Use、Vision、Extended Thinking
