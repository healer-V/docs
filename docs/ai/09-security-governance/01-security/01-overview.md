# 安全与合规治理概述

安全与合规治理关注 AI 应用在企业环境中的数据安全、访问控制、内容审核、模型准入和审计留痕。AI 应用会接触用户输入、企业知识、工具调用和模型输出，因此必须从设计阶段就纳入安全边界。

## 核心定位

- **防止输入攻击**：识别 Prompt 注入、越权请求和恶意上下文污染。
- **保护企业数据**：控制敏感信息、权限隔离、数据留存和外部模型调用边界。
- **治理模型输出**：对内容安全、工具调用、风险响应和审计追踪建立机制。

## 治理范围

| 范围 | 说明 |
|---|---|
| 输入安全 | Prompt 注入、越权访问、敏感信息和恶意文件输入 |
| 输出治理 | 内容审核、风险拦截、敏感内容处理和工具调用审批 |
| 合规治理 | 数据合规、模型准入、权限策略、审计留痕和保留周期 |
| 运行控制 | 结合日志、告警和审批机制处理高风险请求 |

## 学习路线

1. 先理解 AI 应用常见安全风险，尤其是 Prompt 注入和数据泄露。
2. 再建立输入、输出和工具调用的安全控制点。
3. 最后从企业合规角度设计模型准入、权限策略和审计机制。
