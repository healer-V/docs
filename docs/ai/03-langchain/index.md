# LangChain

## 核心优势

- **模块化设计**：将 LLM 调用、提示词管理、记忆系统和工具集成拆分为独立模块，灵活组合
- **丰富的集成**：内置对 OpenAI、Anthropic、HuggingFace 等主流模型和各种向量数据库的支持
- **RAG 支持**：提供从文档加载到向量检索的完整 RAG 开发工具链

## 适用场景

LangChain 适合构建以下类型的 AI 应用：

- 基于私有知识库的问答系统（RAG）
- 多轮对话机器人
- 文档摘要和分析工具
- 具备工具调用能力的 AI Agent

## 技术栈

- **编程语言**：Python、TypeScript
- **核心框架**：LangChain、LCEL
- **向量数据库**：Chroma、FAISS、Pinecone
- **LLM 提供商**：OpenAI、Anthropic

## 学习路线

1. **LangChain 入门**：安装配置、核心概念（Models、Chains、Agents、Memory）、LCEL 表达式语法
2. **RAG 检索增强生成**：文档加载、文本分割、向量嵌入、检索链构建
