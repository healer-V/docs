# Agent 工作流概述

Agent 工作流关注让大模型具备规划、调用工具、观察结果和持续推进任务的能力。企业级 Agent 不只是让模型自由发挥，而是要把工具权限、流程状态、人机协同、失败恢复和审计治理纳入工程体系。

## 核心定位

- **从问答到执行**：让 AI 不只回答问题，还能调用工具完成具体任务。
- **从自由对话到可控流程**：通过状态机、工作流和审批机制控制执行边界。
- **从单步调用到长任务**：支持多步骤任务、重试、恢复、追踪和人工介入。

## 关键能力

| 能力 | 说明 |
|---|---|
| Agent 循环 | 理解规划、行动、观察和反馈的执行模式 |
| 工具调用 | 设计 Tool Schema、权限边界和沙箱执行策略 |
| LangGraph | 使用状态图管理复杂流程、条件路由和 Checkpoint |
| 多 Agent | 处理任务分派、角色协作、失败恢复和协作治理 |

## 学习路线

1. 先理解 Agent 的基本循环和工具调用边界。
2. 再学习 MCP 和工具权限控制，让 Agent 可以安全接入外部能力。
3. 最后使用 LangGraph 组织复杂工作流，支持长任务、人机协同和状态恢复。
