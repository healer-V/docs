# LLMOps 质量工程概述

LLMOps 质量工程关注 AI 应用上线后的效果评测、链路追踪、质量优化、灰度发布和持续反馈。它解决的是 AI 应用不可控、不可测、不可回归和难以稳定迭代的问题。

## 核心定位

- **让效果可评估**：通过评测集、Golden Answer、自动评分和人工评审衡量质量。
- **让问题可定位**：通过 Trace、Prompt 日志、Token、延迟和失败分析定位问题。
- **让迭代可回归**：通过版本管理、灰度发布、A/B 测试和回滚保障稳定性。

## 质量体系

| 能力 | 说明 |
|---|---|
| 评测体系 | 构建测试集、基准答案、评分规则和人工评审流程 |
| 可观测性 | 记录 Prompt、模型响应、检索结果、工具调用和成本指标 |
| 质量优化 | 治理幻觉、相关性、可引用性和用户反馈闭环 |
| 发布管理 | 管理 Prompt 灰度、A/B 测试、版本回滚和事故复盘 |

## 学习路线

1. 先建立评测集和质量指标，明确什么叫回答得好。
2. 再接入 Trace 和日志，保证每次模型调用都可以追踪。
3. 最后建立灰度、回滚和反馈闭环，让 AI 应用可以持续迭代。
