# 本地部署

## 核心优势

- **数据隐私**：所有数据在本地处理，不经过第三方服务器，适合敏感场景
- **零成本使用**：无需 API 费用，模型一次下载即可无限调用
- **离线可用**：不依赖网络，适合网络受限或断网环境

## 适用场景

本地部署适合以下使用场景：

- 对数据隐私有严格要求的企业应用
- 需要频繁调用 LLM 且想节省 API 成本的项目
- 离线环境下的 AI 功能集成
- 学习和实验开源大模型

## 技术栈

- **部署工具**：Ollama、vLLM、llama.cpp
- **开源模型**：Llama 3、Qwen、DeepSeek、Mistral
- **硬件要求**：NVIDIA GPU（推荐）、Apple Silicon
- **集成方式**：REST API、LangChain
