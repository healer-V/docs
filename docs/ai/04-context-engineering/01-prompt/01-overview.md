# 上下文工程概述

上下文工程关注如何把用户问题、系统指令、业务约束、历史对话、知识片段和工具结果组织成模型可以稳定理解的输入。它是 Prompt 工程的升级版，更强调上下文结构、记忆管理和可维护性。

## 核心定位

- **让模型理解任务**：通过角色、目标、约束、示例和输出格式降低模型偏差。
- **让上下文可管理**：处理历史压缩、记忆选择、知识拼装和上下文污染。
- **让 Prompt 可维护**：通过模板、版本、变量注入和结构化输出支持工程化迭代。

## 关键能力

| 能力 | 说明 |
|---|---|
| Prompt 设计 | 明确角色、任务、边界、示例、反例和输出格式 |
| 上下文拼装 | 组合用户输入、历史消息、知识检索结果和工具返回 |
| 记忆管理 | 区分短期记忆、长期记忆和可丢弃上下文 |
| 输出控制 | 使用结构化输出、解析规则和 Guardrails 提升稳定性 |

## 学习路线

1. 从 Prompt 基础结构开始，掌握任务描述、约束和示例的写法。
2. 进一步学习 Message 结构、上下文拼装和历史压缩策略。
3. 最后建立 Prompt 模板、版本管理和结构化输出的工程化机制。
