# 应用架构模块蓝图

应用架构负责把前面模块中的单个能力放进一个可运行的服务：谁持有凭据、请求走同步还是异步、会话和业务状态存在哪里、流式交互和后台任务如何去重与恢复、模型结果怎样成为可审计的业务记录，以及直接调用、RAG 与 Agent 三种架构如何选择。知识讲解沿用 HTML、JavaScript 已确认的方式；每篇示例从读者新建的空目录独立复现，只包含验证当前问题所需的最小服务，不使用贯穿工程。

目录已于 2026-11-15 由用户确认（6 章 15 篇，标题与 catalog 一致）；本蓝图于 2026-11-18 起草，**待用户确认**。正文尚未编写，下文执行证据均为计划验证。

外部基础入口为 [FastAPI 教程](https://fastapi.tiangolo.com/tutorial/) 与 [sqlite3](https://docs.python.org/3.12/library/sqlite3.html)。本模块不展开 Web 框架基础，示例只使用当前篇必要的路由与依赖。

唯一主讲约定：网关只定义职责与路由接入点，路由策略与降级归 AI10；会话保存只设计数据边界，保留与删除策略归 AI09；后台任务讲业务状态与结果恢复，队列与工作进程的运行机制归 AI10；人工复核讲业务流转，统一审计治理归 AI09。
