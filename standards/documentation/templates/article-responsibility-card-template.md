# 文章职责卡模板

尖括号字段必须在模块蓝图中替换为当前文章的实际内容。职责卡用于限制正文范围，不是发布到教程中的文章目录。

## 一、文章身份

| 字段 | 内容 |
|------|------|
| 文章 ID | `<与章节和文件编号一致的 ID>` |
| 文件路径 | `<仓库相对路径>` |
| 文章标题 | `<直接描述唯一学习问题的标题>` |
| 所属章节 | `<章节 ID 和标题>` |
| 唯一学习问题 | `<读者通过本文需要解决的一个明确问题>` |

## 二、知识归属

| 字段 | 内容 |
|------|------|
| 前置知识项 | `<知识项 ID；没有则写“无”>` |
| 负责知识项 | `<由本文完整讲解的知识项 ID>` |
| 引用知识项 | `<只保留最小说明并链接主讲文章的知识项 ID>` |
| 后续依赖者 | `<依赖本文的文章 ID，用于蓝图检查，不写入正文串联>` |

## 三、内容契约

| 字段 | 内容 |
|------|------|
| 主文章类型 | `<基础概念/语法与 API/运行机制/接入教程/设计与实践/测试与排障/速查与参考>` |
| 辅助文章类型 | `<最多一个；没有则写“无”>` |
| 目标深度 | `<认识/使用/解释/设计/诊断>` |
| 必须覆盖 | `<当前文章必须完整说明的规则、API、机制或判断>` |
| 明确不覆盖 | `<其他文章负责或当前模块排除的内容>` |
| 版本边界 | `<主版本行为和差异内容归属>` |

## 四、证据与示例

| 字段 | 内容 |
|------|------|
| 核心证据 | `<代码、配置、命令、输出、日志、指标、图、案例或决策表>` |
| 示例场景 | `<与章节统一场景的关系；不适用则说明>` |
| 执行环境 | `<运行时、依赖和必要服务>` |
| 触发方式 | `<命令、调用、操作或测试入口>` |
| 预期结果 | `<可以观察的真实结果>` |
| 失败边界 | `<至少一个必要错误、边界或反例及判断方式>` |
| 验证状态 | `<计划验证/已运行/仅编译/局部示例/无法验证>` |

“计划验证”只能出现在蓝图阶段。文章交付时必须更新为实际状态；核心证据仍为“无法验证”时，文章不得通过质量门禁。

## 五、重复与链接

| 可能重叠的文章 | 重叠知识 | 完整讲解位置 | 当前文章处理方式 |
|----------------|----------|--------------|------------------|
| `<文章 ID>` | `<知识项 ID>` | `<主讲文章 ID>` | `<最小说明和相对链接>` |

## 六、完成标准

- [ ] 正文只回答唯一学习问题；
- [ ] 负责知识项达到目标深度；
- [ ] 主文章类型与证据形式匹配；
- [ ] 必须覆盖和明确不覆盖边界得到遵守；
- [ ] 示例具有用途、触发方式、结果和解释；
- [ ] 失败边界具有现象、原因、证据和处理方式；
- [ ] 没有重复其他文章负责完整讲解的知识；
- [ ] 版本和来源与模块蓝图一致；
- [ ] 满足单篇文档内容契约和根目录 `AGENTS.md`。
