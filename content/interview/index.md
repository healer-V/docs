# 面试题库

题库按开发方向分为四部分。每道题先给出可以直接作答的结论，再解释机制、成立条件和常见误区，并附官方资料链接，方便应对面试官的追问。各篇开头注明了题目依据的版本，版本更新后行为可能不同。

## 一、题库与主题

| 题库 | 主题范围 | 版本基线 | 入口 |
|------|----------|----------|------|
| 前端开发篇 | HTML、CSS、JavaScript、ES6、TypeScript、Vue、React、工程化、网络、浏览器、手写题、项目常考 | 现代浏览器；Vue 3.5、React 18 | [HTML 面试题](./frontend/01-html.md) |
| Java 开发篇 | Java 基础、集合、并发、JVM、Spring、MySQL、Redis、分布式与微服务 | Java 21、Spring Boot 3.5、MySQL 8.4、Redis 7 | [Java 基础面试题](./java/01-java-basics.md) |
| 全栈开发篇 | Node.js、接口设计、认证与 Web 安全、SSR 与全栈框架、部署与运维、系统设计 | Node.js 22 LTS、React 19 | [Node.js 面试题](./fullstack/01-nodejs.md) |
| Agent 开发篇 | 大模型原理与调用、Prompt 与上下文工程、RAG、Agent 架构与框架、工具调用与 MCP/Skills、记忆与多 Agent、工程化、手撕与系统设计；按国内大厂面经整理 | 与具体厂商无关；MCP 以 2026-07-28 规范为准 | [大模型原理与调用面试题](./agent/01-llm-fundamentals.md) |

## 二、按岗位选择

前端岗位以前端开发篇为主；需要接触服务端或 BFF 时，再看全栈开发篇的 Node.js、接口设计和认证安全。Java 后端岗位以 Java 开发篇为主，全栈开发篇中的接口设计、Web 安全、部署与系统设计也常被追问。

大模型应用和 Agent 岗位先看 Agent 开发篇；实际项目还要编写后端服务和部署，可配合全栈开发篇的接口设计、部署与运维一起准备。左侧导航列出了每个题库的全部篇目。
