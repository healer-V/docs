# Prompt 与上下文

Prompt 是应用交给模型的任务契约，上下文是当前任务可以使用的信息集合。两者需要明确指令权威、数据来源、相关性、Token 预算、会话状态和变更证据，不能依赖不断追加自然语言修补结果。

## 三、职责关系

| 当前模块负责 | 其他模块负责 |
|--------------|--------------|
| 表达任务、指令和输出边界 | 模型接入负责请求字段与结构化接口 |
| 标记上下文来源、可信度和用途 | RAG 应用负责检索、重排和引用 |
| 选择会话状态模式与投影内容 | 应用架构负责权威业务状态和持久化 |
| 用样本回归管理 Prompt 变更 | 评测模块负责完整质量体系与线上反馈 |
| 识别不可信数据边界 | 安全模块负责攻击防护、权限和高风险动作控制 |

Prompt 结构清晰只能提高可解释性和可维护性。业务事实、授权和高风险动作仍必须由确定性应用逻辑控制。
