# CSS 与浏览器

**CSS**（层叠样式表）是描述文档如何呈现的语言。它为 HTML 元素指定颜色、字体、间距、布局和动效等规则，由浏览器根据这些规则生成页面。

CSS 表达的是“需要什么呈现结果”。例如写下 `color: green`，就是要求文字使用绿色；作者不需要编写逐个像素着色的程序。这种方式称为**声明式表达**。

## 一、HTML、CSS 与浏览器的分工

### 1. 结构与呈现

一个标题既有“这是标题”的含义，也有字号、颜色等外观。两类信息承担不同职责：

| 对象 | 负责什么 | 标题示例 |
|------|----------|----------|
| HTML | 内容、结构和语义 | `<h1>` 表示一级标题 |
| CSS | 文档的呈现规则 | 指定字号、颜色与间距 |
| 浏览器 | 解释 HTML 和 CSS，处理交互并呈现结果 | 生成标题盒子并绘制文字 |
| JavaScript | 编程行为和状态变化 | 响应按钮操作，修改内容或样式 |

CSS 能改变标题的外观，但把一个 `<div>` 放大不会赋予它标题语义。同样，改变按钮颜色不等于实现提交行为。

::: tip 先用 HTML 表达内容含义
标题使用标题元素，链接使用链接元素，操作使用按钮。CSS 在这些结构上控制呈现，读屏软件和浏览器仍可理解元素的用途。
:::

### 2. 没写 CSS 时为何仍有样式

浏览器通常带有自己的样式表，称为**用户代理样式表**。它为标题、段落、列表等元素提供基本外观，因此没有作者 CSS 的页面也不是毫无排版。

下面是局部 HTML，省略文档外壳。浏览器通常会把标题显示得比段落更大：

```html
<h1>页面标题</h1>
<p>页面的正文内容。</p>
```

添加这段局部 CSS 后，标题的文字改为绿色，字号由作者指定：

```css
h1 {
  color: green;
  font-size: 24px;
}
```

其他未覆盖的样式仍可能来自浏览器。这里的 `24px` 是 CSS 像素，不保证对应屏幕上的 24 个物理像素。

::: warning 默认外观与属性初始值有区别
属性的初始值由 CSS 属性定义；元素的默认外观可能来自浏览器样式表。例如 `display` 的初始值是 `inline`，但浏览器通常为 `<div>` 设置 `display: block`。
:::

## 二、样式、布局与绘制

浏览器呈现页面时，需要解决三个不同的问题：

1. **样式计算**：哪些规则适用？同一属性有多条声明时，最后使用什么值？
2. **布局**：元素生成哪些盒子？盒子的尺寸和位置是多少？
3. **绘制**：如何把背景、边框和文字画出来？重叠时谁在前面？

这三个名称描述呈现工作的职责。实际浏览器会缓存结果、合并任务和跳过不需要重做的工作，不能把它们理解为每次都完整执行的固定三轮程序。

修改不同属性，会影响不同范围：

| 修改 | 主要影响 | 可观察现象 |
|------|----------|------------|
| `color` | 文字的绘制样式 | 颜色变化，通常不改变盒子尺寸 |
| `font-size` | 字体度量及布局 | 字变大，可能换行并推开后续内容 |
| `display: none` | 盒子的生成 | 该元素及其后代不再产生显示盒子 |

::: info 层叠与层叠上下文是两个问题
**层叠**选择同一属性的胜出声明；**层叠上下文**组织重叠内容的绘制顺序。名字相近，但前者决定取值，后者决定前后关系。
:::

## 三、CSS 的能力边界

### 1. 隐藏内容不等于删除内容

`display: none` 会让内容退出视觉布局，通常也会使它退出无障碍树，但 HTML 元素仍存在于 DOM 中。**DOM**是浏览器用于表示文档结构的对象树，脚本仍能找到和修改该元素。

下面只展示局部样式，假设 HTML 已包含 `.notice` 元素：

```css
.notice {
  display: none;
}
```

移除这条样式，内容可以重新呈现；通过脚本删除 DOM 元素则改变了文档结构。两种行为不能混用来判断“数据是否还存在”。

### 2. CSS 按模块演进

现代 CSS 由选择器、颜色、Flexbox、Grid、定位等多个模块共同组成。各模块分别推进自己的规范级别，因此不能把所有新能力归为一个统一发布的“CSS4”。

使用一个特性时，应检查**具体属性、值或 API**的支持情况。例如浏览器支持 Grid，不代表它同时支持所有 Grid 的扩展能力。特性的介绍与演进方式可参照 [MDN CSS 概览](https://developer.mozilla.org/en-US/docs/Web/CSS) 和 [CSS Snapshot](https://www.w3.org/TR/CSS/)。

::: tip 判断 CSS 是否满足需求
内容含义由 HTML 提供，呈现规则由 CSS 描述，复杂行为由脚本处理。遇到样式问题时，先分清它属于规则取值、盒子布局还是绘制顺序，才能选择合适的检查位置。
:::
