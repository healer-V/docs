# CSS 边框、阴影与轮廓

**边框**属于盒模型，**阴影**和**轮廓**主要属于绘制装饰。它们都能出现在盒子边缘，但对布局尺寸和可见范围的影响不同。

## 一、边框与圆角

### 1. 边框的宽度、样式与颜色

`border` 是宽度、样式和颜色的简写。未指定有效样式时，即使写了宽度也可能没有可见边框，因为默认边框样式为 `none`。

以下是局部样式，假设页面已包含 `.box`：

```css
.box {
  width: 200px;
  height: 80px;
  box-sizing: content-box;
  border: 2px solid #166534;
}
```

没有内边距时，边框框尺寸为 `204px × 84px`。切换为 `border-box` 后，指定宽高包含边框，内部内容区域相应缩小。

动态状态如果从“无边框”切到“有边框”，可能改变尺寸或内部空间。可以先保留透明边框，再只切换颜色，减少这种状态变化。

### 2. 圆角的作用范围

`border-radius` 控制边框轮廓和背景的圆角。它不自动裁剪所有后代内容，子级图片或背景仍可能超出父级圆角。

需要裁剪时可以结合 `overflow`，但也会影响菜单、阴影和焦点轮廓。因此最好把需要裁剪的装饰区域与交互内容分开。

::: warning 圆角不等于后代裁剪
先确认超出的是父级背景还是子级内容，再决定是否增加裁剪。不要为了圆角效果，无条件在整个组件上写 `overflow: hidden`。
:::

## 二、盒阴影与文字阴影

### 1. box-shadow

常见语法包含水平偏移、垂直偏移、模糊半径、扩散半径和颜色，还可以用 `inset` 表示内阴影。多个阴影用逗号分隔，先写的位于前方。

下面是局部样式，省略未修改的尺寸规则：

```css
.box {
  box-shadow: 0 4px 12px 0 rgb(0 0 0 / 0.15);
}
```

阴影向外绘制，不为邻近盒子自动保留间距，也不增加 `getBoundingClientRect()` 的边框框尺寸。父级裁剪可能使外阴影不可见。

### 2. text-shadow

`text-shadow` 按文字字形绘制阴影，不支持 `box-shadow` 的扩散半径和 `inset`。以下是局部标题样式：

```css
.heading {
  text-shadow: 0 1px 1px rgb(0 0 0 / 0.15);
}
```

阴影不会增加文字的布局尺寸。模糊过强可能降低清晰度，不能用它代替文字与背景的基本对比。

::: info 阴影描绘的对象不同
`box-shadow` 跟随盒子轮廓，`text-shadow` 跟随字形；`filter: drop-shadow()` 则按输入图像的透明轮廓形成效果，使用边界见[变换与视觉效果](./04-transforms-effects.md)。
:::

## 三、轮廓与焦点提示

`outline` 在盒子边缘之外绘制轮廓，不占据盒模型中的边框空间。`outline-offset` 调整它与边界的距离，可以为正或为负。

以下是局部按钮样式，保留清晰的键盘焦点反馈：

```css
.action:focus-visible {
  outline: 2px solid #166534;
  outline-offset: 3px;
}
```

轮廓可能与其他元素重叠或被裁剪。检查时应实际用 Tab 移动焦点，而不是只在工具里强制显示一个状态。

::: warning 移除轮廓前提供可见替代
`outline: none` 会移除常见焦点指示。背景颜色微小变化、阴影或只有鼠标悬停的效果，未必足以让键盘用户识别当前位置。
:::

## 四、对照装饰与测量结果

假设 `.box` 使用第一节的 `content-box` 尺寸，以下是当前页面中的局部读取动作：

```js
const box = document.querySelector('.box');
box.getBoundingClientRect().width; // 204
```

依次添加阴影和 `outline: 2px solid`，测量宽度仍为 `204`。边框参与尺寸，阴影与轮廓只扩展可见装饰范围。

| 改动 | 是否占据盒模型空间 | 是否可能超出边框框 |
|------|--------------------|--------------------|
| 边框 | 是 | 边框框包含它 |
| 圆角 | 不新增空间 | 不自动裁掉所有后代 |
| 盒阴影、文字阴影 | 否 | 是 |
| 轮廓 | 否 | 是 |

如果装饰缺失，先检查属性语法和实际颜色，再看祖先裁剪；如果布局移动，先检查边框及尺寸模式。规范见 [CSS Backgrounds and Borders](https://www.w3.org/TR/css-backgrounds-3/) 与 [CSS UI 轮廓](https://www.w3.org/TR/css-ui-4/#outline)。
