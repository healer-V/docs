# CSS 选择器匹配

**选择器**是寻找样式目标的条件。只有元素满足选择器条件，规则中的声明才有机会应用到它；匹配成功不代表这些声明一定会在冲突中胜出。

## 一、用元素自身的特征匹配

### 1. 基本选择器

| 选择器 | 匹配条件 | 示例 |
|--------|----------|------|
| 类型 | HTML 元素名称 | `button` 匹配按钮 |
| 类 | `class` 包含指定类名 | `.action` |
| ID | `id` 等于指定值 | `#save` |
| 通配 | 任意元素 | `*` |
| 属性 | 存在属性或属性值满足条件 | `[disabled]`、`[type="email"]` |

一个元素可以同时拥有多个类，例如 `class="action primary"`。`.action.primary` 要求两个类都存在；`.action, .primary` 表示满足任意一项即可，逗号组成**选择器列表**。

以下是局部 HTML，省略文档外壳：

```html
<button id="save" class="action primary" type="button">保存</button>
<button class="action" type="button" disabled>删除</button>
```

下面的局部 CSS 用来核对匹配范围，省略其他页面样式：

```css
.action { padding: 8px; }
.action.primary { color: green; }
button[disabled] { opacity: 0.5; }
```

两个按钮都有内边距，只有保存按钮变绿，只有删除按钮变淡。`button[disabled]` 把类型和属性两个条件写在一起，称为**复合选择器**。

::: tip 类名适合表达可复用样式
类可以重复用于多个元素；ID 应在同一文档中唯一。选择器负责选中对象，类名本身不会自动赋予 HTML 语义或行为。
:::

### 2. 属性值的匹配方式

属性选择器不只有等于判断。以链接和语言属性为例：

| 写法 | 含义 |
|------|------|
| `[href^="https://"]` | 值以指定文本开头 |
| `[href$=".pdf"]` | 值以指定文本结尾 |
| `[href*="guide"]` | 值包含指定文本 |
| `[class~="action"]` | 空白分隔的词列表中存在完整词 |
| `[lang\|="zh"]` | 值是 `zh`，或以 `zh-` 开头 |

`[class*="action"]` 也会匹配 `transaction` 中的连续字符，因此不能替代 `.action`。需要按类名匹配时，应使用类选择器。

默认大小写规则取决于文档语言和属性定义。HTML 中类名与 ID 值通常区分大小写；属性值可通过 `i` 标志进行 ASCII 范围的不区分大小写比较，例如 `[data-state="ready" i]`。不要把所有属性都当成同一种大小写规则。

## 二、用元素之间的关系匹配

### 1. 后代与子代

**后代**包括所有层级的后辈元素；**子代**只包含紧邻的下一层。以下局部 HTML 故意包含一层嵌套，用来观察差异：

```html
<div class="toolbar">
  <button>直属按钮</button>
  <div><button>嵌套按钮</button></div>
</div>
```

对应的局部 CSS：

```css
.toolbar button { color: green; }
.toolbar > button { border: 2px solid red; }
```

两个按钮都变绿，只有直属按钮有红色边框。空格表示后代，`>` 表示子代。

::: warning 空格改变匹配对象
`.action.primary` 匹配同时拥有两个类的同一元素；`.action .primary` 匹配 `.action` 内部的 `.primary` 后代。这两种写法不能互换。
:::

### 2. 相邻与后续兄弟

**兄弟元素**具有同一个父元素。兄弟组合器还要求目标位于前一个条件之后：

| 写法 | 匹配的目标 |
|------|------------|
| `.field + .hint` | 紧接在 `.field` 后面的一个 `.hint` 兄弟 |
| `.field ~ .hint` | `.field` 后面所有符合 `.hint` 的兄弟 |

文本节点和注释不影响这里的元素相邻关系，但中间插入另一个元素会影响 `+`。它们也不会跨父元素寻找兄弟。

## 三、判断一条规则的匹配范围

复杂选择器的最右侧通常是被设置样式的目标，其左侧用于限制关系。例如 `.panel > .toolbar button` 设置按钮的样式：

1. 目标必须是 `button`。
2. 它必须位于 `.toolbar` 内部，可以隔着多层。
3. 该 `.toolbar` 必须是 `.panel` 的直属子元素。

这是一种阅读方法，不是对所有浏览器内部算法的承诺。规则的形式化定义见 [Selectors Level 4](https://www.w3.org/TR/selectors-4/)。

在开发者工具中选中目标元素后，按以下顺序检查：

1. 确认实际标签名、类名、属性值和父子关系。
2. 查看 Styles 面板是否出现目标规则。没有出现时，先查选择器、样式加载和条件规则。
3. 如果规则出现但声明被划线，再检查[层叠与优先级](./03-cascade-specificity.md)。

::: info 匹配与继承分开判断
父元素被选中，不意味着后代也匹配这个选择器。后代文字颜色发生变化，可能来自继承；它和直接匹配是两条不同路径。
:::
