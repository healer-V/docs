# CSS 值、单位与函数

**属性值**必须符合对应属性允许的类型和规则。长度、百分比、颜色、时间和关键字不是可随意互换的字符串；写法正确还需要参考对象和计算条件成立。

## 一、值类型与属性语法

| 类型 | 示例 | 常见用途 |
|------|------|----------|
| 关键字 | `auto`、`none`、`block` | 选择属性定义的行为 |
| 数值 | `1.5`、`0` | 行高、透明度、增长因子等 |
| 长度 | `12px`、`2rem` | 尺寸、间距、偏移 |
| 百分比 | `50%` | 相对该属性指定的参考量 |
| 颜色 | `#166534`、`rgb(22 101 52)` | 文字、背景、边框 |
| 时间 | `200ms`、`0.2s` | 过渡和动画 |

阅读属性的正式语法时，`<length>` 表示长度类型，`<percentage>` 表示百分比，`A | B` 表示选项，方括号把一组规则组合起来。例如允许 `<length-percentage>` 的属性可接受长度、百分比或其合法组合。

::: warning 关键字按属性解释
`auto` 的含义由属性及布局方式决定，不是统一的 `0` 或 `100%`。`width: auto` 和 `margin: auto` 处理的也不是同一问题。
:::

## 二、长度的参考对象

### 1. px、em 与 rem

`px` 是 CSS 像素，是网页布局的基准单位，不等于一个屏幕物理像素。页面缩放和设备像素比会影响实际显示。

| 单位 | 参考对象 | 边界 |
|------|----------|------|
| `px` | CSS 像素 | 值固定不等于显示不能缩放 |
| `em` | 当前元素的计算字号 | 用于 `font-size` 时参照父级字号 |
| `rem` | 根元素的字号 | 根元素的 `font-size` 自身使用 `rem` 时有初始值规则 |
| `ch` | 字体中“0”字符的字形进宽 | 不等于任意字符的平均宽度 |

下面是局部 CSS，假设 `.child` 位于 `.parent` 中，省略 HTML 外壳：

```css
html { font-size: 16px; }
.parent { font-size: 20px; }
.child {
  font-size: 1.5em;
  padding: 1em;
  margin: 1rem;
}
```

子级字号为 `30px`；子级内边距参照它自己的字号，为 `30px`；外边距参照根字号，为 `16px`。不能把三个相对值都乘父级的 `20px`。

::: tip 单位表达依赖关系
需要跟随局部字号的间距可用 `em`；需要跟随页面根字号的尺度可用 `rem`。选择单位时先决定跟随谁，不以“某个单位一定更先进”作判断。
:::

### 2. 百分比没有统一基准

百分比的参考对象由属性定义：`font-size` 通常参照父级字号，常规块级 `width` 参照包含块宽度，`transform: translateX(50%)` 通常参照自身变换参考框的宽度。

在水平书写模式下，常规块级盒子的上下 `padding` 百分比也以包含块宽度为参考，而不是以高度为参考。百分比高度则经常需要确定的参考高度，具体见[包含块与定位](../03-visual-formatting-model/07-containing-block-position.md)。

### 3. 视口单位

**视口**是浏览器用于呈现文档的可见区域。`1vw` 对应视口宽度的 1%，`1vh` 对应视口高度的 1%。移动端浏览器工具栏的展开与收起会带来高度差异。

| 单位 | 参考高度 | 适用考虑 |
|------|----------|----------|
| `svh` | 小视口高度 | 工具栏展开时也能放下内容 |
| `lvh` | 大视口高度 | 工具栏收起后的空间 |
| `dvh` | 动态视口高度 | 随工具栏状态变化，可能触发尺寸调整 |

传统 `vh` 按大视口单位定义。需要可见区域填充时，应先用 `min-height` 保留内容增长空间，再按目标浏览器选择动态或小视口单位。定义见 [CSS Values and Units](https://www.w3.org/TR/css-values-4/#viewport-relative-lengths)。

## 三、数学函数

### 1. calc 的类型与运算

`calc()` 在允许的值类型中组合算式。以下是局部尺寸规则，省略元素结构：

```css
.panel {
  width: calc(100% - 32px);
  padding: calc(1rem + 4px);
}
```

第一项在得到百分比参考宽度后减去 `32px`，第二项组合根字号尺度与固定补偿。加减号两侧要有空格，且结果类型必须被目标属性接受。

::: warning 算式不能消除类型约束
`width: calc(1s + 10px)` 混合时间与长度，不能成为合法宽度。`var()` 也不能在替换后绕过属性语法。复杂的带单位乘除还有支持差异，跨浏览器基础示例优先使用长度加减及无单位倍率。
:::

### 2. min、max 与 clamp

| 函数 | 结果 | 例子 |
|------|------|------|
| `min(a, b)` | 取较小值 | `width: min(100%, 40rem)` |
| `max(a, b)` | 取较大值 | `padding: max(12px, 1rem)` |
| `clamp(min, preferred, max)` | 首选值受上下界约束 | `gap: clamp(8px, 2vw, 24px)` |

`width: min(100%, 40rem)` 使盒子不超过可用宽度和 `40rem` 两个限制。`clamp()` 的三个参数都要有可以比较的类型；若最小值大于最大值，最小值优先，因此应先检查边界是否合理。

下面是局部间距规则，首选间距随视口宽度变化：

```css
.list {
  display: grid;
  gap: clamp(8px, 2vw, 24px);
}
```

视口宽度为 `390px` 时，`2vw` 为 `7.8px`，结果被下限限制为 `8px`；视口宽度为 `1440px` 时，首选值为 `28.8px`，结果被上限限制为 `24px`。

## 四、数值与单位的易错边界

1. 长度 `0` 通常可以省略单位，但时间通常仍需写 `0s` 或 `0ms`；不能对所有类型套用无单位零。
2. `opacity: 0.5` 使用数值；`font-size: 1.5` 缺少合法长度或其他允许形式，不等于 `1.5px`。
3. 数学函数表达值关系，不会让盒子绕过最小尺寸、内容尺寸或 Flex/Grid 的布局约束。

查看异常尺寸时，先检查属性允许的类型，再找相对单位的参考量，最后检查布局限制。只看 CSS 中写出的数字，无法确定最终盒子尺寸。
