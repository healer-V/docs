# CSS 继承与默认值

**继承**是子元素取得父元素属性值的机制。并非所有属性都会继承：文字颜色与字号通常继承，宽度、内边距和边框通常不继承。

**默认值处理**保证没有普通取值声明的属性也能获得值：可继承属性通常取父元素的计算值，其他属性取规范定义的初始值。

## 一、哪些属性会继承

### 1. 文字与盒子的差异

继承让正文的字体与颜色能在一个祖先上统一设置。尺寸和边距若也自动继承，子元素就会意外重复祖先的几何约束，因此这些属性通常各自取值。

以下是局部 HTML，省略文档外壳：

```html
<div class="panel">
  <p class="text">继承文字样式。</p>
</div>
```

对应局部 CSS：

```css
.panel {
  color: green;
  font-size: 20px;
  padding: 24px;
}
.text { margin: 0; }
```

段落的文字为绿色，字号为 `20px`；段落不会自动取得 `24px` 的内边距。外层内边距让段落与外层边缘保持距离，不是段落继承了这项属性。

::: tip 通过属性定义核对继承
属性文档的“继承”字段决定默认传递行为。不要凭名称猜测，也不要把祖先样式造成的视觉影响都称为继承。
:::

### 2. 传递的是父级计算值

继承不是把父级的 CSS 文本复制到子级再计算。父级 `font-size: 2em` 算出 `32px` 后，未声明字号的子级通常继承 `32px`，不会再把自己放大两倍。

`line-height` 有一个值得单独判断的差异：无单位数值的计算值仍是数值，子级继承后可按自己的字号确定行高；长度或已计算的百分比则可能传递固定长度。具体文字排版见[字体与文本](../05-appearance-motion/01-fonts-text.md)。

## 二、初始值与默认外观

**初始值**是每个属性定义的起点；**用户代理样式**是浏览器为元素提供的声明。两者不是同一来源。

| 判断对象 | 例子 | 含义 |
|----------|------|------|
| 属性初始值 | `display` 的初始值为 `inline` | 来自属性定义 |
| 元素默认样式 | `<div>` 通常呈现为块级 | 浏览器规则设置了 `display: block` |
| 继承结果 | 子段落跟随父级颜色 | 来自父元素的计算值 |

根元素没有父元素，不能从文档外再继承一个值，因此需要初始值作为起点。其他元素仍需先检查自身的适用声明，不能跳过层叠直接继承。

::: warning 子元素自己的声明优先于默认继承
若父级使用 `#panel { color: red; }`，子级使用 `p { color: green; }`，段落仍为绿色。两条选择器作用于不同元素，不能拿它们的权重直接比较。
:::

## 三、五个全局关键字

### 1. 继承与初始值控制

全局关键字可用于大多数 CSS 属性，明确指定取值来源：

| 关键字 | 作用 |
|--------|------|
| `inherit` | 显式取父元素的计算值，包括原本不继承的属性 |
| `initial` | 取该属性的规范初始值 |
| `unset` | 可继承属性相当于 `inherit`，否则相当于 `initial` |
| `revert` | 回退当前层叠来源，重新从较低来源及默认机制取值 |
| `revert-layer` | 回退当前层叠层，按层叠规则查找可用的其他层 |

下面的局部规则适用于前面的 `.panel`、`.text`，用于显式传递内边距：

```css
.text {
  padding: inherit;
}
```

此时段落也有 `24px` 内边距，祖先与子级各贡献一层间距。`inherit` 改变的是属性的取值方式，不会消除祖先原有的内边距。

### 2. revert 与 revert-layer

作者样式中的 `display: revert` 可以恢复较低来源提供的外观；`display: initial` 则直接使用 `inline`。因此恢复浏览器外观与清到属性起点是不同操作。

下面是局部层叠示例，假设 `.text` 为段落：

```css
@layer base, theme;
@layer base { .text { color: green; } }
@layer theme {
  .text { color: red; }
  .text { color: revert-layer; }
}
```

`theme` 中胜出的 `revert-layer` 回退该层，颜色来自 `base` 的绿色。它不是让同层中前一条红色声明重新胜出。定义见 [CSS 默认值处理](https://www.w3.org/TR/css-cascade-5/#defaulting)。

::: info 全局关键字也要先参与层叠
`initial` 或 `revert` 不会自动赢过其他声明。只有包含它的声明胜出后，浏览器才执行对应的默认取值规则。
:::

## 四、all 的重置范围

`all` 可以把大量属性一起设置为某个全局关键字，例如 `all: revert`。它不重置 `direction`、`unicode-bidi` 和自定义属性。

下面是局部重置声明，省略元素结构：

```css
.isolated-control {
  all: revert;
  font: inherit;
}
```

这会回退大部分作者样式，再显式使用父级字体。它不是完整的样式隔离方案；继承、自定义属性以及外部后写规则仍需判断。

::: warning 大范围重置会移除必要表现
`all: unset` 可能移除按钮边框、焦点提示及布局默认值。使用前逐项验证控件外观、键盘焦点和状态，不能把它当成无成本的通用清理。
:::
