# CSS 伪类与伪元素

**伪类**根据元素的状态或结构关系匹配元素，例如获得焦点的按钮。**伪元素**选择元素的特定呈现部分，例如段落的首行或在元素前生成的装饰内容。

伪类通常写成 `:名称`，伪元素写成 `::名称`。两者都附着在选择器上使用，但选中的对象不同。

## 一、交互状态伪类

### 1. 状态由什么触发

| 伪类 | 条件 | 使用对象 |
|------|------|----------|
| `:hover` | 指针悬停 | 支持悬停的元素 |
| `:active` | 正在激活，常见于按下期间 | 按钮、链接等 |
| `:focus` | 获得焦点 | 可聚焦元素 |
| `:focus-visible` | 获得焦点且浏览器判断需要焦点提示 | 常见于键盘导航 |
| `:checked` | 选中 | 复选框、单选框等 |
| `:disabled` | 原生禁用状态 | 支持禁用的表单控件 |

给 `<div>` 写 `disabled` 属性不会自动使它符合 `:disabled`，因为 HTML 没有为这个元素定义相同的禁用行为。

### 2. 鼠标与键盘分别验证

以下是局部 HTML，省略文档外壳：

```html
<button class="action">确认</button>
<label><input type="checkbox"> 接收通知</label>
```

对应的局部 CSS：

```css
.action:hover { background: #e7f6ee; }
.action:focus-visible { outline: 2px solid green; }
input:checked { accent-color: green; }
```

用鼠标悬停观察背景；按 Tab 让按钮获得键盘焦点，观察轮廓；切换复选框观察选中标记。三种状态独立存在，也可能同时发生。

::: warning 悬停反馈不能代替焦点反馈
触摸设备和键盘操作不一定产生同样的悬停状态。不要直接移除焦点轮廓；定制后应保留清晰的键盘焦点提示。
:::

## 二、结构与关系伪类

### 1. nth-child 与 nth-of-type

`nth-child()` 按同一父元素下的**元素兄弟位置**计数，位置从 1 开始；`nth-of-type()` 只在相同元素类型中计数。文本与注释不计入位置。

以下局部 HTML 用不同标签建立计数差异：

```html
<div>
  <h2>标题</h2>
  <p>第一段</p>
  <p>第二段</p>
</div>
```

1. `p:nth-child(2)` 匹配第一段，它是父元素的第二个元素子代。
2. `p:nth-of-type(2)` 匹配第二段，它是第二个 `p`。
3. `:nth-child(2n + 1)` 匹配第 1、3、5……个元素子代；`odd` 与这个序列相同。
4. `:nth-child(2 of .item)` 先在兄弟中筛选 `.item`，再匹配其中第二个，和 `.item:nth-child(2)` 不同。

列表出现额外标签后条纹错位时，应先核对计数集合，而不是立即增加更复杂的选择器。

### 2. 函数式伪类

| 写法 | 匹配含义 | 判断重点 |
|------|----------|----------|
| `:is(h1, h2)` | 满足任意一个参数 | 合并相同声明的目标 |
| `:where(.panel) p` | 在符合条件的范围内匹配段落 | `:where()` 本身不增加优先级 |
| `button:not(:disabled)` | 不满足排除条件 | 排除的是元素条件 |
| `.field:has(input:checked)` | 内部有符合关系的目标 | 最后被设置样式的是 `.field` |

`:has()` 是**关系伪类**。它也能检查相邻关系，例如 `h2:has(+ p)` 匹配后面紧接段落的标题，因此不应简单把它叫成“父选择器”。它不能随意嵌套 `:has()`，也不能把普通伪元素当作参数使用。具体限制见 [Selectors Level 4 的关系伪类](https://www.w3.org/TR/selectors-4/#relational)。

::: tip 匹配语义与优先级分别阅读
`:is()`、`:not()`、`:has()` 的权重由参数中最高的选择器决定；`:where()` 的权重为零。完整比较方式见[层叠与优先级](./03-cascade-specificity.md)。
:::

## 三、伪元素与生成内容

### 1. 选择呈现的一部分

常用伪元素包括 `::first-line`（首行）、`::first-letter`（首字母或对应首字符）、`::selection`（选中部分）与 `::marker`（列表标记）。它们各自允许的属性范围不同，不能默认支持普通元素的全部样式。

`::before` 与 `::after` 会在元素内容的前后生成盒子。下面是局部样式，假设页面有 `.required` 标签：

```css
.required::after {
  content: " *";
  color: #b42318;
}
```

标签后面应出现红色星号。`content` 为 `none` 或 `normal` 时，这类伪元素不会生成；空字符串 `""` 仍可生成用于装饰的盒子。

### 2. 生成内容的边界

伪元素不是作者直接写入的 DOM 子元素，不能用 `querySelector()` 找到一个普通的 `::after` 元素。图片等替换元素也不能按普通容器方式依赖 `::before`、`::after` 生成内容。

::: warning 关键信息保留在 HTML 中
表单必填含义、错误原因和按钮名称应由 HTML 与相应无障碍属性表达。生成内容对辅助技术的呈现存在差异，不适合承担唯一的业务信息。
:::

判断一段样式时，先问“是在选择某个状态的元素，还是在选择元素的一部分”。再检查触发条件、计数范围和支持的属性，通常比只记冒号数量更有用。
