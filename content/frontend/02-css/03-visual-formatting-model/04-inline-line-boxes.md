# CSS 行内布局与行盒

**行内布局**把文字和行内级盒子放进一行，空间不足时按断行规则分成多行。每一行占用的布局区域称为**行盒（line box）**；一个行盒可能包含多个元素的片段。

**行内盒**属于具体行内内容，**行盒**收集同一行中的内容。一个跨三行的 `<span>` 不是一个三行高的普通块，它可能在三条行盒中分别留下片段。

## 一、字号、行高与基线

### 1. 字号不等于行高

`font-size` 决定字体尺度，`line-height` 参与计算文字在行内布局中的高度。行盒还要容纳同行较高的图标或其他行内级盒子，因此最终行高不一定等于某一个元素写出的 `line-height`。

以下是局部 HTML，省略文档外壳：

```html
<p class="text">普通文字 <span class="large">较大文字</span></p>
```

对应局部 CSS：

```css
.text { font-size: 16px; line-height: 24px; }
.large { font-size: 28px; line-height: 36px; }
```

较大文字可能撑高这一行，后续行的位置也会受到影响。只设置段落的 `24px` 行高，不代表内部所有内容都被限制在 `24px` 高度中。

### 2. 基线与 vertical-align

**基线**是文字对齐使用的参考线。默认的行内级对齐通常是 `baseline`，字母中向下延伸的部分仍需要基线以下的空间。

| 值 | 判断对象 |
|----|----------|
| `baseline` | 按基线对齐 |
| `middle` | 元素中点与父级基线加半个 x 字符高度对齐 |
| `top` / `bottom` | 与行盒的相应边缘对齐 |
| 长度或百分比 | 相对基线调整位置，百分比参照自身行高 |

`middle` 不是对整个父盒进行几何垂直居中。`vertical-align` 主要用于行内级和表格单元格，不能用它直接居中普通块级元素。

## 二、行内盒的尺寸与装饰

### 1. 普通行内元素

对于 `<span>` 这类普通非替换行内元素，`width`、`height` 不按普通块级盒子的方式约束尺寸。水平内边距会影响同行空间，竖直内边距和边框可以绘制出去，但通常不会相应增加文字行盒的高度。

以下是局部样式，假设 `.tag` 位于多行段落中：

```css
.tag {
  padding: 12px 4px;
  border: 1px solid green;
  background: #e7f6ee;
}
```

标签的装饰可能覆盖相邻行。若需要一个具有独立宽高且会参与行高计算的完整盒子，可按需要使用 `inline-block`，而不是继续增加 `height`。

::: warning 可见装饰不等于布局占位
行内背景和边框能超出行盒，而后续内容仍按原来的行盒安排。排查文字重叠时，需同时查看行高与装饰范围。
:::

### 2. inline-block 与替换元素

`inline-block` 在外部作为一个行内级整体参与排列，内部可布局子内容；它接受宽高和内边距。图片等**替换元素**的内容由外部资源或浏览器控件实现，尺寸也有自己的规则。

以下局部样式把一个同行图标做成独立盒子：

```css
.icon {
  display: inline-block;
  width: 24px;
  height: 24px;
  background: green;
  vertical-align: middle;
}
```

假设 HTML 使用 `<span class="icon" aria-hidden="true"></span>`，图标有 `24px` 的盒子尺寸，并会参与行盒高度计算。`aria-hidden` 仅适用于这里没有独立信息的装饰图标。

## 三、图片底部空隙与断行

### 1. 基线空隙的来源

行内图片默认按基线对齐，行盒在基线下还为文字留出空间，因此图片底部常能看到空隙。它不一定是图片文件自带白边，也不一定是 `margin`。

处理方式按用途选择：

1. 图片独占一块时，可设置 `display: block`，使它退出行内布局。
2. 图片仍需与文字同行时，可调整 `vertical-align`，再检查实际对齐。
3. 只有容器不承载可读文字时，才谨慎考虑 `line-height: 0`，避免把文字行高一起清零。

::: tip 按图片用途修复
内容图片与文本同行时保留行内布局；独立展示图片时使用块级盒子。修复应对应布局用途，而不是在所有图片上统一删除空隙。
:::

### 2. 空白与可断行位置

普通行内元素之间的 HTML 空白可能成为可见间隔；换行也可能折叠成一个空格。长网址或连续字符是否能换行，则由 `white-space`、`overflow-wrap` 等规则决定。

行盒是布局结果，不是 HTML 源码中的每一行。相关定义见 [CSS 行内格式化模型](https://www.w3.org/TR/CSS22/visuren.html#inline-formatting)；断行属性的使用见[字体与文本](../05-appearance-motion/01-fonts-text.md)。
