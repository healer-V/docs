# CSS 浮动与清除

**浮动**（float）把盒子移向可用区域的一侧，让后续行内内容绕着它排列。浮动不按普通常规流块的方式占位，但仍会影响同一布局上下文中的行盒和其他浮动。

它适合图文绕排。操作栏、等宽列和二维页面结构通常更适合 Flexbox 或 Grid，因为那些需求是排列项目，而不是让文字绕过某个盒子。

## 一、浮动怎样影响周围内容

### 1. 行盒绕排

以下是局部 HTML，`.figure` 用来表示需要绕排的内容区域，省略文档外壳：

```html
<div class="article">
  <div class="figure">插图区域</div>
  <p>正文会在可用空间中绕过浮动区域；文字足够长时，后续行继续排列。</p>
  <p class="next">后续段落。</p>
</div>
```

对应局部 CSS：

```css
.article { width: 360px; }
.figure {
  float: left;
  width: 100px;
  height: 100px;
  margin-inline-end: 16px;
  background: #e7f6ee;
}
```

正文的行盒避开左侧浮动和它的外边距。若文字延伸到浮动底部之后，后面的行可重新利用完整宽度。

### 2. 块背景与文字不是同一对象

普通后续块的盒子可能延伸到浮动后方，而它内部的行盒避让浮动。因此给段落设置背景时，可能看到背景出现在浮动后面，文字却没有重叠。

若希望整个段落区域都避开浮动，可以根据布局意图让它建立独立 BFC，例如 `display: flow-root`。这会改变布局关系，不能与单纯的文字绕排混为一谈。

::: info 浮动仍有尺寸规则
浮动盒会按相应的块化和收紧尺寸规则布局。多个浮动能否并排取决于可用宽度，不是只写 `float: left` 就永远保持在一行。
:::

## 二、clear 控制后续盒子

`clear` 要求当前盒子避开同一 BFC 中、位于它之前的指定侧浮动。它通常通过增加清除间距，让盒子来到相应浮动下方。

| 值 | 需要避开的浮动 |
|----|----------------|
| `none` | 不要求清除 |
| `left` | 左侧浮动 |
| `right` | 右侧浮动 |
| `both` | 两侧浮动 |

在第一节的局部样式后加入以下规则：

```css
.next {
  clear: both;
}
```

“后续段落”应从浮动下方开始。被清除的是 `.next` 的位置；前面的 `.figure` 仍然浮动，`clear` 没有撤销它的 `float`。

::: warning clear 不是父级高度开关
它约束某个后续盒子的位置。父容器是否包含浮动，还取决于内部内容和格式化上下文；不能只给父级写 `clear: both` 就认为会包住自己的浮动子级。
:::

## 三、父容器包含浮动

### 1. flow-root

当容器里只有浮动，普通自动高度可能没有把浮动纳入。明确建立独立 BFC，能让容器的自动高度包含自己的浮动后代：

```css
.article {
  display: flow-root;
}
```

把正文临时移除，只保留 `.figure` 后，容器仍能包住浮动的高度。其边距折叠等变化见[格式化上下文](./05-formatting-contexts.md)。

### 2. 历史 clearfix

旧代码常在父容器末尾生成一个清除浮动的块。以下是局部样式，假设容器类名为 `clearfix`：

```css
.clearfix::after {
  content: "";
  display: block;
  clear: both;
}
```

这个生成的块被移到浮动下方，间接让容器的常规流内容延伸下去。它和 `flow-root` 的实现机制不同，改写旧布局后应重新验证间距和相邻浮动。

| 方式 | 直接表达的目的 | 需要关注 |
|------|----------------|----------|
| `flow-root` | 建立独立流布局，包含内部浮动 | 改变父子边距边界 |
| clearfix | 增加一个末尾清除块 | 占用伪元素，影响清除与间距 |
| `overflow: hidden` | 裁剪溢出并产生布局隔离 | 可能裁掉阴影、菜单和焦点轮廓 |

::: tip 浮动只服务于绕排需求
绕排用 `float`；后续内容需要移到浮动下方时用 `clear`；容器需要包含浮动时优先考虑 `flow-root`。三项分别解决不同问题。
:::

浮动位置和清除规则见 [CSS 浮动与清除](https://www.w3.org/TR/CSS22/visuren.html#floats)。
