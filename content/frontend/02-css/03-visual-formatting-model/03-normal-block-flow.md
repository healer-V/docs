# CSS 常规流与块级布局

**常规流**（normal flow）是没有浮动、绝对定位等特殊安排时，盒子参与的基本布局方式。其中，块级盒子沿块方向依次排列，行内内容在行内方向排成一行或多行。

在常见的水平书写模式下，块方向从上到下，行内方向通常从左到右；换成其他书写模式后，不能继续把“块方向”等同于“竖直方向”。

## 一、块级盒子的排列与宽度

### 1. 可用宽度与自动尺寸

普通块级盒子通常从一个新的块级位置开始，`width: auto` 利用包含块提供的可用宽度。它不是把内容宽度直接设置为 `100%`，而是连同水平内边距、边框和外边距一起满足布局约束。

以下是局部 HTML，省略文档外壳：

```html
<div class="container">
  <div class="first">第一块</div>
  <div class="second">第二块</div>
</div>
```

对应局部 CSS，两个子块没有水平外边距和边框：

```css
.container { width: 400px; }
.first { padding: 20px; background: #e7f6ee; }
.second { background: #e5e7eb; }
```

第一块的内容宽度为 `360px`，边框框宽度仍为 `400px`；第二块排在它的后面。增加第一块的内容高度，会把第二块推向后方。

### 2. 自动外边距居中

在普通块级布局中，已知宽度的盒子可以让两个行内方向外边距分配剩余空间。下面是局部规则，仍使用 `400px` 容器：

```css
.first {
  box-sizing: border-box;
  width: 240px;
  margin-inline: auto;
}
```

剩余 `160px` 被两边平均分配，各为 `80px`。`width: auto` 已用满空间时，单独写自动外边距通常不会出现同样的居中效果。

::: warning 普通块级布局的垂直 auto 不负责居中
`margin-block: auto` 在这种布局中不会把盒子自动放到父级中央。Flex/Grid 中的自动外边距有其他规则，需按实际布局判断。
:::

## 二、外边距折叠

**外边距折叠**是特定常规块布局条件下，接触的块方向外边距合并成一份间距。它不发生在所有盒子、所有方向或所有布局中。

### 1. 相邻块的外边距

下面是局部样式，两个块处于同一常规块布局中，没有其他隔开因素：

```css
.first { margin-block-end: 20px; }
.second { margin-block-start: 30px; }
```

两块之间的间距为 `30px`，不是 `50px`。折叠时取决于外边距的符号：

| 外边距组合 | 折叠结果 |
|------------|----------|
| `20px` 与 `30px` | 最大正值，即 `30px` |
| `20px` 与 `-8px` | 最大正值加最负值，即 `12px` |
| `-10px` 与 `-20px` | 最负值，即 `-20px` |

负结果可能使两个盒子的边界发生重叠，不能理解成内容被浏览器自动删去。

### 2. 父子外边距

父级与第一个常规流块级子元素之间，若没有边框、内边距、行内内容或独立格式化上下文等隔开因素，顶部外边距可能发生折叠。子级的间距会表现到父级之外。

底部折叠还要求父级的高度与最小高度等条件允许，不应仅凭“父子关系”判断。给父级添加边框、对应方向内边距或 `display: flow-root`，可根据需要阻断跨边界折叠。

::: tip 区分容器内部留白与外部间距
希望内容远离容器边缘时优先使用容器的 `padding`；希望整个盒子远离邻居时使用 `margin`。这能减少把子级外边距误当作容器内部留白的问题。
:::

### 3. 空块的外边距

没有内容、边框、内边距且高度条件允许的空块，其上下外边距可能互相折叠，再与相邻外边距形成同一组。一个空 `<div>` 不一定能可靠制造两段独立间隔。

若间距代表布局项目之间的距离，可在适合的 Flex/Grid 容器上使用 `gap`；若确实需要占位盒子，应明确它的尺寸和语义，而不是依赖偶然的折叠结果。

## 三、不发生折叠的情况

以下情况不能套用“取最大值”的结论：

1. 行内方向的外边距。
2. Flex 项目和 Grid 项目之间的外边距。
3. 浮动盒或绝对定位盒的外边距。
4. 跨独立格式化上下文边界的父子外边距；内部常规块之间仍可能折叠。

折叠规则见 [CSS 块级布局与外边距](https://www.w3.org/TR/CSS22/box.html#collapsing-margins)。测量时先看布局类型、方向及接触条件，再判断符号与结果。

::: info 负 margin 与 transform 不等价
负外边距会参与布局并可能影响后续盒子的位置；视觉变换通常保留原来的布局占位。看到重叠时，应先找出是哪一种机制造成的。
:::
