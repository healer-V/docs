# CSS 格式化上下文

**格式化上下文**是一组盒子共同采用的布局规则及其作用范围。常规块、行内、Flexbox 和 Grid 使用不同规则，所以同一项属性在不同上下文中可能表现不同。

需要分开两个问题：**当前盒子参与外部哪种布局**，以及**它为内部子内容建立哪种布局**。例如 Flex 容器可以作为块级盒子参与外部布局，内部的直属子盒则成为 Flex 项目。

## 一、上下文中的布局对象

| 上下文 | 主要对象 | 基本关系 |
|--------|----------|----------|
| 块格式化上下文（BFC） | 常规块级盒、浮动盒等 | 块排列、外边距及浮动相互作用 |
| 行内格式化上下文 | 文字和行内级盒子 | 断行、行盒和基线对齐 |
| Flex 格式化上下文 | Flex 容器与直属项目 | 按主轴分配空间、对齐 |
| Grid 格式化上下文 | Grid 容器与直属项目 | 按行列轨道放置和定尺寸 |

**BFC**（block formatting context）是布局隔离边界之一。边界内的浮动和边距按自身规则处理，不会任意与外部的布局过程混合。

普通 `display: block` 不会自动为每个元素建立独立 BFC；它的子块可能仍参与已有的 BFC。`display: flow-root` 则明确建立一个新的 BFC。

::: warning 不要把所有独立布局都称为 BFC
Flex 和 Grid 建立的是各自的格式化上下文。它们也有隔离效果，但内部项目不是按常规块级算法分配尺寸。
:::

## 二、BFC 的隔离效果

### 1. 自动高度包含内部浮动

浮动不会像普通常规流块一样直接撑开父级，但建立独立 BFC 的容器会在自动高度计算中包含它自己的浮动后代。

以下局部 HTML 只包含一个浮动块，省略文档外壳：

```html
<div class="container">
  <div class="float">浮动</div>
</div>
```

对应局部 CSS：

```css
.container { background: #e7f6ee; }
.float { float: left; width: 80px; height: 60px; }
```

容器可能没有可见的内容高度。为它加上 `display: flow-root` 后，自动高度包含 `60px` 的浮动内容，背景也能包住它。

### 2. 阻断跨边界外边距折叠

独立 BFC 的容器不会与自己的子元素跨边界折叠外边距。因此 `flow-root` 可以让第一个子块的顶部外边距留在容器边界以内。

但**内部相邻常规块之间**仍可能折叠。`flow-root` 建立边界，不是关闭内部所有折叠规则的开关。

### 3. 避让外部浮动

新 BFC 的边框框不与同一外部上下文中的浮动外边距框重叠。文本区域因此可作为整体避开浮动，而不是仅让内部的行盒绕排。

这种效果适用于需要独立区域的内容；如果目标就是图文绕排，不应无条件给每个段落加 `flow-root`。

::: tip 按需要的隔离效果选择属性
需要包含浮动、阻断父子边距折叠时，`flow-root` 表达的意图更直接。为建立 BFC 而使用 `overflow: hidden`，还会附带裁剪和滚动方面的变化。
:::

## 三、创建条件与副作用

除了 `flow-root`，浮动、绝对定位、`inline-block` 以及某些 `overflow` 值等，也可建立 BFC。完整条件见 [MDN 块格式化上下文](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Display/Block_formatting_context)。

这些属性各有本职工作：

| 选择 | 同时改变什么 |
|------|--------------|
| `flow-root` | 建立独立流布局边界 |
| `inline-block` | 在外部变为行内级整体，尺寸规则也改变 |
| `overflow: auto` | 建立滚动条件，必要时显示滚动条 |
| `overflow: hidden` | 裁剪可见内容，仍具有程序滚动能力 |

`overflow: clip` 本身不建立 BFC；需要裁剪并建立独立流布局时，可明确组合 `overflow: clip` 与 `display: flow-root`。

## 四、三个相近概念的区别

| 概念 | 负责的问题 | 常见观察项 |
|------|------------|------------|
| 格式化上下文 | 一组盒子怎样布局，在哪个边界隔离 | 浮动包含、项目排列、边距 |
| 包含块 | 尺寸和位置参照哪个区域 | 百分比、定位偏移 |
| 层叠上下文 | 重叠内容怎样分组绘制 | `z-index`、遮挡 |

一个元素可能同时承担多个角色，但角色不能相互替代。容器包含浮动，不代表它一定改变了 `z-index`；创建层叠上下文，也不代表它就成为所有后代的定位包含块。

::: info 用实际变化判断上下文
先确定子盒是普通块、行内盒还是 Flex/Grid 项目，再找容器建立的边界。只有确认布局对象之后，才应使用对应的尺寸与对齐规则。
:::
