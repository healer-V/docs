# 表达式与运算符

表达式是会产生值的代码片段，语句是组织执行的单位。`2 + 3` 是表达式，它的值是 `5`；`const total = 2 + 3;` 是语句，它把表达式的值绑定到名字上。运算符决定多个值怎样组合，优先级和结合性决定先算哪一步。

很多“结果不对”并不是运算符出错，而是分组不符合预期：`2 + 3 * 4` 先算乘法，`1 < 2 < 3` 先算左边的比较，`"1" + 2 + 3` 在遇到字符串后全部转为拼接。理解这些规则，才能判断表达式实际算了什么。

本篇先区分表达式与语句，再说明优先级与结合性，随后用页面逐条观察算术、比较、逻辑、赋值和逗号运算符的结果，最后复现两个常见失败：把 `=` 写成条件、把 `??` 与 `||` 直接混用。

::: info 本篇的范围
本篇讲表达式的组合与求值顺序，不展开类型转换的完整算法和位运算技巧。类型转换与相等性见“类型转换与相等性”，可选链与空值合并的组合用法见“可选链、空值合并与展开”。
:::

## 一、表达式与语句

### 1. 表达式产生一个值

字面量、变量、函数调用和运算符组合都是表达式。表达式可以出现在赋值右侧、函数参数、条件判断和另一个表达式内部。求值后得到一个值，这个值有类型。

```js
console.log(2 + 3); // 5
console.log("总价：" + 36); // "总价：36"
```

### 2. 语句组织执行

声明、赋值语句、条件语句、循环和 `return` 都是语句。语句不一定产生可用的值，它们负责声明名字、改变状态或控制流程。表达式语句是“求值后丢弃结果”的语句，例如单独一行的函数调用。

```js
const total = 12 * 3; // 声明语句，右侧是表达式
console.log(total); // 表达式语句，调用函数并丢弃返回值
```

### 3. 求值顺序

运算符的操作数通常从左到右求值，但优先级决定先组合哪一部分。含副作用的表达式（赋值、自增、函数调用）放在同一个表达式中时，顺序会影响结果。无法一眼看出顺序时，拆成多条语句比加括号更清楚。

```js
let index = 0;
console.log(index++); // 0，先取值再自增
console.log(index); // 1
```

## 二、优先级与结合性

### 1. 优先级决定分组

优先级高的运算符先结合操作数。乘除高于加减，幂高于乘除，比较高于逻辑运算，赋值最低。`2 + 3 * 4` 等价于 `2 + (3 * 4)`，结果是 `14`；写成 `(2 + 3) * 4` 才是 `20`。

```js
console.log(2 + 3 * 4); // 14
console.log((2 + 3) * 4); // 20
```

### 2. 结合性决定同级顺序

同级运算符按结合性分组。减法和除法是左结合，`10 - 3 - 2` 等价于 `(10 - 3) - 2`，结果是 `5`；幂是右结合，`2 ** 3 ** 2` 等价于 `2 ** (3 ** 2)`，结果是 `512`。

```js
console.log(10 - 3 - 2); // 5
console.log(2 ** 3 ** 2); // 512
```

### 3. 用括号表达意图

括号可以覆盖优先级和结合性，也能让读者不必记忆规则。复杂表达式、混用 `&&` 与 `||`、以及 `??` 与其他逻辑运算符相邻时，显式加括号更可靠。

```js
const isReady = (count > 0) && (status === "open");
```

::: tip 不确定就拆开
一个表达式里同时出现赋值、自增和函数调用时，优先拆成多条语句。括号只改变分组，不能让含副作用的代码变得易读。
:::

## 三、常用运算符的行为

### 1. 算术与幂运算

`+`、`-`、`*`、`/`、`%` 和 `**` 分别表示加、减、乘、除、取余和幂。`+` 在任一方是字符串时执行拼接，其余算术运算符把操作数转成数字。

```js
console.log(1 + 2 + "3"); // "33"
console.log("1" + 2 + 3); // "123"
```

`1 + 2` 先得到数字 `3`，再与字符串 `"3"` 拼接；第二行一开始就是字符串，后续全部拼接。

### 2. 比较运算符

`>`、`<`、`>=`、`<=` 比较大小，`===` 和 `!==` 判断严格相等。两个字符串按字符编码逐位比较，字符串与数字比较时字符串转成数字。

```js
console.log("10" < "9"); // true，字符串逐位比较
console.log("10" < 9); // false，字符串转成数字 10
```

需要比较数字时，先确认两侧都是数字，不要依赖隐式转换。

### 3. 逻辑运算符返回操作数

`&&` 和 `||` 不一定返回布尔值，而是返回决定结果的那个操作数。`&&` 在左操作数为假时返回左值，否则返回右值；`||` 在左操作数为真时返回左值，否则返回右值。

```js
console.log(0 || "默认"); // "默认"
console.log("a" && "b"); // "b"
```

这也是 `value || fallback` 能提供默认值的原因，但它会把 `0` 和空字符串也当成“没有值”，需要保留这些值时改用 `??`。

### 4. 空值合并与短路

`??` 只在左侧为 `null` 或 `undefined` 时返回右侧，`0`、`false` 和空字符串都会保留。逻辑运算符具有短路行为：左侧已经决定结果时，右侧不会求值。

```js
console.log(null ?? "默认"); // "默认"
console.log(0 ?? "默认"); // 0
```

短路会影响副作用。`false && increment()` 不会调用 `increment()`，`true || increment()` 也不会。把必须执行的函数放在短路右侧，是常见的漏执行原因。

### 5. 赋值与自增

赋值表达式返回被赋的值，可以链式赋值。自增 `++` 放在变量前返回新值，放在变量后返回旧值再自增。两者都会改变变量本身。

```js
let index = 0;
console.log(index++); // 0
console.log(++index); // 2
```

## 四、反直觉结果与失败写法

### 1. 连续比较不表示区间

`1 < 2 < 3` 为 `true`，但 `3 > 2 > 1` 为 `false`。`<` 和 `>` 从左到右结合，先算 `3 > 2` 得到 `true`，再比较 `true > 1`，布尔值转成数字 `1`，`1 > 1` 为 `false`。

```js
console.log(1 < 2 < 3); // true
console.log(3 > 2 > 1); // false
```

判断区间应写成 `value > 1 && value < 3`，而不是连续比较。

### 2. 赋值写成比较

把条件中的 `===` 写成 `=` 不会报错，赋值表达式返回被赋的值，非空字符串为真，于是分支总是进入：

```js
let status = "idle";
if (status = "done") {
  console.log("进入分支，status = " + status);
}
```

本次运行输出“进入分支，status = done”。修复是把条件改成 `status === "done"`，或先比较再赋值。编辑器通常会对条件中的赋值给出提示，但不要把提示当成错误已经修复。

### 3. 空值合并不能与逻辑运算符无括号混用

`??` 与 `||`、`&&` 直接相邻时是语法错误，必须加括号说明优先级：

```js
const value = null ?? "a" || "b";
// SyntaxError: Unexpected token '||'
```

写成 `(null ?? "a") || "b"` 或 `null ?? ("a" || "b")` 才能通过解析。两者结果可能不同，因此不能只为了消除报错随意加括号。

### 4. 字符串比较与数字比较混用

同一组值在字符串比较和数字比较下可能得到相反结果。表单输入默认是字符串，直接比较 `"10" < "9"` 会按字符逐位判断，得到 `true`；先转成数字再比较才是 `10 < 9` 的 `false`。

::: warning 先确认操作数类型
比较结果反常时，先打印两侧的类型和值，再决定是否需要显式转换。连续比较、字符串数字混用和赋值误写，是表达式结果“看起来不对”的三类常见来源。
:::

### 1. 创建页面

新建空目录 `js-expressions`，创建 `index.html`。脚本把每条表达式的结果写入列表，页面加载后显示完整对照。


创建 `assign.html`，把条件写成赋值：
