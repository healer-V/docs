Vue2 ​

一、Vue2 基础 ​

1、 Vue2 简介 ​

vue2是什么

    1. 一套用于构建用户界面的渐进式JavaScript 框架。
    1. Vue 被设计为可以自底向上逐层应用。
    1. 易用：Vue 的核心库只关注视图层，易于上手。
    1. 生态系统丰富：Vue 生态系统提供了大量的插件、工具和库，便于与第三方库或既有项目整合。
    1. 性能高效：Vue 相比于其他 Virtual DOM 库和框架，有着出色的性能表现。
    1. 轻量级: Vue 的核心库只有 7kb 大小。

2、 Vue2 语法特性 ​

TIP

    1. 组件化：基于组件的开发方式，允许开发者使用自定义组件封装可重用代码。
    1. 双向数据绑定：Vue 提供完整的双向数据绑定系统，从而实现 View 和 Model 之间的同步更新。
    1. 响应式：Vue 实现了响应式系统，能够自动追踪依赖关系并在数据变化时重新渲染组件。

3、 MVVM 模式 ​

TIP

    1. Model：Vue 实例的数据对象。
    1. View：Vue 实例的模板，即将数据渲染成视图的 HTML。
    1. ViewModel：Vue 实例的视图模型，连接 View 和 Model。

二、Vue2 语法 ​

1、Vue2 指令 ​

TIP

    1. v-text：绑定文本内容。
    1. v-html：绑定 HTML 内容。
    1. v-model：实现表单输入和数据双向绑定。
    1. v-if：条件渲染。
    1. v-show：条件展示。
    1. v-for：循环渲染。
    1. v-on：绑定事件。
    1. v-bind：绑定属性。
    1. v-cloak：延迟显示未编译的模板内容。

2、插值表达式 ​

TIP

    1. { { } }：双大括号，用于绑定数据。

3、自定义指令 ​

TIP

  • 全局指令：指令可以全局注册，所有组件实例均可使用。
  • 局部指令：指令只能在当前组件实例中使用。

3.1、 全局指令 ​

TIP

    1. Vue.directive：注册全局指令。
    1. el：指令所在元素。
    1. binding：指令绑定的数据对象。
    1. vnode：Vue 编译生成的虚拟节点。
    1. oldVnode：上一个虚拟节点。

示例：

js
// 注册全局指令
Vue.directive('my-directive', {
  bind: function(el, binding, vnode, oldVnode) {
    // 指令绑定时执行的函数
  },
  update: function(el, binding, vnode, oldVnode) {
    // 指令更新时执行的函数
  },
  componentUpdated: function(el, binding, vnode, oldVnode) {
    // 指令所在组件的更新完毕时执行的函数
  },
  unbind: function(el, binding, vnode, oldVnode) {
    // 指令解绑时执行的函数
  }
})

3.2、 局部指令 ​

TIP

    1. directives：注册局部指令。
    1. bind：指令绑定时执行的函数。
    1. update：指令更新时执行的函数。
    1. componentUpdated：指令所在组件的更新完毕时执行的函数。
    1. unbind：指令解绑时执行的函数。

示例：

js
// 注册局部指令
var vm = new Vue({
  el: '#app',
  data: {
    message: 'Hello Vue!'
  },
  directives: {
    'focus': {
      bind: function(el, binding) {
        el.focus()
      }
    }
  }
})

5、插槽 ​

作用

  1. 实现组件的内容分发。
  • 内容定制 ：内部部分内容可以由外部使用者传入，从而使组件具有更高的灵活性和复用性
  • 分离逻辑与内容：将组件的逻辑和展示内容分离开，使得组件更加容易维护和扩展。
  1. 支持组件的布局定制。
  • 灵活布局：使用者能够自定义组件的布局，从而调整组件内部元素的排列方式。
  • 适配不同场景：不同的媒体查询条件下，通过插槽能够轻松地适配不同的屏幕尺寸和设备类型
  1. 实现组件的可扩展性。
  • 插件化开发：插槽使得组件可以像插件一样进行扩展。
  • 组件组合：多个组件可以通过插槽相互嵌套和通信，形成更高级、更复杂的组件结构，从而实现更丰富的页面功能。

5.1、默认插槽 ​

TIP

  • 默认插槽：没有被指定名字的插槽，会被渲染为默认插槽。
  • 使用：
    • 在父组件中，使用<slot>标签作为默认插槽的占位符；
    • 在子组件中使用slot属性指定默认插槽的名字。
子组件
vue
<!-- MyBox.vue -->
<template>
  <div class="box">
    <slot>
      <!-- 这里可以设置插槽的默认内容 -->
      这是默认内容，当没有插入其他内容时会显示。
    </slot>
  </div>
</template>

<script>
export default {
  name: 'MyBox'
}
</script>
父组件
vue
<template>
  <div>
    <my-box>
      <p>这里是插槽内容</p>
    </my-box>
  </div>
</template>

<script>
import MyBox from './MyBox.vue'
export default {
  name: 'App',
  components: {
    MyBox
  }
}
</script>

<script>
export default {
  name: 'MyLayout'

5.3、作用域插槽 ​

作用域插槽

  • 作用域插槽：可以让我们将父组件的数据和方法传递给子组件，从而实现更灵活的组件间通信。
  • 使用：
    • 在父组件中，使用slot-scope属性定义作用域插槽；
    • 在子组件中，使用slot-scope属性绑定作用域数据。
子组件
vue
<template>
  <ul>
    <li v-ide="item in items">
      <!-- 通过slot-scope属性绑定作用域数据 -->
      <slot :item="item" :index="index">{{ item.name }}</slot>
    </li>
  </ul>
</template>

<script>
export default {
    name: 'ItemList',
    data() {
        return {
            items: [
                { id: 1, name: 'Item 1' },
                { id: 2, name: 'Item 2' },
                { id: 3, name: 'Item 3' },
            ]
        }
    }
}
</script>
父组件
vue
<template>
  <div>
    <h1>使用作用域插槽 - 缩写语法</h1>
    <ItemList>
      <template #default="slotProps">
        <!-- 访问作用域数据 -->
        <span>{{ slotProps.index + 1 }}. {{ slotProps.item.name }}</span>
      </template>
    <ItemList>
  </div>
</template>

<script>
import ItemList from './ItemList.vue'

export default {
  name: 'App',
  components: {
    ItemList
  }
}
</script>

6、动态组件 ​

动态组件

  • 是一种在运行时动态切换不同组件的技术，通过 <component> 内置组件和 is 属性实现。
  • <component> 元素
    • Vue 的内置组件，作为动态组件的容器占位符。
  • is 属性
    • 决定当前渲染哪个组件，值可以是：
    • 组件选项对象（直接导入的组件对象）
    • 已注册的组件名（字符串）
    • 异步组件（defineAsyncComponent）

6.1、 基本用法 ​

动态组件 Vue2版本
vue
<template>
  <div>
    <component :is="currentView"></component>
    <button @click="changeView">切换视图</button>
  </div>
</template>

<script>
export default {
  name: 'App',
  components: {
    Child1: { template: '<div>子组件1</div>' },
    Child2: { template: '<div>子组件2</div>' }
  },
  data() {
    return {
      currentView: 'Child1'
    }
  },
  methods: {
    changeView() {
      this.currentView = this.currentView === 'Child1' ? 'Child2' : 'Child1'
    }
  }
}
</script>
动态组件 Vue3版本
vue
<template>
  <component :is="currentComponent"></component>
</template>

<script setup>
import ComponentA from './ComponentA.vue'
import ComponentB from './ComponentB.vue'
import { ref } from 'vue'

const currentComponent = ref('ComponentA') // 默认显示 ComponentA
</script>

三、组件通信 ​

1、父子组件传值 ​

1.1、 父传子 ​

TIP

    1. 父组件通过props属性向子组件传递数据。
    1. 子组件通过this.$emit()方法触发一个事件，并将数据作为参数传递给父组件。

示例：

父组件
vue
<!-- 父组件 -->
<template>
    <child :msg="message"></child>
</template>

<script>
import Child from './Child.vue'
export default {
  data() {
    return {
      message: 'Hello Vue!'
    }
  }
}
</script>
子组件
vue
<!-- 子组件 -->
<template>
  <div>
    <p>{{ msg }}</p>
    <button @click="emitMessage">触发事件</button>
  </div>
</template>

<script>
export default {
  name: 'Child',
  props: ['msg'],
  methods: {
    emitMessage() {
      this.$emit('update:msg', 'Hello Vue2!')
    }
  }
}
</script>

1.2、 子传父 ​

TIP

    1. 子组件通过$emit()方法触发一个事件，并将数据作为参数传递给父组件。
    1. 父组件通过v-on指令监听子组件的事件，并将数据作为属性绑定到父组件的data对象上。

示例：

父组件
vue
<!-- 父组件 -->
<template>
  <div>
    <child @update:msg="message = $event"></child>
    <p>{{ message }}</p>
  </div>
</template>

<script>
export default {
  data() {
    return {
      message: ''
    }
  }
}
</script>
子组件
vue
<!-- 子组件 -->
<template>
  <div>
    <p>{{ msg }}</p>
    <button @click="emitMessage">触发事件</button>
  </div>
</template>

<script>
export default {
  name: 'Child',
  props: ['msg'],
  methods: {
    emitMessage() {
      this.$emit('update:msg', 'Hello Vue2!')
    }
  }
}
</script>

2、兄弟组件传值 ​

兄弟组件通信说明

  • 兄弟组件：指拥有同一个父组件的两个子组件，它们之间不能直接通信。
  • 通信方式：兄弟组件之间需要通过共同的父组件作为中介进行通信。
  • 实现原理：
    1. 子组件1 通过 $emit() 触发事件，将数据传递给父组件
    2. 父组件通过 v-on 监听子组件1 的事件，更新父组件的数据
    3. 父组件通过 props 将更新后的数据传递给子组件2
    4. 这样就实现了子组件1 向子组件2 传递数据
  • 适用场景：两个兄弟组件需要共享数据或进行数据同步

示例:

父组件 - 数据桥梁
vue
<!-- 父组件 -->
<template>
  <div>
    <child1 @send-message="handleMessage"></child1>
    <child2 :message="sharedMessage"></child2>
  </div>
</template>

<script>
import Child1 from './Child1.vue'
import Child2 from './Child2.vue'

export default {
  name: 'Parent',
  components: {
    Child1,
    Child2
  },
  data() {
    return {
      sharedMessage: '' // 共享数据
    }
  },
  methods: {
    // 监听子组件1 的事件，更新共享数据
    handleMessage(msg) {
      this.sharedMessage = msg
    }
  }
}
</script>
子组件1 - 发送数据
vue
<!-- 子组件1 - 发送数据 -->
<template>
  <div>
    <h3>子组件1</h3>
    <button @click="sendToSibling">向兄弟组件发送消息</button>
  </div>
</template>

<script>
export default {
  name: 'Child1',
  methods: {
    sendToSibling() {
      // 触发事件，将数据传递给父组件
      this.$emit('send-message', '这是来自子组件1的消息')
    }
  }
}
</script>
子组件2 - 接收数据
vue
<!-- 子组件2 - 接收数据 -->
<template>
  <div>
    <h3>子组件2</h3>
    <p>接收到的消息：{{ message }}</p>
  </div>
</template>

<script>
export default {
  name: 'Child2',
  props: {
    message: {
      type: String,
      default: ''
    }
  }
}
</script>

注意事项

  • 兄弟组件不能直接通过 props 通信，必须通过父组件作为中介
  • 父组件需要维护共享状态，监听子组件事件并更新数据
  • 如果兄弟组件通信频繁，可以考虑使用事件总线（EventBus）或状态管理工具（Vuex）

3、跨级组件传值 ​

TIP

    1. 跨级组件之间通过provide和inject进行通信。
    1. 父组件通过provide方法提供数据，子组件通过inject方法注入数据。
    1. 父组件通过v-on指令监听子组件的事件，并将数据作为属性绑定到父组件的data对象上。

示例：

父组件
vue
<!-- 父组件 -->
<template>
  <div>
    <child :msg="message"></child>
    <p>{{ message }}</p>
  </div>
</template>

<script>
import Child from './Child.vue'
export default {
  name: 'Parent',
  components: {
    Child
  },
  data() {
    return {
      message: ''
    }
  },
  provide() {
    return {
      message: this.message
    }
  }
}
</script>
子组件
vue
<!-- 子组件 -->
<template>
  <div>
    <p>{{ msg }}</p>
    <button @click="emitMessage">触发事件</button>
  </div>
</template>

<script>
export default {
  name: 'Child',
  props: ['msg'],
  inject: ['message'],
  methods: {
    emitMessage() {
      this.$emit('update:msg', 'Hello Vue2!')
    }
  }
}
</script>

4、Vuex 状态管理 ​

TIP

    1. Vuex 是一个专为 Vue.js 应用程序开发的状态管理模式。
    1. Vuex 采用集中式存储管理应用的所有组件的状态，并以相应的规则保证状态以一种可预测的方式发生变化。
    1. Vuex 的状态存储是响应式的。
    1. Vuex 包含了模块化、插件化、工具化的概念，使得它成为一个灵活的状态管理方案。

示例：

父组件
vue
<!-- 父组件 -->
<template>
  <div>
    <child :msg="message"></child>
    <p>{{ message }}</p>
  </div>
</template>
<script>
import Child from './Child.vue'
import { mapState } from 'vuex'
import { store } from '../store'

export default {
  name: 'Parent',
  components: {
    Child
  },
  computed: {
   ...mapState(['message'])
  },
  created() {
    this.$store.dispatch('getMessage')
  }
}
</script>
子组件
vue
<!-- 子组件 -->
<template>
  <div>
    <p>{{ msg }}</p>
    <button @click="emitMessage">触发事件</button>
  </div>
</template>

<script>
export default {
  name: 'Child',
  props: ['msg'],
  methods: {
    emitMessage() {
      this.$emit('update:msg', 'Hello Vue2!')
    }
  }
}
</script>
store.js
js
// store.js
import Vue from 'vue'
import Vuex from 'vuex'

Vue.use(Vuex)

export const store = new Vuex.Store({
  state: {
    message: 'Hello Vue!'
  },
  mutations: {
    updateMessage(state, message) {
      state.message = message
    }
  },
  actions: {
    getMessage({ commit }) {
      commit('updateMessage', 'Hello Vue2!')
    }
  }
})

5、自定义事件 ​

TIP

    1. 自定义事件是一种触发自定义行为的机制。
    1. 自定义事件可以绑定在元素、组件或根实例上。
    1. 自定义事件可以触发任意 JavaScript 代码。
    1. 自定义事件可以传递任意数据。

示例：

vue
<!-- 父组件 -->
<template>
  <div>
    <child :msg="message"></child>
    <p>{{ message }}</p>
  </div>
</template>

<script>
import Child from './Child.vue'
export default {
  name: 'Parent',
  components: {
    Child
  },
  data() {
    return {
      message: ''
    }
  },
  created() {
    this.$on('updateMessage', this.updateMessage)
  },
  methods: {
    updateMessage(message) {
      this.message = message
    }
  }
}
</script>
vue
<!-- 子组件 -->
<template>
  <div>
    <p>{{ msg }}</p>
    <button @click="emitMessage">触发事件</button>
  </div>
</template>

<script>
export default {
  name: 'Child',
  props: ['msg'],
  methods: {
    emitMessage() {

3、路由传参 ​

几种方式

  1. params 传参：通过动态路由参数传递，参数会显示在 URL 路径中
  2. query 传参：通过查询字符串传递，参数会显示在 URL 的 ? 后面
  3. props 传参：将路由参数作为组件的 props 传递，更符合组件化开发规范

3.1、params 传参（动态路由参数） ​

说明

params 传参是通过动态路由参数传递数据的方式。参数会直接显示在 URL 路径中，格式如 /user/123。这种方式适合传递必需的、结构化的参数，如用户 ID、文章 ID 等。

特点：

  • 参数会显示在 URL 路径中
  • 使用动态路由占位符 :id 定义参数
  • 参数是路由的一部分，刷新页面参数不会丢失
  • 使用 params 传参时，必须使用命名路由（name），不能使用 path
  • 适合传递必需的、结构化的参数

// router/index.js
export default new VueRouter({

    },
    {
      path: '/user/:id/:name',  // 多个参数
      name: 'UserDetail',
      component: () => import('@/views/UserDetail.vue')
    }
  ]
})

3.3、props 传参 ​

说明

  • props 传参是将路由参数作为组件的 props 传递的方式。
  • 这是最符合 Vue 组件化开发规范的传参方式，可以让组件不直接依赖 $route 对象，提高组件的可复用性和可测试性。

  • 将路由参数转换为组件的 props，组件不直接依赖 $route
  • 提高组件的可复用性和可测试性
  • 支持三种模式：布尔模式、对象模式、函数模式
  • 更符合组件化开发规范
  • 组件可以在非路由环境下使用（如单元测试）

  • 布尔模式：props: true，将 params 作为 props 传递

5、动态路由(路由懒加载) ​

路由懒加载说明

  • 路由懒加载：也称为代码分割或按需加载，是指将路由对应的组件打包成独立的代码块，只有在访问该路由时才加载对应的组件代码。
  • 优势：
    • 减少初始加载时间：只加载当前路由需要的组件，而不是一次性加载所有组件
    • 减小初始包体积：将代码分割成多个小的代码块，按需加载
    • 提升用户体验：首屏加载更快，后续路由切换时再加载对应组件
    • 优化性能：减少内存占用，提高应用运行效率
  • 实现方式：使用动态 import() 语法，返回一个 Promise，Vue Router 会在需要时自动加载组件

基本用法：

Details
javascript
// router/index.js
import Vue from 'vue'
import VueRouter from 'vue-router'

Vue.use(VueRouter)

export default new VueRouter({
  routes: [
    {
      path: '/',
      name: 'Home',
      // 方式1：直接使用动态 import
      component: () => import('@/views/Home.vue')
    },
    {
      path: '/about',
      name: 'About',
      // 方式2：先定义再使用
      component: () => import('@/views/About.vue')
    }
  ]
})

分组打包（推荐）：

Details
javascript
// router/index.js
import Vue from 'vue'
import VueRouter from 'vue-router'

Vue.use(VueRouter)

export default new VueRouter({
  routes: [
    {
      path: '/',
      name: 'Home',
      // 使用 webpackChunkName 指定打包后的文件名
      component: () => import(/* webpackChunkName: "home" */ '@/views/Home.vue')
    },
    {
      path: '/about',
      name: 'About',
      component: () => import(/* webpackChunkName: "about" */ '@/views/About.vue')
    },
    {
      path: '/user',
      name: 'User',
      // 多个路由可以打包到同一个代码块
      component: () => import(/* webpackChunkName: "user" */ '@/views/User.vue')
    }
  ]
})

Details
javascript
// ❌ 静态导入（不推荐）- 所有组件都会被打包到主文件中

  ]

注意事项

  • 动态 import() 返回的是一个 Promise，Vue Router 会自动处理
  • 使用 webpackChunkName 注释可以自定义打包后的文件名，便于调试和管理
  • 懒加载的组件在首次访问时会有短暂的加载时间，可以配合 Loading 组件提升用户体验
  • 对于小型应用，如果组件数量不多，也可以不使用懒加载，避免过度优化

七、VueX 状态管理库 ​

1、vuex介绍 ​

VueX 是什么

  • VueX：Vue.js 官方提供的状态管理库，用于集中管理应用的所有组件的状态。
  • 为什么需要 VueX：
    • 当应用变得复杂时，组件之间的数据共享变得困难
    • 通过 props 和事件传递数据在深层嵌套组件中非常繁琐
    • VueX 提供了统一的状态管理方案，让数据流更加清晰和可预测
  • 核心概念：
    • State：存储应用的状态数据（类似组件的 data）
    • Getters：从 state 中派生出一些状态（类似组件的 computed）
    • Mutations：同步修改 state 的方法（类似组件的 methods，但只能同步）
    • Actions：异步操作，提交 mutations 来修改 state
    • Modules：将 store 分割成多个模块，便于管理大型应用
  • 适用场景：
    • 多个组件需要共享状态
    • 组件之间需要频繁通信
    • 需要统一管理全局状态（如用户信息、购物车等）

3、多store配置（Modules） ​

Modules 模块化说明

  • Modules：将 store 分割成多个模块，每个模块拥有自己的 state、mutations、actions、getters
  • 优势：
    • 代码组织更清晰，便于维护
    • 避免命名冲突
    • 适合大型应用的状态管理
    • 每个模块可以独立开发和测试
  • 命名空间：默认情况下，模块内部的 action、mutation 和 getter 是注册在全局命名空间的，可以通过 namespaced: true 开启命名空间

  },

      // 模拟登录
      return new Promise((resolve) => {

    }

}

const cartModule = {
  namespaced: true,
  
  state: {
    items: [],
    total: 0
  },
  
  getters: {
    itemCount: state => state.items.length,
    totalPrice: state => {
      return state.items.reduce((total, item) => {
        return total + item.price * item.quantity
      }, 0)
    }
  },
  
  mutations: {
    ADD_ITEM(state, item) {
      const existItem = state.items.find(i => i.id === item.id)
      if (existItem) {
        existItem.quantity += item.quantity
      } else {
        state.items.push(item)
      }
    },
    REMOVE_ITEM(state, itemId) {
      state.items = state.items.filter(item => item.id !== itemId)
    },
    CLEAR_CART(state) {
      state.items = []
      state.total = 0
    }
  },
  
  actions: {
    addToCart({ commit, state }, item) {
      commit('ADD_ITEM', item)
      // 可以访问其他模块的 state
      console.log('当前购物车商品数：', state.items.length)
    },
    checkout({ commit, dispatch, rootState }) {
      // 结账逻辑
      commit('CLEAR_CART')
      // 可以调用其他模块的 action
      dispatch('user/updatePoints', 100, { root: true })
    }
  }
}

  • 模块内部的 state 是局部状态，需要通过 context.state 访问
  • 开启 namespaced: true 后，访问模块需要使用命名空间路径

5、数据持久化 ​

数据持久化说明

  • 数据持久化：将 VueX 中的状态数据保存到本地存储（localStorage 或 sessionStorage），刷新页面后数据不丢失。
  • 实现方式：使用 vuex-persistedstate 插件
  • 适用场景：用户信息、购物车、设置项等需要持久保存的数据
  • 注意事项：敏感信息不建议存储在 localStorage 中
