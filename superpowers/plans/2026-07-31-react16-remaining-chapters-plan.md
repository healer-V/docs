## 三、重写约束

1. 每篇文档直接进入当前技术主题，不写课程式引导。
2. API 先解释作用、参数、返回值和边界，再给示例。
3. 示例必须解释触发方式和预期结果，不创建示例工程。
4. JavaScript/JSX 作为主要语言，类型内容只在必要位置补充。
5. React 行为以 16.8 为准，第三方生态必须说明兼容版本线。
6. 保留任务范围外的全部工作区改动，不执行自动提交或推送。
