# CSS 模块章节目录设计

CSS（层叠样式表）通过属性声明控制文档的呈现。理解 CSS 行为，需要同时回答三个问题：元素的属性如何得到值，元素生成的盒子如何布局，重叠内容按什么顺序绘制。本设计围绕这三个问题组织 `content/frontend/02-css/`，再补齐入门、外观、动效和工程使用能力。

这是一份章节目录与内容职责设计。用户于 2026-09-29 确认 `A02-06` 样板，并授权按本目录修改全部 CSS 正文。当前六章三十七篇均已落地，正式导航已切换；样板校准见[属性值处理样板评审](./2026-09-28-css-property-value-sample-review.md)，整体验证见[CSS 模块实施验收](./2026-09-29-css-module-delivery-review.md)。已有十二篇旧文保留原址，不计入新目录覆盖。

## 二、模块契约与知识边界

### 1. 教学契约

| 字段 | 内容 |
|------|------|
| 模块名称 | CSS |
| 模块位置 | `content/frontend/02-css/` |
| 主知识方向 | 浏览器中的声明式样式语言；采用语言覆盖模型中的环境、语法、值、对象关系、运行机制和调试能力，不机械加入语言不存在的变量赋值、通用控制流、类与线程 |
| 辅助方向 | 浏览器呈现模型与开发者工具；只解释证明 CSS 行为所需的 DOM、测量、绘制与性能观察 |
| 当前方向起点 | 从 CSS 规则、属性声明和引入方式开始；选择器、继承、盒模型和定位均在本模块讲解 |
| 最终能力 | 能独立给 HTML 页面添加样式；解释属性取值；选择并实现布局；定位遮挡问题；实现常用视觉反馈；维护组件样式并通过证据排错 |
| 主技术基线 | CSS 按模块规范维护，以 2026-09-28 核对的 MDN 文档为讲解基线；不使用统一“CSS3/CSS4”版本承诺 |
| 验证环境 | Windows、Edge 154.0.4258.37；样板局部数值已核对，当前 7 个完整示例独立复现，37 篇页面按桌面与手机视口验证；旧版演示页结果仅作历史记录 |
| 兼容边界 | 浏览器兼容数据与实际执行分别记录；Edge 单环境验证不能证明 Firefox、Safari 或旧浏览器兼容 |
| 维护线 | 保留旧文章 URL；不维护 IE 布局教程，不把 `border-box` 当作浏览器切入怪异模式 |

### 2. 三个机制的职责

| 主线 | 负责的问题 | 完整讲解位置 | 不承担的职责 |
|------|------------|--------------|--------------|
| 样式计算 | 哪些声明适用，哪个值胜出，默认值与依赖怎样解析 | 第 2 章 | 布局算法的尺寸求解、绘制前后顺序 |
| 视觉格式化模型 | 元素如何生成盒子，盒子怎样参与布局并获得尺寸和位置 | 第 3 章 | 属性声明冲突的裁决、层叠上下文的前后层级 |
| 层叠上下文 | 内容重叠时怎样组织绘制顺序，嵌套层级为什么限制 `z-index` | 第 4 章 | CSS 声明的层叠优先级、GPU 合成层分配策略 |

三者是教学上的组织主线，不是 MDN 规定的三个互斥模块，也不是浏览器实现必须依次完成的三个步骤。属性值处理中的应用值依赖布局信息；定位、变换和部分视觉效果又会影响包含块或层叠上下文，因此跨章引用必须保留必要上下文。
