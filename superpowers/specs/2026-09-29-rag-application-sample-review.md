## 六、批量生成校准

| 校准项 | 后续正文要求 |
|--------|--------------|
| 概念与机制 | 解释对象、因果及边界，不用 API 列表代替讲解 |
| 单篇职责 | 前置只保留最小上下文，知识完整主讲只有一个位置 |
| 独立示例 | 每篇给齐数据、依赖、文件和执行入口；统一场景不形成跨篇源码依赖 |
| 结果验收 | 将结构、来源、事实支持和业务条件分别验证，避免伪完成 |
| 检索策略 | 在各自职责文章完整解释向量、关键词、混合和重排，不推导出唯一实现方案 |
| 权限及维护 | 失败和不可见资料不得发送给模型，维护动作必须验证派生产物状态 |
| 阅读组织 | 核心条件与结论展开，长代码第 11 行起折叠，标题体现真实子问题 |
| 验证记录 | 离线、在线、仅编译及未验证结论区分，不能将计划写成实测 |
