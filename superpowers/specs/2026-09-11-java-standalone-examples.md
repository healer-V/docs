# Java 示例独立性修订

Java 文章中的示例以读者新建的空目录为起点。源码、构建配置、测试数据和运行命令均由当前文章提供；示例路径只表示读者需要创建的文件，不要求读者知道文档仓库或其他章节工程的结构。

## 一、修订范围

| 范围 | 处理结果 |
|------|----------|
| 单篇规范 | 升级为 v1.5，明确独立示例、文件起点、完整依赖、Wrapper 生成与空目录复现要求 |
| 执行入口 | 同步 AGENTS.md、文章内容契约和质量门禁，生成指令同样携带独立性约束 |
| Java 正文 | 审查 14 章、123 篇；补齐存在隐式依赖的代码、配置、数据与入口 |
| 知识组织 | 沿用 123 个文章职责、247 项知识与当前目录，未重新规划章节 |
| 展示规则 | 保留机制讲解和文字容器；超过 10 行代码折叠，短文件默认展开 |
| 兼容与工作区 | 保留历史锚点、导航与用户暂存区；不执行提交、推送或发布 |

规范源文件为仓库根的 `standards/documentation/article-generation.md`，章节来源和旧专题去向仍见[Java 全量重构记录](./2026-09-10-java-full-refactor.md)。

## 二、示例处理

| 章节 | 独立组织方式 |
|------|--------------|
| 语言、语法、面向对象与常用 API | 使用本篇创建的源文件和输出目录，补齐完整类、导入及必要支持类型 |
| Maven 与测试 | 使用独立 POM；仅多模块主题创建文中明确列出的父子模块；测试按本篇职责选取 |
| Gradle | 使用本篇标准源码目录；给出设置、构建脚本、源码、测试和生成 Wrapper 的命令 |
| JDBC 与并发 | 每篇提供依赖、主题测试及必要辅助类；数据库由本篇测试初始化 |
| JVM 与诊断 | 每篇提供当前模式所需的完整程序；同页完成编译、故障触发、证据采集和清理 |
| Java 8 维护 | 给出本篇工具链配置或 JDK 命令；在实际 Java 8 与 Java 21 进程中核对正常和失败路径 |

::: tip 验证以正文为输入
此次验证只从当前文章的代码块提取文件到空目录，再按文中步骤编译、运行或测试。实际执行内容必须与读者可见内容一致，才能发现缺失的依赖、配置与辅助类型。
:::

## 四、验证边界

GC 次数、CPU 时间和采样事件取决于机器、负载与观察窗口。H2 测试不包含生产数据库、网络故障或真实部署条件；本次未执行服务灰度、生产压测和数据库迁移。
:::

正常路径与故意失败的结果分开判断。示例明确声明的构建、执行与观测已按当前正文核对；库兼容范围、真实外部服务和其他操作系统仍需在目标环境验证。
