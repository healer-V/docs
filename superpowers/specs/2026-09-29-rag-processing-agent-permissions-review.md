## 二、职责与内容复核

| 文章 | 主讲及去重判断 | 结构完整性判断 |
|------|----------------|----------------|
| 解析与清洗 | 负责格式、编码、结构和清洗；结果为正文区块，最终片段由切分文章负责 | 原文身份、定位、否定词、噪声、格式拒绝及恢复均有原因和证据 |
| 切分与元数据 | 输入为明确的固定解析夹具，负责片段边界及标识；不复制通用解析器或向量排序 | 条件、重叠、标题、表格、区间单位和超长拒绝分别展开 |
| 增量采集 | 接收规范化资料，负责事件、哈希、游标和本地提交；索引发布另有归属 | 正常采集、修改、删除、重放、失败回滚与响应丢失形成连续判断路径 |
| 工具权限与人工确认 | 保留现有工具与业务操作键，主讲主体、范围和确认绑定；业务幂等引用原文章 | 授权先于确认，执行前再授权；终态、过期及业务结果未知有独立解释 |
| 沙箱与凭据边界 | 主讲执行环境的能力与秘密暴露；不扩写企业安全平台或容器部署教程 | 从控制器分离到文件、进程、网络、代理，再用反例及部署证据收束 |

已逐节检查现有小节及职责卡要求的必要子主题，无空小节、骨架化小节或课程式预告。表格用于对象、字段及诊断比较，因果解释保留正文；信息、建议、误区和危险容器紧邻相应主题。五份完整实现分别默认折叠，核心前提、执行入口和结果判断保持展开。

复核时修正了两处一致性问题：采集流程把当前游标检查明确放在写事务内；确认门禁先判断既有状态，防止迟到请求把已消费或已拒绝记录改成过期。后者新增两个确定性用例，人工确认从十三个增至十五个用例，并重新执行。

### 2. 空目录复现

完整 Python 围栏由 VitePress Markdown 解析器从本篇正文机械抽取到新的空临时目录，未补入文档未展示的数据、配置或辅助代码。使用实际 Python 3.12 逐个运行，修订后的确认程序单独复测。

| 命令 | 实际输出 | 主要观察及失败证据 |
|------|----------|--------------------|
| `python parse_policies.py` | `parser_tests=passed cases=8` | 四个 HTML 区块，否定词完整，原文第 6 行可定位；拒绝空文本、错误编码、未适配格式、表格及未闭合正文 |
| `python chunk_policies.py` | `chunking_tests=passed cases=9` | 四个片段覆盖五个正文区块，一个正文区间重叠，表格整体保留；版本和配置变化改变 ID，超长区块拒绝 |
| `python ingest_policies.py` | `ingestion_tests=passed cases=10` | 游标 8、有效片段 2、配送版本 3；持久重启、重放、相同正文、删除、回滚、缺口、恢复及提交确认丢失均验证 |
| `python approval_gate.py` | `approval_tests=passed cases=15` | 只创建一条 `pending_approval` 提议；未确认、篡改、越权、过期、撤权、重复及迟到请求均受阻 |
| `python boundary_checks.py` | `boundary_tests=passed cases=7` | `cwd_confines_files=False`，显式演示令牌对子进程可见，移除后不可见；代理拒绝越权对象与额外 URL、token 参数 |

合计 49 个离线用例。AST 检查覆盖 36 个类、函数与方法，均有职责说明；函数具有返回或副作用说明，多入参函数具备参数约束说明。所有 Python 文件可解析并实际执行。

## 六、证据边界与剩余正文

| 对象 | 当前结论与限制 |
|------|----------------|
| 解析 | 只证明文中约定的文本及 HTML 结构；通用网页、办公文件、OCR 和复杂布局未实现 |
| 切分 | 只证明固定政策区块及字符限制；没有检索质量或最佳长度结论 |
| 采集 | 固定连续不可变流与同一 SQLite 数据库；不含真实连接器、跨存储索引发布和物理删除 |
| 确认 | 固定可信身份、内存状态和单进程锁；动作只创建待审批提议，不连接真实审批或支付系统 |
| 隔离 | 运行了受控反例及代理接口策略；没有部署容器、虚拟机、网络代理或验证真实生产隔离 |
| 后续批次 | RAG「嵌入与索引」两篇，Agent「状态与记忆」三篇，继续使用已确认职责与阶段门禁 |
