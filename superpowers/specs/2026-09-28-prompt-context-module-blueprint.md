# Prompt 与上下文模块蓝图

“Prompt 与上下文”负责把业务任务转换为可执行的模型输入，并在有限上下文窗口中维护必要、可信、可追踪的信息。模块不以“万能提示词”或话术模板为主线，而是建立任务契约、指令权威、数据边界、上下文预算、会话状态和版本回归之间的工程关系。

本蓝图只定义知识责任和实施门禁。当前 `content/ai/03-prompt-context/index.md` 是旧规划页；样板文章通过验收前，不创建正文、不删除首页、不修改正式导航。模块与章节最终均不保留 `index.md`。

| 辅助知识方向 | 软件配置、测试与发布；只覆盖 Prompt 代码化、样本回归和渐进发布所需内容 |

:::
