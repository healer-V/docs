# Markdown 与 VitePress 语法归属整理

## 一、文章职责

用户明确要求继续整理两篇文档，将 Markdown 语法归入语法指南，VitePress 文档单独讲解其特有扩展。本次按该边界重新组织正文，保留现有文件和 URL。

| 文章 | 唯一问题与主讲范围 | 类型与深度 |
|------|--------------------|------------|
| `content/articles/tools/02-markdown-guide.md` | 如何编写可读的 Markdown，并区分基础语法、GFM 与平台插件行为；主讲段落、标题、强调、列表、引用、代码、链接、图片、表格、HTML 与通用扩展 | 语法参考，以使用为目标；从文本编辑开始，不要求编程基础 |
| `content/articles/blog/02-vitepress-markdown.md` | 如何在 VitePress 中使用其 Markdown 编译和默认主题能力；主讲容器、代码增强、内容导入、页面配置、标题锚点及 Vue 集成 | 语法与使用教程，以使用为目标；Markdown 基础由语法指南主讲，提供独立复现所需的环境与文件 |

VitePress 文档不重复通用标题、列表、图片和表格的语法。Markdown 指南只引用 VitePress 主讲文章，不保留专门的 VitePress 容器或代码组教学章节；指南页面自身仍使用仓库统一的提示和折叠容器展示说明。

## 二、知识归属

| 知识 | 主讲文章 | 处理方式 |
|------|----------|----------|
| 标题、段落、换行、强调、列表、块引用、围栏代码、链接与图片 | Markdown 指南 | 合并重复内容，纠正嵌套围栏、锚点、缩进及转义规则 |
| 表格、删除线、任务列表 | Markdown 指南 | 明确 GFM 扩展身份，不宣称所有 Markdown 渲染器都支持 |
| GitHub Alerts、脚注、数学公式、Mermaid、Emoji 简码 | Markdown 指南 | 说明平台或插件前提，只对实际已开启功能展示渲染结果 |
| 图片徽章、HTML 与 CSS 类名 | Markdown 指南 | 区分图片链接、HTML 和外部样式，删除无关且错误的图标名称表 |
| 原生容器、代码组、行高亮、聚焦、增删标记、错误警告标记与行号 | VitePress 扩展 | 给出输入与观察结果，普通 `diff` 代码块归入 Markdown 指南 |
| 代码片段导入、Markdown 包含、Frontmatter 页面选项、自定义锚点、目录生成 | VitePress 扩展 | 解释构建期处理，提供本篇直接展示的必要文件；目录语法只在示例文件中演示 |
| Badge、页面数据插值、v-pre 与图片编译配置 | VitePress 扩展 | 区分默认主题、Vue 编译和配置能力，不把项目 CSS 或非标准图片后缀写成原生语法 |

## 三、版本与修改范围

Markdown 核心规则以 CommonMark 0.31.2 为参考，GFM 与 GitHub 平台扩展分别按官方规范和文档核对。VitePress 独立示例固定 1.6.4、Node.js 22.19.0、pnpm 10.21.0；当前文档仓库保留 1.3.4，正文演示仅使用两者共有并经验证的能力。

当前站点没有启用任务列表复选框、脚注、数学公式、Mermaid 图形及双等号高亮的解析。源码可以展示，不把这些功能记录为已启用，也不为内容整理新增插件。

除两篇正文外，只调整 `.vitepress/themeConfig/nav.js` 与 `.vitepress/themeConfig/sidebar/more.js` 中对应入口的名称，新增本记录。无文件改名、依赖升级、远端推送和线上发布。
