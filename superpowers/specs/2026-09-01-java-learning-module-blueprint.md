# Java 21 主线与 Java 8 维护线模块蓝图

本文件保留为 2026-09-01 的历史蓝图，用于追溯既有样板与第1～4章交付。自用户于 2026-09-08 确认修订方案起，后续生成、目录迁移、文章职责和样板安排统一执行[当前 Java 模块蓝图](./2026-09-08-java-learning-module-blueprint.md)及其[职责与覆盖矩阵](./2026-09-08-java-article-responsibilities.md)。下方旧篇数、合并方案和样板限制不再作为当前执行要求。

## 一、模块教学契约

| 字段 | 内容 |
|------|------|
| 模块名称 | Java 核心 |
| 目标目录 | `content/backend/04-java/` |
| 主知识方向 | 编程语言；负责 Java 语法、类型、标准库和直接运行模型 |
| 辅助知识方向 | 工程化、数据访问和生产诊断；只覆盖 Java 开发者进入真实工程所需的能力 |
| 读者基线 | 计算机相关专业毕业或同等基础，具备通用编程、数据结构、操作系统、网络和数据库常识 |
| 当前方向起点 | 可以没有 Java 使用经验，从 JDK、源文件、编译运行和 Java 自身类型规则开始 |
| 主版本基线 | Java 21 LTS；示例使用标准 Java 21 能力，不使用预览特性 |
| 维护版本 | Java 8；只在第 14 章讲解能力边界、旧式代码和迁移 |
| 构建基线 | Maven 为主；Gradle 只建立阅读与迁移能力 |
| 最终能力 | 能编写、测试和解释 Java 程序；能使用 JDBC；能分析并发、JVM 和常见生产问题；能维护 Java 8 项目 |
| 范围排除 | Spring、Web 框架、ORM 深层机制、数据库内部原理、分布式系统和容器平台 |
