## 五、示例评审

三份完整 Java 代码块已与配套源文件逐字核对；比较时只剥离文档用于说明文件位置的首行注释。以下证据均来自实际执行，故意失败的用例按预期退出码判断。

| 验证对象 | 命令或入口 | 实际结果与证明 |
|---|---|---|
| 两份正向源码 | javac；`-Xlint:all -Xdoclint:all,-missing -Werror` | 退出0，无警告；包括 JavaDoc 语法检查 |
| 正向行为 | 两个主程序均使用 `java -ea` | 均退出0；合计10行输出与正文一致，覆盖金额比较、PECS、extends 清空、捕获交换、空输入、分组合并、instanceof 和擦除调用 |
| 故障源码编译 | UnsafeGenericDemo；保留 Xlint 与 doclint，不启用 Werror | 退出0，产生4条预期警告；未用 SuppressWarnings 隐藏证据 |
| 原始类型污染 | UnsafeGenericDemo raw | 退出1；Integer 读取为 String 时抛出 ClassCastException |
| 可变参数污染 | UnsafeGenericDemo varargs | 退出1；通过 Object[] 别名换入错误列表，读取时抛出 ClassCastException |
| 九处静态错误 | 从正文提取完整 InvalidGenerics.java，独立执行 javac | 退出1，9 errors；覆盖不变性、数组创建、通配符读写、捕获、实例化、instanceof 和擦除冲突 |
| 子类桥接字节码 | javap -p -c -v 检查 OrderIdSlot | 观察到 set(Object)、ACC_BRIDGE、ACC_SYNTHETIC、checkcast String 和转发 set(String) |
| 调用点与上界擦除 | javap 检查主程序与 Bounds 描述符 | 读取点包含 String checkcast；maximum 的两个参数和返回值描述符均为 Number |
| 别名和输入边界 | 临时 GenericBoundsProbe，带断言编译运行 | 同一列表复制得到 `[2, 3, 2, 3]`；单元素交换不变；不可修改目标触发 UnsupportedOperationException；null 比较输入触发 NullPointerException；数值相等时返回首个 BigDecimal 引用 |
| 数组与类型实参边界 | 同一边界程序及3份独立错误片段 | `new List<?>[2]` 与 Object 的 `List<?>` 判断合法；数组协变错误写入触发 ArrayStoreException；`List<int>`、类型参数下界、字符串复制到整数列表均编译失败 |

示例不访问外部系统。污染进程退出即可解除本地故障状态；修正源类型关系后重新编译运行，不在读取点吞掉异常。验证范围不包含并发一致性、性能基准、生产数据或业务事务。
