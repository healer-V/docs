## 三、独立示例与故障证据

完整 Python 围栏由 VitePress Markdown 解析器从本篇抽取，每份程序置于独立空目录。仅使用当前正文提供的代码、数据、依赖和公开模型制品；两份 RAG 程序分别解压模型到各自目录，三个 Agent 程序只使用标准库。

| 运行文件 | 实测输出 | 关键证据 |
|----------|----------|----------|
| `embeddings_similarity.py` | `embedding_tests=passed cases=12`；`dimensions=512 passages=3 top=shipping-policy` | 三条中文政策由真实模型表示，配送查询排名正确；维度、零向量、NaN、无穷值及类型边界受检查 |
| `vector_index.py` | `index_tests=passed cases=12`；`reopened=true stored_vector_bytes=2048 top=shipping-policy` | 每条 float32 向量占 2048 字节；重开库后一致，拒绝模型、前缀、维度与来源冲突，失败写入回滚 |
| `task_checkpoints.py` | `checkpoint_tests=passed cases=12`；`completed_sequence=5 model_steps=2 waiting_state=restored` | 重启恢复等待状态；陈旧写入、跨主体读取、非法版本、结果冲突及注入失败保持边界 |
| `agent_memory.py` | `memory_tests=passed cases=12`；`candidate_used=false expired_used=false remaining_rows=0` | 用户隔离、确认更新、候选摘要、到期边界、删除与物理清理均有观察结果 |
| `failure_recovery.py` | `recovery_tests=passed cases=14`；`duplicate_proposals=0 nonidempotent_unknown=manual expired_state=waiting_approval` | 三个提交前后故障关闭并重开数据库；重复不增提议，确认到期或撤权不执行新动作，损坏结果转人工 |

合计 62 个逻辑用例。AST 检查覆盖 38 个类、函数与方法，均有职责注释；函数注明返回或副作用，多入参函数注明参数及约束。没有仅依赖打印的通过信息，程序中的断言同时核对数据、状态和故障结果。

恢复示例使用两份数据库，任务提交与业务提交不构成同一事务。实际动作仅创建 `pending_approval` 提议；一条提议的恢复成功不能表述为退款执行成功。恢复复核增加了业务结果字段损坏用例，防止摘要正确但结果内容不合法时仍宣称完成。
