# About 页面资源分类扩充设计

## 一、目标与范围

### 1. 调整目标

`/docs/about/` 当前只有“知识文档”和“博客系统”两个分类，面试、源码原理和 GitHub 文章混放在“知识文档”中。本次调整新增“原理拆解”“面试题库”“GitHub文档”三个分类，使读者可以按学习目的定位资源。

页面继续使用现有分类标题、数量标记和资源卡片，不改变卡片交互、链接打开方式、响应式网格或已调整的标题行样式。

### 2. 资源来源

新增分类只使用 `AboutPage.vue` 已有链接和 `HomeBento.vue` 中已维护的相关链接，不临时引入未经项目使用的新站点。相同 URL 在 About 页面只出现一次；同时符合多个分类的资源按主要用途归入一个分类。

## 二、方案选择

| 方案 | 处理方式 | 优点 | 限制 | 结论 |
|------|----------|------|------|------|
| 直接重分类并复用 | 迁移现有条目，并从首页资源中补充对应分类 | 范围可控、内容完整、没有重复 | About 与首页仍分别维护数据 | 采用 |
| 仅迁移现有条目 | 不复用首页资源 | 修改最少 | “知识文档”和新增分类内容偏少 | 不采用 |
| 抽取共享资源配置 | About 与首页读取同一数据源 | 可消除跨组件数据重复 | 涉及首页重构，超出本次范围 | 不采用 |

## 三、分类设计

### 1. 展示顺序与资源归属

分类按“基础资料 → 原理理解 → 面试准备 → 社区沉淀 → 博客参考”的学习路径展示。资源归属如下：

| 顺序 | 分类 | 描述方向 | 资源 |
|------|------|----------|------|
| 1 | 知识文档 | 系统教程和框架文档 | ExplainThis、小满 React Docs、ES6 标准入门、现代 JavaScript 教程、网道文档 |
| 2 | 原理拆解 | 源码、运行机制和底层原理 | Vue 源码剖析、Vue3 源码解析、Vue.js 技术揭秘 |
| 3 | 面试题库 | 面经、知识检查和面试准备 | 小鹤、面试指南、前端官 Vue3 面试题 |
| 4 | GitHub文档 | GitHub 上持续维护的技术文章和知识库 | 前端知识分享、冴羽 JavaScript 深入系列、前端知识笔记 |
| 5 | 博客系统 | 个人博客和主题参考 | 粥里有糖、DK酱、onedayxyy |

“前端知识分享”虽然内容属于服务端渲染原理，但其载体是 GitHub 单篇技术文章，因此统一归入“GitHub文档”，避免在“原理拆解”中重复展示。

### 2. 图标与数据结构

三个新分类分别使用能够表达“机制”“问答”和“代码仓库”的线性图标，并沿用现有 `16px` 尺寸、描边粗细和主题强调色。图标组件继续由 Vue `h` 函数渲染，不新增图片资源或外部图标依赖。

`sections` 数组保持现有数据结构，每个分类继续提供 `title`、`desc`、`iconComponent` 和 `items`。资源卡片字段保持 `icon`、`name`、`desc` 和 `link`，因此模板和样式无需重构。

## 四、验证标准

### 1. 内容与页面验证

完成修改后必须满足以下条件：

1. 页面依次显示五个分类，分类数量与实际卡片数一致；
2. 全部资源 URL 唯一，原有 About 页面链接没有丢失；
3. 新增资源链接与 `HomeBento.vue` 中现有地址一致；
4. 桌面端保持双列卡片，移动端保持单列卡片；
5. 新分类图标、标题、数量和横线没有重叠或错位；
6. VitePress 全量构建成功，且代码修改仅涉及 `AboutPage.vue`。
