# VitePress 建站教程修订记录

## 一、文章职责

| 字段 | 约定 |
|------|------|
| 文章 | `content/articles/blog/01-vitepress.md`，标题为“VitePress 建站教程” |
| 授权依据 | 用户要求评审该文章，在明确的问题清单与六项补充建议后要求“继续” |
| 唯一问题 | 如何从空目录创建、配置、预览并准备发布一个 VitePress 文档站 |
| 主类型 | 接入教程；辅助类型为测试与排障 |
| 目标深度 | 使用；能解释配置层级、文件路由及部署路径的差异 |
| 前置知识 | 基本文件操作、终端命令及 Markdown；正文解释本任务所需的配置术语 |
| 版本 | 独立示例固定 VitePress 1.6.4、pnpm 10.21.0、Node.js 22.19.0；不升级文档仓库依赖 |
| 场景 | 团队手册：一个首页和一篇“文档约定”，统一使用 `team-handbook` 项目名与部署前缀 |
| 必须覆盖 | 环境、依赖、完整文件、启动、配置层级、内容编写、资源路径、导航搜索、主题扩展、构建预览、GitHub Pages、错误恢复 |
| 排除范围 | 不实现业务后端、登录、动态内容管理、评论系统或复杂 Vue 组件；广告与统计仅给官方接入入口 |
| 知识引用 | Markdown 通用语法由 `content/articles/tools/02-markdown-guide.md` 主讲；扩展语法由同目录 `02-vitepress-markdown.md` 主讲 |
| 迁移范围 | 保留文章文件与页面 URL；标题调整后扫描受影响站内锚点，不建立旧锚点兼容 |

## 二、修订方案

按已接受的评审方向重组单篇正文，补足独立示例和操作结果。保留现有文章路径，在一篇教程中完成从空目录创建站点到准备发布的完整过程。

完整实现各保留一个权威代码块，其他配置明确标注为合并到已有对象中的局部修改。超过十行的代码默认折叠，配置、命令和结果相邻展示；必要前提、路径误区和发布风险保留在折叠外。

GitHub Pages 使用官方 Artifact 工作流，固定与本地一致的依赖工具和输出目录。正文可以讲解用户自行执行的发布步骤，本任务不推送、不创建远端仓库、不执行线上部署。
