# DevOps：Linux 模块蓝图

本蓝图细化[DevOps 知识目录重构设计](./2026-09-23-operation-devops-directory-design.md)的 Linux 模块。以下路径是**拟新建路径**，不是可访问的教程链接。旧版 Linux 目录已退役；蓝图确认后另行制作样板文章，样板经确认后才逐章写作。

## 一、模块教学契约

| 字段 | 内容 |
|------|------|
| 模块名称 | Linux 主机运维 |
| 目标目录 | `content/operation/01-linux/` |
| 主知识方向 | 基础设施与平台：以主机资源、生命周期、配置、权限、存储、网络和诊断为教学对象 |
| 辅助知识方向 | 工程工具：只讲操作所需的终端与命令帮助；不教授 Bash 编程语法 |
| 读者基线 | 会使用电脑和浏览器，理解文件与目录；不预设 Linux、另一门编程语言或生产运维经验 |
| 当前方向起点 | Linux、内核、发行版与 Ubuntu Server 的关系；隔离实验环境；首次登录、终端和命令结构 |
| 主版本基线 | Ubuntu Server 26.04.1 LTS、amd64、全新隔离虚拟机；建议实验资源 2 GiB 内存、20 GiB 系统盘，可为存储章另加一块可丢弃的虚拟盘。建议值是课程余量，不是官方最低配置 |
| 最终能力 | 在隔离主机上独立安装、定位文件、管理本地账号与权限、管理服务和软件、安排周期任务、验证备份恢复、判断本机网络与防火墙、保护 SSH 入口，并按证据定位常见资源及服务故障 |
| 范围排除 | Bash 脚本编程、通用 TCP/IP 原理、Nginx 指令、容器/集群、集中监控与告警、SRE 流程和跨系统安全治理；分别由领域设计的其他模块主讲 |

官方 Ubuntu Server 26.04.1 LTS 下载页提供当前安装介质；[26.04 LTS 发布说明](https://documentation.ubuntu.com/release-notes/26.04/)给出的服务器起始配置为 1.5 GB 内存、4 GB 存储。正文以虚拟机控制台为失联回退入口；远程网络、SSH、挂载和权限变更前先保存快照或可恢复的实验数据。命令输出随硬件和软件更新变化，正文验证观察项与退出状态，不伪造固定 PID、IP、时间或包版本。

## 二、知识方向与边界

### 1. 方向覆盖模型

| 覆盖层次 | 适用状态 | 当前模块检查内容 | 判定依据 |
|----------|----------|------------------|----------|
| 资源与对象 | 适用 | 文件、用户、进程、服务、块设备、网络接口 | 主机可见对象是操作与诊断基础 |
| 生命周期 | 适用 | 安装、运行、变更、停止、恢复 | 每次变更要能观察状态与回退 |
| 配置与操作 | 适用 | 命令、权限、服务单元、软件源、计划任务 | Ubuntu Server 官方教程和操作指南 |
| 网络与存储 | 适用 | 地址、路由、解析、设备、文件系统、挂载、备份 | 仅主机配置和本机证据，不展开协议设计 |
| 安全与隔离 | 适用 | 本地身份、`sudo`、SSH、更新、防火墙和审计线索 | 限于主机基线；组织级治理不在本模块 |
| 可观测与诊断 | 适用 | 进程状态、journal、容量、CPU、内存、I/O 与连接 | 本地观察；集中遥测归监控模块 |
| 高可用与恢复 | 部分适用 | 备份、还原验证和变更回退 | 单机没有副本调度与集群故障转移能力 |

### 2. 前置知识与排除内容

| 前置知识 | 要求深度 | 入口或处理方式 |
|----------|----------|----------------|
| 电脑文件与目录 | 认识 | 只借用日常概念；Linux 路径、挂载和权限在本模块从零讲 |
| 虚拟机操作 | 使用 | 安装文在当前篇给出可复现的虚拟机创建、控制台和快照步骤；不要求事先掌握某个产品 |
| 网络地址 | 认识 | 在主机网络篇给出 IPv4、网关、DNS 的最小解释；协议机制可继续学习同领域 `03-networking`，尚未发布时不加失效链接 |

| 排除主题 | 正确归属 | 当前模块边界 |
|----------|----------|----------------|
| Bash 的变量、展开、条件、管道和脚本质量 | `02-bash-shell` | 只解释命令调用和必要的输入/输出，不把 Shell 语法当作读者前置 |
| TCP/IP、DNS、TLS 的协议机制和跨节点排障 | `03-networking` | 只检查本机地址、路由、解析结果和连接证据 |
| Nginx、容器、集群的产品配置 | 对应独立模块 | 本模块以最小本机服务演示 `systemd`，不代替产品教程 |
| 集中日志、指标、链路、告警和容量平台 | `09-monitoring-observability` | 只观察主机本地状态与日志 |
| 事件响应、SLO、演练、组织级安全治理 | SRE、运维安全 | 仅讲本机恢复与权限边界，不声称形成组织流程 |

## 三、版本与来源

### 1. 版本基线

| 项目 | 版本或环境 | 使用范围 | 差异处理 |
|------|------------|----------|----------|
| Ubuntu Server | 26.04.1 LTS amd64 | 安装和所有操作示例 | 24.04、其他发行版只在确有影响处说明，不混用包管理和网络配置 |

| 定时任务 | 以实例上安装并核验的 `cron` 或 `systemd` timer 为准 | 周期任务篇选定一种完整演示 | 不预设两者都默认安装；不混写两套配置 |
