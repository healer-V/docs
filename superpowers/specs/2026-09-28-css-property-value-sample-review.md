## 三、验证结果

验证时从当前文章提取 HTML 和 CSS 局部片段，在系统 Edge 的隔离页面中组合加载，未使用旧版演示页代码。以下结果对应 `1440×900` 视口：

| 条件 | CSSOM 宽度解析值 | 字号解析值 | 边框框宽度 |
|------|-------------------|--------------|---------------|
| 默认，容器 `480px` | `240px` | `30px` | `268px` |
| 容器改为 `320px` | `160px` | `30px` | `188px` |
| 父级字号改为 `24px` | `240px` | `36px` | `268px` |
| 元素宽度改为 `auto` | `452px` | `30px` | `480px` |

`CSS.supports('width', 'blue')` 返回 `false`。本次验证证明片段中的尺寸关系及无效值语法判断；它不证明所有属性或浏览器都按这些数字返回。

文档页面复用既有 `127.0.0.1:5173` 服务，在 `1440×900` 和 `390×844` 视口检查。首屏显示主题定义和六个编号概念，第三节才出现最小示例；手机文档滚动宽度 `385px`，小于 `390px` 视口。执行 `pnpm docs:build:unit frontend` 成功，结果为 198 页、612 个产物文件。

此前订单演示页的 15 场景及截图验证属于旧稿历史，不能作为当前局部片段的验证结果。旧截图文件保留，但当前正文不再引用。

## 四、后续文章校准

1. **先讲知识**：定义必要概念，解释它们的关系和成立条件，再使用足以核对结论的最小例子。
2. **按类型选示例**：概念和机制文章可用局部规则、关系图或状态对照；操作、接入和排错文章才按其目标提供可独立复现的完整链路。
3. **突出判断**：序号表示先后关系，VitePress 容器突出关键结论、前提或误区；正文保留原因与推导，不用容器数量充当内容质量。
4. **不预设业务场景**：示例对象由知识点决定，不因蓝图或前篇使用过某个页面就强行贯穿全模块。
