## 六、批量写作校准

| 校准项 | 本样板形成的约束 |
|--------|------------------|
| 内容深度 | 不把 `systemctl` 命令清单当作教程；要解释状态独立性并用调用结果判断 |
| 小节与阅读顺序 | 按对象、创建、正常状态、故障恢复和撤销推进；只有独立子问题才加标题 |
| 容器与折叠 | 前提和风险在操作前，11 行起折叠完整配置，核心判断始终展开 |
| 场景与证据 | 每篇从其自身条件起步；示例对象固定、可恢复，输出区分预期与实测 |
| 版本与术语 | 主线为 Ubuntu Server 26.04.1，官方版本依据和实际包版本分别记录 |
