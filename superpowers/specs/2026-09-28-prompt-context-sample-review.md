# Prompt 与上下文样板文章评审

本轮以 Prompt 构造和会话状态两种不同职责校准 AI03 正文。指令与数据边界样板已完成全部在线与离线验证；会话状态样板的手工历史已完成真实两轮调用，另外两种服务端状态模式被当前兼容网关阻断，因此本模块不能把样板门禁标记为全部通过。

| 字段 | 内容 |
|------|------|
| 模块 | Prompt 与上下文；Python 3.12 / OpenAI Python SDK 3.19.2 |
| 模块蓝图 | [Prompt 与上下文模块蓝图](./2026-09-28-prompt-context-module-blueprint.md) |
| 主样板 | [指令与数据边界](../../content/ai/03-prompt-context/02-prompt-construction/01-instructions-data-boundary.md)，`AI03-A02-01` |

## 八、批量生成校准项

| 校准项 | 样板结论 | 后续文章必须执行的规则 |
|--------|----------|------------------------|
| 内容深度 | 结构选择必须绑定职责、证据和失效条件 | 不以 Prompt 文案清单或 API 参数表代替机制解释 |
| 小节粒度 | 二级标题表达主题阶段，三级标题表达可独立判断的问题 | 并列短事实使用表格；有机制和失败边界时再设标题 |
| 标题表达 | 使用“信息职责”“边界转义”等技术短语 | 删除聊天式问题和完整结论，不牺牲必要技术对象 |
| 阅读顺序 | 先定义来源与责任，再实现、对照、失败与范围 | 不把安全限制和验证前提前后倒置 |
| 长代码折叠 | 第 11 行起默认折叠 | 折叠外保留请求形状、关键函数、执行入口和判断依据 |
| 示例场景 | 延续虚构客服工单 | 固定模型和数据做对照，不用真实客户文本 |
| 证据形式 | Prompt 用固定输入对照；状态 API 用两轮调用和清理证据 | 环境不支持时必须保留错误原文和未验证标记 |
| 安全表述 | 分区提高可解释性，不等于安全防护 | 权限、工具和输出动作必须由确定性代码限制 |
| 版本表达 | 固定 SDK 与官方行为日期 | 兼容网关能力与官方 API 能力分别描述 |

| 重要 | AI03 旧目录只有 4 章 11 篇 | 导航遗漏指令契约、会话状态和完整生命周期 | AI catalog、模块首页、导航测试 | 已同步为确认后的 5 章 15 篇，2 篇样板开放链接 |
